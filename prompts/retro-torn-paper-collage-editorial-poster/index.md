# 复古手撕拼贴

![预览图](preview.webp)

## Prompt

```text
围绕用户提供的主题，创作一张“复古手撕拼贴 × 编辑海报”风格的封面海报。

整体目标是：
让旧报纸、撕裂纸边、杂志切片、胶带、复印颗粒、半调网点、手写批注和强标题排版，共同组成一张具有杂志叙事感的拼贴海报。

最终效果应介于：
独立杂志封面、
街头海报墙、
复古电影海报、
青年文化刊物、
艺术展览海报

之间。

这不是把几张素材随便堆起来，
也不是干净的矢量拼图，
而是一张看得出“纸张层次、印刷痕迹、编辑判断和主次关系”的复古拼贴设计。

【输入】
主题词 / 主标题：{{主题词}}
副标题：{{副标题，可留空}}
画幅比例：{{画幅比例}}
语言：{{中文 / 英文 / 中英混排}}
用途：{{用途}}
可选补充语境：{{补充背景，可留空}}
可选情绪倾向：{{情绪倾向，可留空}}
可选禁用元素：{{不想出现的元素，可留空}}

【核心目标】
先理解“{{主题词}}”真正想表达的内容、情绪、矛盾、关系或处境，
再把它转化成一张具有故事感的拼贴编辑海报。

重点判断：
- 画面最值得被放大的核心是什么
- 主图应该是什么
- 标题应该以什么方式介入拼贴
- 哪些纸片、批注、小字和印刷痕迹真正有必要
- 画面是更偏文化、批评、情绪、街头、档案、艺术，还是趋势观察

不要停留在把主题名词逐个画出来。
不要做成“报纸元素背景 + 一行大标题”的模板图。

【画面原则】
整张图尽量只保留：

1 个主标题；
最多 1 个副标题；
1 个主视觉中心；
1 套拼贴叙事关系；
少量但有效的纸片层次；
少量但有效的辅助文字系统。

拼贴可以丰富，
但不能失控。

整体应做到：
层次丰富，但主次清楚；
看似随意，但实际平衡；
元素很多，但阅读路径明确。

【主题转译】
优先把主题转译为以下某一种拼贴叙事方式：

- 一个核心物件 + 若干纸片证据
- 一个局部人物 / 手部 / 动作 + 标题冲突
- 一个概念符号 + 报纸化解释痕迹
- 城市碎片 / 文本碎片 / 标签碎片共同指向一个判断
- 一张被剪开、遮挡、重组的标题卡
- 一组有限切片共同表达一个主题现场

所有元素必须共同讲一件事。
不要出现多个无关主视觉。
不要为了“拼贴感”而无序堆满。

【拼贴材料】
可使用但不必全部使用：

- 手撕纸片
- 旧报纸裁片
- 杂志页面切片
- 复印件碎片
- 半调网点图片
- 黑白或低彩度照片局部
- 小型标签纸
- 胶带
- 手写批注
- 贴纸式小标记
- 油墨错位文字
- 放大镜式局部强调
- 圈注、箭头、下划线、框选痕迹

材料数量应经过控制。
不要把所有素材都堆进同一张图。

【纸张质感】
必须保留清楚的纸张属性：

- 撕裂边缘
- 不规则纸片轮廓
- 轻微卷边
- 纸张厚薄差异
- 层叠阴影
- 旧印刷颗粒
- 复印粗粝感
- 半调网点
- 轻微油墨不均
- 局部错位印刷感

纸张层与层之间要有真实遮挡和接触阴影。
不要让所有元素都像悬浮贴在同一平面上。

【撕裂与层次】
手撕边缘要自然、粗粝、有方向感，
不要整齐裁切成标准矩形。

拼贴层次可以采用：

- 大底纸 + 小碎片
- 一张主图纸片 + 几张辅助说明纸
- 被撕开的标题纸 + 主图穿插
- 局部遮挡、借位、露边、压叠
- 大块留白中的少量碎片组合
- 一块强主视觉 + 边缘零散编辑痕迹

不要所有纸片都同样大、同样重要。

【主视觉】
主图可根据主题自动选择为：

- 物件切片
- 局部人物
- 城市碎片
- 符号结构
- 剪开的标题结构
- 档案式图像片段
- 放大的细节局部

主图不一定要完整。
可以是：
半张脸之外的局部、
一只手、
一个物件切角、
一段街景碎片、
一个被撕开重组的符号。

但必须清楚服务主题。
不要用无关好看图片撑场。

【人物使用】
如果主题适合人物，
优先使用“局部人物、动作片段、剪影切片或脸部局部”，
而不是完整商业人像。

人物应更像：
杂志剪报、
复古摄影复印件、
电影定格、
街头文化拼贴素材。

不要默认加入人物脸。
如果加入人物，人物必须服务主题关系，而不是装饰。

【色彩】
配色可以根据主题自动判断为：

1. 高对比方向
适合更强烈、街头、批评、青年文化、杂志冲击感。
可用黑、白、红、深蓝、亮黄等少量强对比色。

2. 复古低饱和方向
适合文化、文艺、档案、旧刊物、纪录感。
可用米白、旧黑、灰蓝、砖红、橄榄绿、褪色黄、脏粉等复古印刷色。

3. 中性色 + 单一强调色
适合更高级、编辑、品牌化、展览感。
以纸色、黑灰和 1 个强调色控制全图。

无论哪种方向，
都必须带有旧印刷质感，
不要鲜艳到像现代电商视觉。

【印刷与复印质感】
加入克制但清楚的印刷痕迹：

- 半调网点
- 复印噪点
- 油墨轻微错位
- 轻微套印偏差
- 老报纸颗粒
- 局部发虚的文字边缘
- 扫描件粗糙感
- 纸面阴影

这些痕迹要增强真实拼贴感，
不要脏乱到影响阅读。

【标题】
主标题必须准确显示：

“{{主题词}}”

主标题必须是画面的第一视觉之一，
并与纸片、主图、标签共同构图。

标题可以采用以下方式之一：

- 印在一张大撕纸上
- 被纸片局部遮挡
- 复印错位叠印
- 油墨轻微压印感
- 被手写批注局部覆盖
- 被切开分段重组
- 嵌入报纸 / 杂志碎片体系中
- 与主图形成压叠、咬合或借位关系

标题必须醒目、完整、清楚可读。
不要为了效果破坏识别度。

【标题排版】
标题可以根据主题选择：

- 超大粗体编辑标题
- 被切开的分段标题
- 错位叠印标题
- 一部分在纸片上，一部分直接落在背景上
- 横排为主，必要时局部竖排
- 与手写批注或标签发生层级关系

标题排版需要有明显编辑感，
不要普通居中打字。

中文可使用：
现代黑体、
粗黑无衬线、
高对比宋体、
窄体黑体。

英文可使用：
grotesk、
condensed sans-serif、
editorial serif、
bold serif、
typewriter-like editorial fonts。

不要使用：
卡通字体、
过度花体、
廉价艺术字、
圆润可爱字体。

【副标题】
如果用户提供副标题：
“{{副标题}}”
则准确显示一次。

副标题明显小于主标题，
可作为：
栏目说明、
小标签、
报纸说明、
边缘说明条、
档案注释。

如果没有提供副标题，
不要自动补大段解释文案。

【小字系统】
允许极少量辅助文字，
形式可以像：

- 栏目名
- 日期
- 编号
- 报纸说明
- 边角标签
- 贴纸文字
- 手写批注
- 小型档案注释

但这些小字必须服务主题和版式。
不要为了“杂志感”硬塞很多无意义文字。

小字应当只作为第三层信息存在。
不能和主标题抢主视觉。

【手写批注】
允许加入少量手写感内容，例如：

- 圈注
- 箭头
- 下划线
- 星号
- 短短的批注句
- 重点标记
- 框选线
- 贴纸备注

批注要像编辑手稿、复印件标记或策展备注，
自然、简短、克制。

不要把整张图做成手账页。
不要大量散落无意义英文。

【胶带与贴附痕迹】
可以加入少量胶带或贴附结构：

- 半透明胶带
- 泛黄旧胶带
- 边缘贴附纸条
- 固定住报纸碎片的胶带痕迹

胶带只能起到“固定层次、增强真实拼贴感”的作用。
不要满图贴胶带。

【构图】
根据 {{画幅比例}} 原生设计构图，
不要先做固定版式再裁切。

可采用：

- 主标题压上方，主图偏下
- 左标题右拼贴
- 右标题左拼贴
- 中央主图，标题错位压叠
- 偏心构图
- 不对称平衡
- 大留白 + 少量拼贴聚焦
- 多纸片向一个主中心聚拢

整张图必须有清楚的阅读路径：
先看到主标题，
再看到主图或核心纸片，
再看到小字与批注。

【比例适配】
- 横版 16:9 / 5:2：
  适合左右关系、报刊排版感、街头海报感、标题与拼贴分区。
- 竖版 4:5 / 3:4 / 9:16：
  适合更强封面感、上下堆叠、标题压住主图、碎片纵向层叠。
- 方形 1:1：
  适合集中冲突、主图居中、标题与纸片环绕、较强图形感。

每个比例都要重新安排主标题、纸片大小、留白和层次。

【情绪倾向】
根据 {{情绪倾向}} 调整画面气质：

- 青年 / 街头：
  提高对比度，增强撕裂感、贴墙感、冲击性。
- 档案 / 研究：
  更克制，增强报纸说明、编号、小标签和复印件结构。
- 文艺 / 复古：
  增加旧纸感、低饱和色和独立刊物气质。
- 批判 / 压迫：
  增强标题冲突、错位叠印、局部强黑块和剪切感。
- 安静 / 怀旧：
  保持更多留白，减少色彩冲突，强调纸张与印刷时间感。
- 展览 / 编辑：
  提高版式纪律，减少杂乱元素，增强高级设计感。

【用途适配】
根据 {{用途}} 自动调节信息密度。

- 公众号 / 文章封面：
  强化标题可读性，减少小字。
- X / 社交媒体：
  缩略图下主标题和主图仍然清楚。
- 海报：
  可以增加更完整的拼贴层次和编辑元素。
- 展览 / 品牌视觉：
  提高留白与秩序，减少街头杂乱感。
- 青年刊物 / 文化视觉：
  允许更大胆撕裂、复印和标签叠印关系。

【必须避免】
不要素材无序堆叠。
不要每个元素都抢主视觉。
不要干净矢量拼图感。
不要现代无菌拼贴。
不要把纸张边缘做得过于整齐。
不要让所有纸片一样大、一样重。
不要只做“报纸背景 + 大标题”。
不要无意义堆满贴纸、胶带、小字和标签。
不要复杂信息图。
不要电商排版。
不要 3D 物体。
不要平滑数字海报感。
不要出现 {{可选禁用元素}}。

【生成前检查】
生成前内部检查：

- 是否先理解了主题，而不是堆关键词？
- 是否只有 1 个主视觉中心？
- 主标题是否完整、准确、清楚？
- 图像、标题、纸片和小字是否在共同讲一个故事？
- 撕纸边、纸张阴影、半调网点和复印颗粒是否清楚可见？
- 是否存在“故意随意但设计平衡”的秩序？
- 是否有无关装饰物？
- 是否有元素在抢主视觉？
- 如果删掉某个元素不影响主题，删掉它。
- 画面是否更像独立杂志拼贴，而不是素材堆放？

【最终标准】
最终只生成一张独立完整海报。

不要输出：
分析、
解释、
多个方案、
拼图、
网格、
样机、
联系表。

最终画面必须同时具备：

一个清楚醒目的主标题；
最多一个副标题；
一个明确主视觉中心；
真实的撕裂纸边与纸张层次；
旧报纸 / 杂志切片感；
复印噪点与半调网点；
少量胶带与贴附痕迹；
克制有效的手写批注；
有主次关系的编辑小字系统；
旧印刷颗粒与油墨错位感；
平衡而不杂乱的拼贴秩序；
强杂志叙事感。

远看时，
先看到主标题和主拼贴结构。

近看时，
再看到撕纸边、
层叠阴影、
半调网点、
复印颗粒、
小标签、
手写批注和编辑细节。

最终效果应像一张真正被剪、撕、贴、复印、标注过的复古编辑海报：

有纸感，
有印刷痕迹，
有故事，
有设计判断，
而不是“素材随机堆放的拼贴图”。
```
