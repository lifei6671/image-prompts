# 黑色复古现代主义封面

# 黑色复古现代主义封面

## Prompt

```text
请根据下面的用户输入，创作一张「黑色复古现代主义编辑插画封面」。

整体视觉融合：

20 世纪中期现代主义书封，
复古杂志封面，
黑色电影视觉语言，
几何平面设计，
丝网印刷与旧版印刷质感。

画面以黑色作为绝对主色，
通过强烈的黑白面积关系、一个鲜明点缀色、简化主体和有力量的标题，
形成复古、高级、理性、克制、鲜明的封面视觉。

不要简单套用某一种电影、侦探或复古题材，
而是根据用户主题重新设计核心视觉。

────────────────

【用户输入】

主题词 / 主标题：
{{填写必须准确显示的主标题}}

副标题：
{{可留空}}

辅助短句：
{{可留空，建议 4–12 个字}}

核心主体：
{{人物 / 产品 / 建筑 / 动物 / 科技设备 / 服务场景 / 抽象概念 / 自动判断}}

画幅比例：
{{5:2 / 16:9 / 4:5 / 3:4 / 9:16 / 1:1 / 其他}}

语言：
{{中文 / 英文 / 中英混排}}

用途：
{{公众号封面 / X 封面 / 视频封面 / 海报 / 文章封面 / 其他}}

点缀色：
{{红色 / 绿色 / 蓝色 / 橙色 / 紫色 / 黄色 / 自动判断}}

补充语境：
{{行业 / 场景 / 内容背景 / 受众 / 可留空}}

情绪倾向：
{{高级 / 克制 / 神秘 / 温暖 / 冷峻 / 理性 / 经典 / 戏剧性 / 可留空}}

不想出现的元素：
{{可留空}}

────────────────

【设计目标】

最终作品应首先是一张具有强烈封面感的编辑设计，
而不是普通插画上叠加标题。

画面只围绕以下四个核心元素组织：

一个主标题，
一个核心主体，
一个主要视觉中心，
一个点缀色重点。

整体感觉：

复古，
高级，
理性，
克制，
简洁，
几何化，
具有出版物气质，
带少量黑色电影式戏剧感。

画面可以具有张力，
但不要拥挤。

────────────────

【颜色系统】

全图严格控制在 3 种主要颜色以内：

1. 黑色：绝对主色；
2. 白色或米白色：辅助色；
3. 一个点缀色。

黑色应占据画面的大部分面积，
承担背景、主体暗部、阴影和整体气质。

建议形成明显的：

大面积黑
+
有限白 / 米白
+
小面积单一彩色

的面积关系。

白色或米白色可以用于：

主标题，
人物肤色，
主体局部，
高光，
轮廓分离，
少量排版信息。

点缀色只能使用一种。

可选择：

红色，
绿色，
蓝色，
橙色，
紫色，
黄色。

如果用户选择“自动判断”，
根据主题、情绪和主体选择最合适的一种。

点缀色用于：

主体关键局部，
一个标题重点词，
单一几何形状，
服装局部，
产品局部，
或画面中的唯一视觉强调。

点缀色必须集中、明确。

不要让多个区域平均分配彩色。

────────────────

【核心主体】

每张图只保留一个核心主体或一个不可拆分的主体组合。

主体根据用户填写的“核心主体”确定。

如果填写“自动判断”，
根据主题和核心语义选择最具有代表性的视觉对象。

核心主体可以是：

人物，
产品，
建筑，
动物，
科技设备，
服务场景，
抽象概念，
或由主题自然推导出的其他对象。

主体必须：

轮廓清楚，
结构简洁，
容易识别，
具有强烈图形感。

不要加入多个互相竞争的主体。

────────────────

【主题转译】

不要机械地把主题词转换成最常见的图标。

先理解主题真正要表达的：

人物关系，
行为，
状态，
冲突，
服务，
产品价值，
空间关系，
变化，
压力，
选择，
速度，
风险，
控制，
连接，
或其他核心含义。

然后选择一个最有代表性的主体或视觉场景。

例如：

技术主题不一定画芯片；

AI 主题不一定画机器人；

互联网主题不一定画电脑；

服务主题不一定画握手；

增长主题不一定画上升箭头。

允许使用更具有叙事性和封面感的视觉隐喻。

────────────────

【插画语言】

将主体转译为复古现代主义编辑插画。

采用：

几何化轮廓，
简化结构，
扁平大色块，
剪影式明暗，
有限内部细节，
少量夸张比例，
硬朗而明确的形状关系。

主体不是照片描摹。

保留最重要的：

外轮廓，
动作，
姿态，
结构，
表情类型，
标志性局部。

删除不影响识别的小细节。

人物可以使用：

简化五官，
大面积黑色阴影，
米白肤色，
几何服装块面，
具有电影感的侧光关系。

产品可以使用：

明确外轮廓，
大块黑白结构，
一个彩色关键局部。

建筑可以使用：

简化立面，
几何体块，
硬边明暗。

动物可以使用：

标志性头部轮廓，
耳朵、尾巴、姿态等关键特征。

抽象概念可以使用：

几何关系，
剪影，
路径，
空间冲突，
局部符号化结构。

整体更接近复古书封和编辑插画，
不要追求写实细节。

────────────────

【构图】

严格按照用户指定的画幅比例设计。

比例只决定画布尺寸，
不要把比例数字显示在画面中。

构图根据：

主体形态，
标题长度，
画幅比例，
用途，
视觉重心

自适应决定。

可使用：

左图右字，
左字右图，
主体居中 + 周边文字，
上下分区，
偏单主体构图，
边缘裁切构图，
大面积黑色负空间 + 单侧主体。

横版：

可以让一侧保持大面积黑色负空间承载标题，
另一侧布置主体，
形成明确戏剧关系。

竖版：

可以让标题和主体形成上下错落，
或让主体贯穿中央区域，
保持复古书封式秩序。

方形：

可以使用偏心式构图，
让主体和标题形成一个紧凑但明确的视觉整体。

不要机械居中。

不要填满每一处空白。

黑色负空间本身就是重要构图元素。

────────────────

【满版设计】

画面采用满版出血设计。

背景、主体或主要色块可以直接延伸到画布边缘。

四边不要形成额外外框。

整体视觉应像一张真正印刷到裁切边缘的书封或杂志封面。

────────────────

【主标题】

主标题是画面的第一视觉中心之一。

必须准确使用用户提供的主标题：

不改写，
不删减，
不自动翻译，
不额外增加宣传语。

主标题应：

醒目，
易读，
有重量，
具有书封或编辑设计气质。

中文主标题可使用：

粗重宋体气质，
标题宋气质，
几何黑体，
复古招牌式字体，
或具有强烈印刷感的标题字体。

根据主题自动选择最合适的一种。

不要同时混用大量字体。

────────────────

【副标题与辅助短句】

如果用户提供副标题：

准确呈现原文，
字号明显低于主标题。

英文副标题可以使用：

优雅衬线体，
简洁大写无衬线体，
或现代主义编辑字体。

如果用户提供辅助短句：

只显示这一条，
保持小尺寸和低视觉权重。

除以下内容外不要自行添加文字：

主标题，
副标题，
辅助短句。

如果副标题或辅助短句为空，
不要生成对应内容。

不要自行添加：

日期，
网址，
编号，
标签，
品牌署名，
说明文字，
英文翻译，
装饰性假文字。

────────────────

【图文关系】

标题和主体必须共同形成封面结构。

不要让文字只是简单覆盖在插画上。

可以通过：

主体轮廓与文字边缘对齐，
标题进入主体附近负空间，
文字与色块产生错位，
标题和主体形成上下或左右重量平衡，
点缀色连接文字与主体

建立图文关系。

标题必须始终清楚可读。

主体不能遮挡标题关键文字。

纹理不能影响文字识别。

副标题和辅助短句明显弱于主标题。

────────────────

【点缀色】

整张图只能存在一个彩色视觉重点。

如果点缀色用于主体，
优先放在最具有故事性或识别度的区域。

例如：

衣服局部，
眼镜，
帽子，
产品表面，
建筑结构，
动物特征，
几何背景块，
重要道具。

如果用于文字，
最多强调主标题中的一个词或极少量字符。

不要同时：

主体大面积彩色
+
标题多处彩色
+
背景彩色色块。

点缀色的作用是建立视觉记忆点，
不是增加丰富度。

────────────────

【明暗】

使用复古现代主义插画式明暗。

采用：

大面积黑色阴影，
有限白色高光，
清晰硬边，
剪影式明暗结构。

可以带有轻微黑色电影气质，
例如：

侧光，
逆光，
局部遮蔽，
大面积暗部，
强烈明暗分区。

但仍然保持平面设计感。

不要进行复杂写实光照模拟。

────────────────

【复古印刷质感】

允许加入轻微的印刷介质质感：

细微纸张颗粒，
轻度丝网印刷网点，
很轻的油墨不均，
轻微旧书封印刷感，
极少量油墨磨损，
非常轻的套色偏差。

这些效果必须克制。

质感不能：

破坏主体轮廓，
降低标题可读性，
让整张图显得脏乱，
造成严重褪色。

复古感主要来自：

综合色彩，
排版，
几何形态，
印刷语言，

而不是人为制造严重老化效果。

────────────────

【最终视觉效果】

最终作品应呈现：

大面积黑色
+
白色 / 米白色辅助结构
+
一个鲜明点缀色
+
一个核心主体
+
一个强主标题
+
几何化编辑插画
+
少量复古印刷质感
+
满版出血构图。

整体具有：

20 世纪中期书封设计感，
复古杂志编辑感，
黑色电影式戏剧气质，
现代主义几何秩序，
鲜明的出版物封面感。

即使缩小观看，
也应能够快速识别：

标题，
核心主体，
综合色调，
唯一的点缀色重点。

────────────────

【生成前内部检查】

生成最终画面前检查：

是否只有一个核心主体；

是否只有一个主要视觉中心；

是否只有一个主标题；

是否最多只有副标题和一个辅助短句；

是否只使用黑色、白色 / 米白色和一种点缀色；

黑色是否承担主要视觉面积；

点缀色是否真正集中在一个重点；

主体是否足够几何化和简洁；

标题是否清晰可读；

主体与标题是否共同构成封面结构；

是否保留足够黑色负空间；

是否采用满版出血设计；

复古印刷质感是否足够克制。

────────────────

【避免】

不要霓虹赛博风；

不要现代蓝紫科技渐变；

不要多彩综合色调；

不要同时使用多个亮色；

不要复杂渐变；

不要玻璃拟态；

不要金属 3D；

不要写实摄影；

不要照片拼贴；

不要 3D 渲染；

不要动漫或漫画风；

不要复杂机械细节；

不要密集背景；

不要普通互联网宣传海报感；

不要大量小图标；

不要参数面板；

不要复杂 UI；

不要信息过载；

不要未经用户提供的额外文字；

不要白色边框；

不要卡片式外框；

不要圆角白边；

不要四周留白式卡片；

不要外圈浅色包边。
```
