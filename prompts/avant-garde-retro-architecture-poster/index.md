# 先锋复古建筑海报

![预览图](preview.webp)

## Prompt

```text
请根据下面的用户输入，创作一张「先锋复古彩色新构成主义建筑海报」。

整体视觉融合：

20 世纪中期建筑旅行海报，
现代编辑设计，
新构成主义空间秩序，
大面积纯色背景，
完整大色面，
清晰建筑明暗结构，
开阔留白，
克制的丝网印刷质感。

建筑本体是唯一视觉中心，也是画面主要色彩来源。

不要把建筑处理成写实照片或精细建筑效果图，而是保留最有识别度的建筑轮廓、比例与结构，将其转译为大胆、完整、鲜明的复古色块。

────────────────

【用户输入】

主题词 / 建筑名称：
{{填写建筑名称或主题词}}

副标题：
{{可留空}}

英文名称：
{{可留空；仅显示用户明确提供的内容}}

城市 / 国家：
{{可留空；仅使用用户提供的信息}}

坐标：
{{可留空；仅使用用户提供的信息，不自行查询或编造}}

画幅比例：
{{5:2 / 16:9 / 4:5 / 3:4 / 9:16 / 1:1 / 其他}}

语言：
{{中文 / 英文 / 中英混排}}

用途：
{{文章封面 / 社交媒体封面 / 活动海报 / 视频封面 / 城市海报 / 其他}}

补充语境：
{{建筑年代 / 地域 / 建筑类型 / 内容背景 / 可留空}}

情绪倾向：
{{庄严 / 开阔 / 明亮 / 冷峻 / 梦幻 / 厚重 / 其他 / 可留空}}

不想出现的元素：
{{可留空}}

────────────────

【设计目标】

先理解当前建筑最重要的视觉识别特征，包括：

整体轮廓，
纵横比例，
主体体块关系，
主要结构层级，
顶部形态，
立面关系，
基座关系，
标志性结构，
建筑的延展方向，
最适合表现其特征的观察角度。

在内部完成判断，不输出分析过程。

最终只保留一个核心建筑。

无论采用完整展示、适度裁切还是局部放大，
都必须让该建筑保持明确识别度。

整个画面的重点是：

建筑轮廓
+
大面积建筑色块
+
纯色背景
+
清晰明暗结构
+
克制文字
+
大量留白。

────────────────

【观察角度】

根据建筑自身结构选择最适合的机位。

不要预设固定视角。

可选择：

正面平视，
正面中轴，
侧前方透视，
侧面视角，
轻微俯视，
高位远眺，
斜向俯视，
低机位仰视，
中距离完整展示，
远距离环境展示，
近距离局部放大，
横向全景，
或建筑群环境中的单一核心建筑。

不同建筑类型优先考虑其结构特征：

高塔、摩天楼、纪念性塔楼：
可使用完整纵向展示、平视远眺、侧前方透视或适度仰视。

宫殿、车站、博物馆、剧院和横向公共建筑：
可使用正面中轴、平视、侧前方透视或轻微俯视。

山地建筑、古城、寺庙群、层叠建筑：
可使用高位观察、斜向俯视或具有远近层次的视角。

桥梁、长城、城墙、长廊和其他线性建筑：
可使用横向全景、路径透视、俯视或斜向延伸。

具有强烈标志性的屋顶、穹顶、球体、拱门、入口或立面：
可以局部放大，将标志性结构作为视觉中心。

机位必须服务于建筑识别，
而不是为了制造夸张透视。

────────────────

【构图】

严格按照用户填写的画幅比例设计。

比例只决定画布尺寸，不在画面中显示比例文字。

根据：

建筑轮廓，
建筑延展方向，
画幅比例，
文字数量，
留白位置

重新设计每张海报。

建筑可以位于：

中央，
中间偏左，
中间偏右，
画面下部，
一侧，
对角线区域，
大面积留白旁，
或被画面边缘适度裁切。

不要求完整居中。

不要求建筑从底部延伸出来。

不要求巨大近景。

不要求固定对角线。

横向建筑应获得足够横向空间，
纵向建筑应获得足够纵向空间，
复杂建筑则优先寻找最有识别度的主体体块。

保留开阔负空间，
使建筑与背景形成明确的面积关系。

────────────────

【背景】

背景始终使用一种大面积纯色。

背景承担：

综合色调，
空间留白，
建筑颜色的衬托。

保持背景完整、安静、平坦。

不要默认模拟真实天空。

背景中不要加入复杂环境。

不要使用：

复杂渐变，
摄影天空，
写实云层，
多色色块拼接，
巨大太阳，
放射线，
复杂几何图案，
装饰性城市天际线。

背景颜色必须根据建筑本身重新判断，
不要固定使用某一种复古配色。

────────────────

【建筑色彩】

建筑本体是整张海报颜色最丰富、视觉吸引力最强的区域。

不要简单照搬建筑真实材质颜色。

根据建筑：

结构，
年代，
地域，
气质，
体块关系，
画面情绪

重新建立一套独立配色。

建筑内部主要使用 2–3 种完整的大面积颜色。

颜色作用于真正的建筑大结构，例如：

主立面与侧立面，
主要受光面与阴影面，
主体与基座，
前部与后部体块，
塔身不同层级，
屋顶与墙体，
球体与支撑结构，
台阶与平台，
突出结构与主体结构。

颜色必须沿着真实建筑结构组织。

不要为了增加丰富度而随意切割色块。

────────────────

【整体配色数量】

全图控制在约 4–5 种主要颜色。

推荐结构：

1 种大面积背景色，
2 种主要建筑色，
1 种深色结构或阴影色，
必要时增加 1 种小面积跳色或高光色。

综合色彩面积可参考：

背景：
约 55%–75%。

建筑主体颜色合计：
约 20%–35%。

深色结构与阴影：
约 8%–15%。

极小面积跳色：
约 3%–8%。

这些比例用于控制视觉秩序，
不要求机械执行精确数值。

色彩应：

鲜明，
复古，
干净，
大胆，
具有先锋性，
但保持协调。

复古不等于灰暗。

先锋不等于高饱和颜色堆叠。

每张图根据建筑重新建立综合色调，
不要机械轮换固定色卡。

────────────────

【建筑简化】

保留建筑最重要的识别信息：

总体轮廓，
纵横比例，
主体体块，
屋顶，
塔尖，
穹顶，
球体，
塔身，
主要立面，
墙体，
柱体，
台阶，
拱门，
基座，
层级关系，
核心结构转折。

将这些结构转化成清晰的大面积形状。

弱化不会影响建筑识别的小细节，例如：

密集门窗，
幕墙网格，
栏杆，
瓦片，
屋檐纹样，
雕刻，
小装饰，
真实石材纹理，
玻璃反射，
金属反光，
复杂灯光，
微小建筑构件。

目标不是复制全部建筑细节，
而是用最少的结构表达最强的建筑识别度。

────────────────

【明暗与体积】

使用简洁、清楚的硬边明暗关系。

通常建立：

一个主要受光方向，
一个主要亮面，
一个主要阴影面，
明确的结构转折，
少量硬边投影，
必要的局部高光。

明暗的作用是解释：

建筑体量，
结构层级，
空间方向，
前后关系，
建筑识别。

不要进行照片级光照模拟。

不要复杂环境光。

不要高光反射堆叠。

不要使用精细 3D 渲染式阴影。

整体应该更接近复古印刷海报中的建筑体积表达。

────────────────

【环境与前景】

环境不是必需元素。

只有当环境能够帮助：

识别建筑，
解释空间，
建立尺度，
强化构图

时，才加入少量环境结构。

允许使用：

建筑基座，
广场，
台阶，
道路，
山体，
水面，
墙体，
屋顶，
必要附属建筑体块，
极少量远处城市剪影。

环境必须被高度概括。

前景最多保留 2–3 个主要体块。

环境使用当前已有综合色彩，
不要建立新的复杂配色系统。

所有环境都必须服务于核心建筑，
不能形成第二视觉主体。

────────────────

【文字】

只使用用户明确提供的信息。

最多显示：

建筑名称 1 处，
副标题 1 处。

英文名称：
仅当用户明确填写时显示。

城市 / 国家：
仅当用户明确填写时显示。

坐标：
仅当用户明确填写时显示。

不得自行增加：

英文翻译，
城市，
国家，
经纬度，
年份，
建筑年代，
旅游口号，
宣传文案，
功能说明，
品牌名称，
网址，
日期，
无意义英文小字。

如果副标题为空，
只保留建筑名称及其他用户明确提供的信息。

文字总面积控制在画面的约 8% 以内。

建筑始终比文字更重要。

────────────────

【字体与编辑排版】

文字采用：

建筑档案式排版，
现代编辑设计，
复古旅行海报中的现代主义文字系统。

根据建筑和构图选择：

高窄无衬线字体，
粗重几何无衬线字体，
现代主义 Grotesk 气质字体，
或具有建筑档案感的简洁字体。

可使用：

适度增加字距，
整齐边缘对齐，
极少量细横线，
简单分隔符，
小型档案式辅助排版。

文字可以位于：

左上角，
右上角，
建筑旁的大面积留白，
画面边缘，
或与建筑轮廓形成空间呼应的位置。

文字位置根据实际构图决定，
不要固定。

文字不得压住建筑最重要的识别结构。

────────────────

【图文关系】

文字与建筑共同构成一个整体版式，
而不是简单地把标题覆盖在建筑照片上。

建筑负责主要视觉重量。

文字负责建立：

名称，
秩序，
节奏，
编辑感。

让文字边缘、建筑轮廓和背景留白之间形成明确关系。

可以通过：

对齐，
错位，
上下对应，
左右平衡，
轮廓呼应，
空间留白

建立图文联系。

不要用无关几何图形填补空白。

留白本身就是构图元素。

────────────────

【印刷质感】

最终画面带有非常克制的复古印刷介质感。

可以加入：

细微纸张颗粒，
极轻丝网印刷网点，
轻微油墨不均，
自然的综合色彩变化，
极轻微套色偏移，
非常轻的年代感。

这些效果必须很微妙。

建筑轮廓仍然保持清楚。

颜色仍然保持鲜明。

整体仍然保持现代设计精度。

复古感来自印刷介质和综合色彩，
而不是把整张图片：

做黄，
做脏，
做暗，
做旧，
做模糊，
做低清晰度。

────────────────

【最终视觉效果】

最终作品应呈现：

一个核心建筑
+
一个大面积纯色背景
+
2–3 个建筑主体大色面
+
清晰硬边明暗
+
开阔留白
+
少量建筑档案式文字
+
克制丝网印刷质感。

整体具有：

20 世纪中期旅行海报的综合色彩，
现代编辑设计的版式意识，
新构成主义的空间秩序，
建筑图形设计的清晰轮廓，
当代视觉设计的克制感。

它应该首先是一张具有鲜明视觉记忆点的建筑海报，
其次才是建筑信息载体。

────────────────

【生成前内部检查】

生成最终画面前检查：

是否只有一个核心建筑；

建筑是否仍然一眼可识别；

机位是否真正适合当前建筑；

建筑位置是否根据轮廓和画幅决定；

背景是否只有一种纯色；

建筑是否承担主要颜色；

建筑颜色是否按照真实大结构组织；

是否避免把建筑切成大量碎色块；

是否控制在约 4–5 种主要颜色；

是否存在明确亮面和阴影面；

环境是否足够克制；

文字是否只来自用户提供的信息；

文字面积是否明显小于建筑；

是否存在足够留白；

复古质感是否保持轻微而克制。

────────────────

【避免】

不要固定使用同一种机位或构图；

不要固定低视角或仰视；

不要固定把建筑放在中间偏右；

不要固定黄色、蓝绿色或红蓝米白综合色调；

不要让鲜明色彩只存在于背景或装饰元素；

不要让建筑整体变成米白、灰色、沙色、银色或无色剪影；

不要机械保留建筑现实原色；

不要把建筑切成大量碎色块；

不要为每层楼、每扇窗或每个小部件单独上色；

不要依赖无关圆形、三角形、放射线、斜线或随机几何色块制造设计感；

不要精细建筑插画；

不要照片写实；

不要建筑 3D 效果图；

不要复杂城市天际线；

不要多建筑抢主体；

不要复杂信息图布局；

不要荧光色；

不要电子霓虹色；

不要综合色调灰暗发闷；

不要严重褪色；

不要脏污纸面；

不要破损海报；

不要大面积划痕；

不要模糊建筑轮廓；

不要过度噪点。
```
