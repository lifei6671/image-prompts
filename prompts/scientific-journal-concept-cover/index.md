# 科研期刊概念

![预览图](preview.webp)

## Prompt

```text
围绕用户提供的研究主题，创作一张“科研期刊封面式概念视觉 / scientific journal cover-style concept image”。

整体目标是：
像顶级科研期刊封面一样专业、克制、清晰、有机制暗示和学术高级感，
但不复制任何真实期刊的刊名、Logo、固定版式或官方识别元素。

这不是普通科技海报，
不是蓝紫色科技背景，
不是实验流程说明图，
也不是把几个科研元素随便拼在一起。

请先理解研究真正的亮点，再将其转译为一个强而清晰的科学主视觉。

【输入】
封面主题 / 主标题：{{主题}}
副标题：{{副标题，可留空}}
学科方向：{{医学 / 生物 / 材料 / AI / 物理 / 化学 / 工程 / 其他，可留空}}
核心机制 / 视觉概念：{{一句话写清楚研究亮点或封面概念}}
画幅比例：{{画幅比例}}
文字需求：{{极少文字 / 只要标题 / 标题+副标题 / 不要文字}}
配色方案：{{配色方案或自适应}}
版式偏好：{{自动判断 / 大主视觉 / 极简封面 / 暗色氛围 / 浅色高级 / 中心主体 / 斜向构图 / 微观世界 / 宏观隐喻 / 结构剖面}}

【核心原则】
整张图只保留：

1 个核心科学主视觉；
1 个清楚的机制暗示；
1 个明确视觉中心；
1 套统一配色与材质逻辑；
1 套克制的科研编辑版式。

不要把研究做成“所有信息都画出来”的说明图。
不要同时放入多个不相关主视觉。
不要用泛泛的科技粒子、随机 DNA、随机芯片、随机试管来冒充科研感。

【主题理解】
先理解：
“{{主题}}”真正表达的研究对象、关键机制、作用关系、变化方向和最终结果。

再判断：
- 研究的主角是什么
- 关键过程是什么
- 最值得被看见的机制是什么
- 哪种视觉转译最适合单张封面表达

优先把研究亮点压缩为一个可视化判断句，例如：
- 某种分子如何进入或阻断某个系统
- 某种材料如何形成特定结构或性能
- 某种神经 / 细胞 / 网络如何建立连接或响应刺激
- 某种工程系统如何完成控制、传输、筛选或协同
- 某种 AI / 计算模型如何重构、预测、生成或优化复杂关系

不要输出分析过程，只输出最终视觉结果。

【科学主视觉】
主视觉必须原创，并与“{{核心机制 / 视觉概念}}”强相关。

可用的视觉主体包括但不限于：
细胞、
蛋白、
细胞器、
组织结构、
神经网络、
药物递送载体、
纳米颗粒、
微流控芯片、
材料晶格、
界面结构、
分子装置、
光学结构、
机器人系统、
工程剖面、
生态模型、
能量场、
网络结构、
计算单元、
抽象科学装置。

但必须按当前研究主题选择，
不要默认套用固定元素。

主体应同时满足：
- 一眼能看出是科学主题
- 能暗示机制，而不是只剩装饰
- 有明确主次和空间层次
- 可以支撑高质量期刊封面视觉

【机制可视化】
不要画完整实验流程。
不要塞进步骤图、箭头图、框图或多面板图。

应只暗示最关键的机制，例如：
- 结合 / 解离
- 穿透 / 包裹
- 组装 / 自组装
- 传递 / 递送
- 激活 / 抑制
- 开启 / 封闭
- 迁移 / 扩散
- 重构 / 折叠
- 导引 / 聚焦
- 筛选 / 分离
- 生长 / 修复
- 识别 / 预测 / 优化

机制应通过：
空间关系、
材料变化、
能量流动、
局部光场、
结构变形、
连接方式、
包裹关系、
轨迹或梯度

来被看见。

【学科适配】
根据学科方向自动调整视觉语言：

如果是医学 / 生物：
优先考虑细胞、组织、蛋白、膜结构、免疫、药物递送、信号传导、神经连接、微观生态等；
强调生命科学质感、膜结构、半透明流体、微观层次和柔和发光。

如果是材料 / 化学：
优先考虑晶格、界面、纳米结构、孔道、分子组装、催化位点、反应路径、材料剖面等；
强调结构精度、表面质感、层状结构、晶体秩序和材料反应关系。

如果是物理：
优先考虑场、波、轨迹、能级、光束、粒子、干涉、拓扑结构、时空关系等；
强调抽象精确、场域关系、方向性和简洁力量感。

如果是工程：
优先考虑流体、器件、微流控、机械结构、传输网络、系统剖面、功能界面、控制节点等；
强调装置感、结构逻辑、剖面关系和功能路径。

如果是 AI：
优先考虑计算单元、表征空间、关系网络、特征汇聚、生成机制、推理路径、模型协同等；
不要默认机器人、芯片、电路板。更应表达“机制”和“结构关系”，而不是消费级科技审美。

如果学科未指定，则根据主题自动判断最合理的科学视觉语言。

【微观与宏观】
允许使用以下两种策略之一：

1. 微观世界
直接表现研究对象的微观结构、细胞环境、材料表面、分子系统、能量场或装置内部机制。

2. 宏观隐喻
在不损失科学严谨感的前提下，将微观机制转译为更宏观但仍专业的视觉结构，例如：
桥接、
通道、
屏障、
门户、
聚合体、
网络、
流场、
剖面地貌、
能量核心、
层状世界。

只选择一种主策略，不要同时堆叠多个世界观。

【构图】
根据“{{版式偏好}}”和“{{画幅比例}}”决定构图。

优先保持：
一个中心主体，
明确空间层次，
清楚前中后景，
大块视觉焦点，
合理留白。

可采用：
- 中心主体构图
- 斜向动势构图
- 结构剖面构图
- 微观世界景深构图
- 悬浮主体构图
- 宏观隐喻构图

但整张图必须只有一个清楚的主导关系。

不要平均铺满画面。
不要四处都是视觉重点。
不要变成拼图、四宫格或多面板图。

【材质与渲染】
整体视觉应介于：
高端科学插图、
期刊封面级数字渲染、
高级概念可视化

之间。

可使用：
透明材质、
半透明膜、
流体、
微粒、
晶体、
金属、
陶瓷、
凝胶、
玻璃、
纤维、
发光界面、
微观表面纹理、
结构剖面层。

但所有材质都必须服务研究主题，不要炫技堆材质。

渲染要求：
- 高精度
- 专业
- 层次清楚
- 光影自然
- 细节可信
- 不廉价
- 不像游戏海报
- 不像通用科技宣传图

【色彩】
配色遵循“{{配色方案}}”；未提供时，根据学科和主题自适应选择一套高级、专业、具有科研期刊气质的配色。

可采用：
- 深色背景 + 高亮主体
- 浅色背景 + 精致结构
- 低饱和高级色
- 局部高饱和点亮机制区域
- 冷暖对比但整体克制

医学 / 生物可偏：
蓝绿、青蓝、紫蓝、珊瑚红、琥珀色等生命科学配色。

材料 / 化学可偏：
深蓝、黑金、银灰、青绿、铜橙、晶体紫等。

物理 / 工程可偏：
深蓝、冷灰、亮青、电蓝、白金、橙红能量点等。

AI 可偏：
冷灰、蓝绿、墨蓝、少量荧光点缀，但保持克制，不做赛博朋克。

不要整张图只有廉价蓝紫渐变。
不要配色混乱。
不要高饱和堆满全图。

【文字与版式】
遵循“{{文字需求}}”严格控制文字数量。

如果是“不要文字”：
画面中不出现任何标题、副标题或其他可读文字。

如果是“只要标题”：
只显示主标题“{{主题}}”。

如果是“标题+副标题”：
显示主标题“{{主题}}”和副标题“{{副标题}}”。

如果是“极少文字”：
显示主标题，必要时可带极短副标题或一句短说明，但仍保持克制。

所有文字必须像科研编辑版式的一部分：
- 少量
- 清楚
- 可读
- 不遮挡主体关键结构
- 与边距、网格和留白协调

不要生成真实期刊刊名。
不要加 Logo。
不要加卷号、期号、条码、网址、机构名、页脚说明、作者列表或虚构出版信息。

【标题排版】
标题风格偏科研编辑设计：
- 现代无衬线
- 简洁衬线
- 清楚专业
- 不夸张
- 不宣传海报化

标题可位于：
上方、
左上、
下方留白区、
边缘信息区

但必须避开主视觉最复杂区域。

如果副标题存在：
明显小于主标题，
不喧宾夺主，
仅承担说明作用。

【留白与编辑气质】
画面需要具备科研期刊封面的“呼吸感”和“边距意识”。

要有：
- 清楚边界
- 适当留白
- 科学编辑感
- 稳定结构
- 精致秩序

不要把画面塞满到像说明书。
不要把文字压在主体复杂细节上。
不要像商业广告页。

【光影】
根据科学主体选择合适光影：
- 微观世界可有局部发光、透射、折射、体积感
- 材料结构可有边缘反射、表面微光、剖面明暗
- 工程装置可有清楚结构照明和层级阴影
- 生物系统可有柔和发光、流体氛围和内部空间感

整体应专业、自然、精致。
不要夸张爆炸光效。
不要满屏光束。
不要廉价炫光。

【必须避免】
不要复制真实期刊封面。
不要使用真实期刊名、Logo、固定版式或官方视觉资产。
不要普通蓝紫科技背景。
不要随机 DNA。
不要随机芯片。
不要无关实验器材。
不要把科学机制画成密集说明图。
不要流程图、节点图、步骤图、仪表盘或 PPT 风。
不要多面板拼贴。
不要无意义粒子特效。
不要廉价赛博朋克。
不要与研究无关的抽象科技纹理。

【生成前检查】
生成前内部检查：

- 是否只有一个核心科学主视觉？
- 是否清楚表达了“{{核心机制 / 视觉概念}}”？
- 是否与“{{学科方向}}”匹配？
- 是否避免了说明图和流程图倾向？
- 是否没有复制真实期刊刊名、Logo 或官方版式？
- 是否保留了专业科研期刊封面的编辑气质？
- 若有文字，文字是否足够少、清楚且不遮挡主体？
- 画面是否专业、高级、原创，而不是通用科技背景？

如果某个元素不帮助理解研究亮点，就删除它。

【最终标准】
最终图像应像一张真正能用于高水平科研期刊封面的概念视觉：

原创科学主视觉，
明确但不过度解释的机制暗示，
符合学科气质的主体与材质，
高级配色，
专业渲染，
克制文字，
稳定编辑版式，
强视觉中心，
可用于封面传播。

只生成一张最终图。
不要输出分析、解释、多个方案、拼图、网格或联系表。
```
