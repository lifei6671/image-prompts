`````text
# 黑白复古蚀刻版画封面

## Prompt

```text
创作一张具有强烈概念性和视觉辨识度的黑白复古蚀刻版画封面。

【输入】
标题：{{填写标题}}
主题：{{填写主题}}
核心意思：{{用 1–3 句话说明真正想表达的观点、矛盾、关系或问题}}
画幅比例：{{默认 5:2，可填写 1:1 / 4:5 / 3:4 / 16:9 / 9:16 / 自定义}}
视觉方向：{{主体、场景、意象、氛围或构图方向；可填写“自由发挥”}}
情绪：{{克制 / 神秘 / 深邃 / 理性 / 超现实 / 哲学 / 宏大 / 孤独 / 压迫 / 未知 / 荒诞 / 诗意 / 庄严 / 探索感 / 自动判断}}
输出模式：{{纯图 / 完整标题 / 核心标题 / 预留文字区}}
副标题：{{可留空}}
避免元素：{{可留空}}

【创意目标】
不要逐字把标题中的关键词画成对应物体。

根据“标题 + 主题 + 核心意思”，提炼其中最重要的一组关系、矛盾或问题，并将它转译成一个清晰、有记忆点的视觉场景。

整张画只建立一个主要视觉隐喻和一个明确视觉中心。

可以通过改变现实中的尺度、距离、空间、结构、数量、方向、功能、材质或因果关系制造陌生感，让熟悉事物形成具有思想性的视觉冲突。

人物、建筑、机械、自然、生物、物体或抽象结构都可以成为主体，由主题本身决定。

不要因为出现 AI 就自动加入机器人、芯片或电脑；
不要因为出现认知就自动加入大脑；
不要因为出现学习就自动加入书本。

只有当某个元素真正服务于核心意思时才使用它。

目标是让观者：
第一眼被一个强烈场景或关系吸引；
第二眼理解画面中的冲突或隐喻；
知道标题后能够理解为什么画面被这样设计。

【视觉媒介】
整体采用十九世纪铜版雕刻、蚀刻版画、木口木刻、古典科学插图与超现实编辑插画融合的视觉语言。

只使用：
纯黑、
纯白、
由墨线和点形成的视觉灰阶。

灰色必须来自线条密度，而不是数字灰色填充。

使用：
细密平行排线表现方向、光影和曲面；
交叉排线建立体积、重量和深阴影；
点描表现雾气、远景、空气、皮肤、石材、纸张和颗粒；
具有轻微手工痕迹的雕刻线勾勒轮廓和结构。

允许局部存在：
线条轻微断续、
排线密度变化、
纸墨不均匀、
细微印刷偏差和传统版画颗粒。

这些痕迹必须克制，不要破坏主体清晰度。

材质主要通过线条的方向、粗细、间距、交叉方式和密度区别，而不是依赖数字高光和光滑渐变。

保持强烈黑白对比。

可以使用大面积纯黑形成深渊、夜空、洞口、阴影、未知区域或视觉重量，同时让关键主体拥有非常精细的刻线细节。

整体必须具有真实手工版画的物质感，而不是给普通数字图片叠加“复古滤镜”。

【构图】
根据 {{画幅比例}} 原生设计构图，不要先生成固定画面再裁切、拉伸或补边。

优先建立：
清晰的大轮廓，
明确的视觉中心，
一个主要视觉轴，
可辨识的前景、中景和背景关系。

横向画幅：
优先用于环境叙事、水平运动、距离关系、左右冲突和巨大空间。

纵向画幅：
优先用于垂直尺度、巨大主体、仰视、坠落、上升和压迫感。

方形画幅：
优先用于集中冲突、象征性场景和单一主体。

主体与核心隐喻发生的位置保持最高信息密度和最精细刻线。

次要区域主动简化、淡出、留白或沉入纯黑。

不要让所有区域拥有相同细节密度，也不要为了填满画面加入无关装饰。

留白和纯黑区域都是构图的一部分。

远看时首先读到强烈剪影和主体关系；
近看时再发现排线、点描、材质、空间和隐藏细节。

【文字】
标题、主题和核心意思用于指导画面设计，但不默认出现在图片中。

如果输出模式为“纯图”：
画面中不要出现任何文字、字母、数字、标签、页码、品牌、Logo、图注或无意义字符。

如果输出模式为“完整标题”：
只显示准确标题：
“{{标题}}”

如果填写了副标题，可同时显示：
“{{副标题}}”

不要生成其他文字。

如果输出模式为“核心标题”：
从标题中保留最重要、最短的一段核心文字，保持含义准确。

如果输出模式为“预留文字区”：
不要渲染标题，在构图中主动留下干净、低纹理、具有足够对比度的文字区域。

需要文字时，采用克制的复古编辑排版或传统版画刻印文字风格。

文字必须：
清晰可读，
拼写准确，
不被主体遮挡，
不被复杂排线干扰，
不产生乱码或伪文字。

【整体气质】
画面应具有：
克制，
深邃，
神秘，
理性，
思想性，
轻微超现实感。

再根据 {{情绪}} 调整整体空间、尺度和明暗关系。

最终气质介于：
十九世纪科学版画、
哲学书籍插图、
高质量编辑插画、
超现实艺术作品之间。

它可以表达现代科技、未来、社会、哲学或抽象概念，但视觉语言始终属于传统黑白版画。

【必须避免】
不要彩色、棕褐色调、局部染色、霓虹或彩色光源。

不要平滑数字渐变、空气刷、CGI 金属反射、塑料质感或现代 3D 渲染感。

不要水彩、油画厚涂、彩铅、卡通、动漫、扁平矢量或漫画式粗黑描边。

不要普通 AI 概念图、廉价赛博朋克视觉或商业素材库风格。

不要同时堆叠多个无关象征物。

不要出现多个同等权重的主角。

不要为了表现“科技”“智慧”“未来”等抽象概念而自动添加常见符号。

不要加入 {{避免元素}}。

【最终检查】
最终只生成一张独立完整封面，不要生成拼图、联系表、网格、样机、设计过程或多个候选方案。

成图必须同时满足：

一个明确的视觉中心；
一个主要核心隐喻；
远看清晰有力的黑白轮廓；
强烈但有秩序的黑白对比；
真实细密的蚀刻排线和点描；
主体区域丰富、次要区域克制的信息密度；
清楚的空间层次；
足够的留白或纯黑呼吸区；
近看具有值得观察的手工雕刻细节。

最终效果应像一位版画艺术家针对文章主题认真构思并手工雕刻完成的编辑封面，而不是将标题关键词逐项拼贴成一张图片。
`````
