# 马卡龙纸张手绘知识图解

![预览图](preview.webp)

## Prompt

```text
创作一张横向 16:9 的手绘知识信息图。

整体采用轻松、亲切、清晰的“纸上手绘笔记”视觉风格，
像用黑色马克笔、彩色荧光笔和淡彩颜料，
在一本暖米白色的厚纸笔记本上手工绘制完成。

【整体视觉】

背景为柔和的暖米白、浅奶油色纸张，
不是纯白数字画布。
保留非常轻微的真实纸张颗粒和自然纹理，
整体干净、温暖、低对比度、大量留白。

所有主要轮廓使用黑色手绘马克笔线条。
线条清晰但不要机械笔直，
粗细存在轻微变化，
边缘带少量自然抖动，
圆角、箭头、图标和下划线都保留真实手绘感。

不要追求矢量图绝对规整，
而要像设计师在纸上认真绘制的信息图草稿。

【配色】

使用柔和、低饱和的马卡龙配色：

- 薄荷绿
- 淡青绿色
- 天空浅蓝
- 奶油黄色
- 柔和杏橙色

颜色只用于模块背景、编号、旗帜、圆形节点和少量重点标记。

彩色区域呈现淡淡的手工涂抹感，
边缘略有不均匀，
可以出现非常轻微的水彩或马克笔填色纹理。

避免高饱和颜色和强烈渐变。

【版式结构】

采用简洁的知识信息图布局。

顶部放置一个醒目的中文主标题，
居中或略偏左，
使用粗黑色手写马克笔字体。

主标题下方可加入一条简单的黑色手绘横线，
标题两侧可以点缀少量短线、放射线或强调符号。

主体区域根据内容自动选择最合适的结构，例如：

1. 左侧核心节点 → 右侧多个内容卡片
2. 三列并排知识卡片
3. 横向时间轴 / 阶段路线图
4. 中心概念 → 多个分支模块

不要机械套用固定模板，
根据知识关系选择最容易理解的视觉结构。

主体通常由 3～5 个信息模块组成。

每个模块使用：
柔和马卡龙色背景 +
黑色手绘圆角边框 +
简短标题 +
1～3 行说明 +
一个简单的手绘线性图标。

模块之间保持明显间距和留白。

【卡片】

卡片使用大圆角矩形，
轮廓为黑色手绘线条。

圆角不要完全几何规则，
保持轻微手工绘制的不对称感。

卡片内部信息层级清楚：

模块标题 > 简短说明 > 辅助文字。

不要塞入大段文字。

【图标】

使用极简黑色手绘线性图标，
类似课堂笔记中的小涂鸦。

可以根据主题自动选择：

火箭、
扳手、
代码符号、
文件、
信封、
报纸、
拼图、
火焰、
幼苗、
鞋子、
灯泡、
放大镜、
人物、
箭头、
电脑、
数据库、
齿轮等。

图标保持简单，
由少量黑色线条构成，
与整张图片的手绘笔触完全一致。

图标附近可以加入 2～5 条短小放射线，
增强“手绘重点标记”的感觉。

【连接关系】

不同模块之间使用简单黑色手绘箭头、
曲线、
水平时间线或短连接线连接。

箭头线条自然流畅，
略有弯曲，
不要使用标准化流程图连接器。

如果是时间轴，
使用一根横向黑色手绘主线，
阶段节点使用不同马卡龙颜色区分。

【文字风格】

所有中文文字都采用自然、清楚、略带随手书写感的黑色手写字体。

主标题：
粗黑、醒目、字号最大。

模块标题：
黑色粗手写字，
可放在浅色手绘标签或白色小底块上。

正文：
稍细的手写字，
字距自然，
保持高度可读。

少量英文或数字可以采用简洁的英文手写体，
与中文风格统一。

需要清晰准确的文字渲染，
保证中文标题、标签和短句完整、可辨认。

如果用户提供明确文案，
严格按照用户提供的文字生成，
不要自行改写关键标题。

【底部】

画面底部可以加入一句简短总结、行动建议或口号。

文字居中，
使用稍大的黑色手写字体。

可以搭配：
手绘下划线、
小图标、
几条短放射线，
形成轻量级视觉收尾。

【整体气质】

像一位擅长知识整理的设计师，
用马克笔和彩色淡笔，
在米白色纸张上快速绘制出的知识笔记。

视觉感觉：

清楚，
友好，
轻松，
有人工温度，
信息层级明确，
容易快速阅读，
略带学习笔记和创作者工作手册的感觉。

保持中低信息密度，
重点突出，
避免过度装饰。

不要使用：
照片写实风格、
3D 渲染、
玻璃拟态、
复杂阴影、
金属质感、
霓虹灯、
高饱和渐变、
标准企业 PPT 风格、
过度规整的矢量图形、
密集小字、
复杂背景。

最终效果应像：
“暖米白纸张上的马卡龙手绘知识信息图”，
黑色马克笔线条 + 柔和色块 + 清晰手写文字 + 简单涂鸦图标 + 大量自然留白。
```
