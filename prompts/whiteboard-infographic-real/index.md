# 白板手绘知识图解

![预览图](preview.webp)

## Prompt

```text
围绕用户提供的主题，创作一张“真实办公白板 × 马克笔手绘 × 知识讲解信息图”风格的画面，像一位产品经理或工程师在会议室白板上亲手完成的视觉笔记。

【输入】
主题 / 主标题：{{主题}}
核心观点：{{一句话说明真正想表达的判断}}
副标题：{{副标题，可留空}}
核心关系：{{对比 / 流程 / 因果 / 演进 / 拆解，可留空}}
关键维度：{{2–5 个短词}}
最终结论：{{一个短句，可留空}}
画幅比例：{{默认 16:9}}
语言：{{中文 / 英文 / 中英混排}}
用途：{{文章封面 / 公众号配图 / 知识图解 / 技术说明 / 商业观点图}}

【核心视觉结构】
使用一整块真实白板作为画布，顶部放置醒目的手写主标题。
根据主题自然划分 2–4 个知识区域，可使用虚线、箭头、框线形成阅读路径。
每个区域组合短文字、简单图表、流程箭头、卡片、代码框、人物小漫画或象征性物件。
核心观点放在视觉中心或底部，以较大的手写文字形成最终落点。
信息呈现有明确层级，同时保留真实白板笔记的自由布局感。

【核心原则】
所有内容都像直接用马克笔画在白板上，文字、框线和图形保留轻微歪斜、粗细变化与手写痕迹。
插画采用简单黑色线稿，表情生动但不过度卡通化；图表和流程图保持容易理解。
文字以短标题、关键词和简短说明为主，避免大段正文。
根据主题自动选择最适合的视觉隐喻，不固定复刻任何人物、图表或版式。
整体具有人工思考和现场讲解感，避免数字排版过度规整。

【主色系统】
白色白板为主体，黑色马克笔承担主要文字与线稿。
使用红、蓝、绿中的 2–3 种颜色作为辅助标记，用于标题、箭头、强调词和重点框线。
颜色面积克制，不使用大面积填色、渐变或高饱和背景。

【风格总基调】
真实会议室白板摄影质感，轻微透视、自然室内光线和细微反光。
手写中文清晰可读，马克笔墨迹自然，有轻微笔锋、停顿和不均匀感。
画面信息丰富但不拥挤，具有技术讨论、产品评审、课堂讲解和视觉笔记的现场感。
不要数字矢量插画感、印刷海报感、精致 UI 卡片感、3D 渲染、复杂装饰或过度艺术化背景。
```
