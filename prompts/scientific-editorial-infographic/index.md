# 科研编辑风知识信息图
![预览图](preview.webp)

## Prompt

```text
围绕用户提供的主题，创作一张“科研论文拆解 × 编辑排版 × 极简信息图”风格的知识海报。

【输入】
主题 / 主标题：{{主题}}
一句话结论：{{这张图真正想表达的核心判断}}
副标题：{{可留空}}
内容模块：{{3–5 个模块，如：背景 / 问题 / 方法 / 数据 / 结果}}
关键数据：{{样本量、百分比、提升幅度、对比数字等，可留空}}
关键术语：{{2–6 个短词，可留空}}
逻辑关系：{{例如：问题 → 拆解 → 方法 → 结果，可留空}}
页码：{{例如 01/01，可留空}}
语言：{{中文 / 英文 / 中英混排}}
用途：{{文章封面 / 公众号配图 / 论文解读图 / 研究摘要图 / 知识卡片}}
画幅比例：{{默认 16:9}}
可选气质：{{理性 / 克制 / 学术 / 未来 / 高级 / 研究}}
可选禁用元素：{{不想出现的元素，可留空}}

【核心视觉结构】
采用严格、清晰、稳定的网格化编辑排版。整张图应像单页研究信息图，而不是商业广告、PPT 页面或手绘海报。

推荐结构如下：
1. 顶部信息栏  
   左上角放很小的栏目标签，使用大写英文或中英混排的小字，例如：PAPER DECODE / WHY IT MATTERS / METHOD / RESULTS / INSIGHT。  
   标签前可配一个很小的橙色方块或短横线，作为系列识别元素。

2. 主标题区  
   使用大字号、左对齐、理性无衬线字体。  
   标题允许分 2–4 行，整体疏朗。  
   标题中的 1–3 个关键词可使用橙色强调，其余保持黑灰色。

3. 导语区  
   在标题下方加入 1–3 行简短说明，概括主题背景或核心问题。  
   文案不宜过长，要像编辑摘要。

4. 主内容区  
   根据内容自动组织成以下一种或多种模块：
   - 数据卡片
   - 编号要点列表（01 / 02 / 03）
   - 柱状对比图
   - 阶段流程图
   - 方法框架图
   - 对比矩阵
   - 简单结构示意
   - 指标结论块

   各模块之间要有明确留白与边界，不要拥挤。

5. 核心结论横条  
   在页面中下部或底部设置一条黑底信息条。  
   左侧可放一个橙色小标签，如 CORE / INSIGHT / WHY / TAKEAWAY。  
   右侧用白字写一句简洁有力的总结。

6. 页脚区  
   左下角放细小辅助说明文字，可像栏目名、主题分类或小型注释。  
   右下角放醒目的橙色页码或编号，例如 01/01、03/05。

【核心原则】
- 不追求花哨，而追求“编辑感、研究感、秩序感”。
- 信息密度中等偏高，但必须清楚、整洁、可读。
- 重点靠字号、粗细、色彩和留白区分，不依赖阴影和装饰。
- 每一块内容都应像经过编辑整理，而不是随意堆字。
- 版式以左对齐为主，避免居中排满全画面。
- 整体应像“研究论文拆解图”“科技媒体深度解读卡片”。

【版式风格】
整体参考现代编辑设计与瑞士网格系统：
- 严格网格
- 非对称留白
- 强调对齐
- 清晰层级
- 模块化信息块
- 精准、理性、克制

画面应该有一种“学术内容被编辑得很好看”的感觉。

【背景与材质】
背景为暖白、米白或极浅灰白纸面。  
可带非常轻微的工程网格纸 / 方格纸纹理，但一定要淡，不能喧宾夺主。  
整体像高质量印刷纸张，干净、平整、克制，允许极轻微纸张质感。

【主色系统】
采用少量固定配色，整体克制：
- 背景：暖白 / 米白 / 浅象牙白
- 主文字：炭黑 / 深灰
- 辅助文字：浅灰 / 中灰
- 强调色：明亮橙色 / 珊瑚橙 / 轻微荧光橙
- 局部辅助底色：极浅粉灰 / 极浅暖灰

整体颜色占比建议：
- 75%–85% 浅背景
- 10%–20% 黑灰文字与线条
- 5%–10% 橙色强调

禁止使用大量彩色、蓝紫渐变、霓虹特效。

【字体与文字气质】
使用现代、理性、干净的无衬线字体风格。  
中文接近科技媒体常用黑体气质，英文接近 Helvetica / Inter / Univers / Neue Haas 一类中性编辑字体。  
可局部搭配极细字重、小型大写英文、数字编号，增强“研究资料”感。  
不要使用手写体、书法体、卡通字体或过于圆润可爱的字体。

【图形语言】
使用简洁的二维信息图形语言：
- 细线
- 几何分隔
- 规则矩形模块
- 干净柱状图
- 简洁箭头
- 轻量结构图
- 极简表格
- 数字指标卡

图表要“解释观点”，不是追求复杂统计可视化。  
图形和文本要服务核心结论。

【风格总基调】
理性、克制、学术、编辑化、现代、清爽、高级。  
像一页来自 AI 研究解读专栏、科技杂志、实验室简报、论文拆解系列的高质量版面。  
视觉吸引力来自：
- 清晰的信息层级
- 温和的纸面背景
- 橙色重点词
- 稳定的网格结构
- 研究感和编辑感

【避免】
不要做成手绘风
不要做成普通 PPT
不要做成商业营销海报
不要加入卡通插画人物
不要使用 3D 炫光、玻璃拟态、液态金属、霓虹赛博朋克
不要使用花哨贴纸、表情符号、大面积渐变
不要把所有内容塞满整页
不要把背景网格做得太重
不要让图表过于复杂难读
不要出现明显“拼接五张图”的版式效果

【输出要求】
生成的是“一张同类风格的新信息图”，
不是对参考图内容或五联拼接结构的一比一复刻。
应保留这类风格的核心特征：
暖白网格背景、黑灰正文、橙色强调、科研编辑排版、模块化信息结构、清晰页码、理性科技杂志气质。
```
