# 白板手绘知识图解

![预览图](preview.webp)

## Prompt

```text
围绕用户提供的主题，创作一张“暖米白纸张底 × 极简手绘线稿 × 低饱和蓝绿点缀 × 流程式知识图解”的横版封面。

这不是写实插画，也不是复杂海报，而是一张具有白板手绘感、纸张纹理感和知识图解气质的封面图。
整体像：极简手绘信息图、轻教程式流程海报、友好型知识卡片、产品方法论插画。

【输入】
主题 / 主标题：{{主题}}
核心观点：{{一句话说明真正想表达的判断}}
副标题：{{副标题，可留空}}
核心关系：{{例如：输入 → 提炼 → 结构化 → 输出 / 问题 → 分析 → 方案 → 结果，可留空}}
关键维度：{{2–4 个短词，可留空}}
最终结果：{{一个短词或短句，可留空}}
画幅比例：{{默认 16:9}}
语言：{{中文 / 英文 / 中英混排}}
用途：{{文章封面 / 公众号封面 / 报告题图 / 商业观点图 / 知识卡片}}
可选情绪倾向：{{理性 / 友好 / 清晰 / 轻松 / 专注 / 入门 / 方法论}}
可选禁用元素：{{不想出现的元素，可留空}}

【核心视觉结构】

采用“左侧标题 + 右侧图解主体”的稳定横版构图。

1. 左侧标题区
- 左侧预留约 30%–38% 的留白区域，放置主标题。
- 标题使用与画面一致的手绘编辑风格，字形清晰，醒目，略带手写海报感。
- 主标题建议分 2–4 行排版，整体左对齐或居中偏左，避免过度拥挤。
- 如有副标题，放在主标题下方，字号更小，作为补充说明。
- 标题区保持干净，不堆叠过多图标和说明文字。

2. 右侧图解主体区
- 右侧约 62%–70% 区域承载核心图解内容。
- 根据主题构建“流程式 / 结构式 / 步骤式”手绘信息图。
- 可以包含：简笔人物、小卡片、文档纸片、箭头、流程框、看板、放大镜、清单、图表、对勾、灯泡、文件堆、小宠物或辅助小角色等。
- 元素之间要有明确层级：问题素材 → 分析整理 → 结构组织 → 清晰结果。
- 构图重点是“看一眼就能明白过程”，而不是做满屏装饰。

3. 信息组织方式
- 顶部或中上部可放一条简洁流程链条，用 3–5 个步骤框表示核心过程。
- 中部和下部用人物小场景来辅助解释流程。
- 每个步骤可搭配简单图标或小插画，增强理解。
- 保持“上方概括、下方展开”的知识图解逻辑。

【核心原则】

1. 风格优先级
版式清晰 > 信息可读 > 手绘亲和力 > 细节趣味 > 装饰性。

2. 画面气质
整体要友好、清楚、轻松、理性，有“把复杂问题讲明白”的感觉。
像教程封面、方法论图解、知识博主配图，而不是商业广告。

3. 手绘语言
所有主体都采用统一的黑色细线或略粗线条勾勒。
线条略有手工感，但不要潦草，不要儿童涂鸦化。
人物与道具都尽量简化，轮廓圆润，易读，轻松可爱。

4. 元素复杂度
元素数量适中，中低信息密度。
允许出现多个对象，但每个对象都要简洁，不要过度写实。
避免复杂透视、复杂背景、复杂材质和密集小字。

5. 文本控制
只保留必要的标题、步骤词、少量关键词。
避免大段说明文字。
所有中文必须清晰、正确、完整，优先保证可读性。

【主色系统】

整体颜色克制，采用“黑线稿 + 暖纸底 + 低饱和蓝绿点缀”的配色结构。

1. 背景色
- 暖米白
- 浅奶油白
- 略带纸张纹理的淡米色
整体像轻微纹理纸、手账纸、白板纸。

2. 线条色
- 黑色
- 深灰黑
用于人物轮廓、边框、箭头、结构线和小图标。

3. 主点缀色
- 柔和蓝色
- 低饱和草绿色
主要用于卡片底色、流程框、文件、图表和局部重点。

4. 辅助强调色
- 少量暖黄色或浅橙色
用于灵感、小强调点、轻提示元素。
强调色占比要很少，只作点睛。

5. 配色原则
- 整体颜色不超过 4–5 种主要色。
- 以留白和浅底为主，色块只是辅助信息分组。
- 避免高饱和霓虹色、渐变科技蓝、厚重阴影和强对比。

【风格总基调】

整体风格应接近：
- 白板手绘知识图解
- 极简教程式流程插画
- 纸张质感的知识型封面
- 低饱和、友好、清楚的博文配图
- 轻量化的信息整理视觉

视觉特征包括：
- 暖米白纸张背景，带细微颗粒感
- 黑色手绘轮廓线，统一且简洁
- 蓝色、绿色作为主要信息色块
- 人物是简笔卡通风，圆头、细肢体、表情简洁友好
- 文档、卡片、图表、流程框都有轻微手绘边缘和纸片感
- 箭头清晰，步骤结构明确
- 整体像在“把复杂内容整理成人人看得懂的图解”

【细节要求】

- 可以有轻微纸张纹理、轻微铅笔或马克笔质感，但不要脏乱。
- 可加入少量拟人化或温和趣味元素，提高亲和力。
- 图标和角色要统一风格，不要混入写实图标或 3D 元素。
- 保持大量留白，让画面呼吸感足够。
- 右侧主体虽然丰富，但不能显得拥挤。

【避免事项】

不要做成：
- 写实场景插画
- 复杂商务 PPT
- 赛博朋克科技风
- 玻璃拟态 UI
- 高饱和卡通海报
- 儿童绘本风厚涂
- 纯图标拼贴没有叙事逻辑
- 满屏大段文字说明

【最终效果】

最终应呈现为一张适合公众号、博客或知识内容封面的白板手绘图解：
左侧是清晰的主题标题，
右侧是用手绘人物、文件纸片、流程框、箭头和简洁结构组成的知识图解主体，
整体干净、亲和、可读、易懂、低压、有方法论感。
```
