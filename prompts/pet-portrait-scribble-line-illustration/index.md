# 宠物手绘肖像指南

![预览图](preview.webp)

## Prompt

```text
基于我上传的宠物照片，创作一张“凌乱打圈线条轮廓风”宠物手绘插画。

整体画面是：
干净白底，
主体居中或略偏中，
保留充足留白，
只保留宠物主体，
不出现背景场景、家具、室内环境、道具杂物或其他干扰元素。

最终效果要像一张高级、轻盈、有纪念感的宠物手绘肖像，
而不是照片滤镜、写实绘画或普通卡通贴纸。

【输入】
上传照片：{{上传宠物照片}}
宠物名字：{{宠物名}}
画幅比例：{{画幅比例，例如 4:5 / 1:1 / 3:4}}

【核心目标】
准确保留照片中宠物的核心识别特征，
让人一眼看出就是这只宠物。

重点保留：
- 宠物品种
- 体型
- 毛量
- 耳朵形状
- 脸型
- 眼神
- 毛色分布
- 鼻子特征
- 嘴巴状态
- 尾巴姿态
- 爪子状态
- 最有辨识度的动作和神态

如果原照片中有明显动作，例如：
张嘴、
吐舌、
抬爪、
趴着、
坐着、
尾巴上扬、
侧头、
发呆、
警觉、
卖萌，
都要尽量保留。

不要把它画成泛泛的卡通动物，
要保留“这只宠物本人”的神态和气质。

【画风】
整体采用：
蜡笔、
彩色铅笔、
粗略手绘
混合质感。

线条是画面主角。

轮廓必须由大量松散、重复、轻微错位、打圈式、潦草感的手绘线条组成，
像随手画出来的草稿线，
而不是工整、干净、封闭的一次性描边。

线条特征包括：
- 凌乱打圈轮廓
- 重复描线
- 轻微错位
- 手工抖动感
- 松散边缘
- 草稿感结构线
- 局部线条疏密变化
- 不完全闭合的轮廓

整体应显得自然、轻松、有观察感，
像插画师用很少控制、很多感受去抓住宠物的样子。

【上色方式】
颜色不要铺得很满，
不要完整填色，
不要做成厚涂。

使用轻薄、跳跃、稀疏的彩铅 / 蜡笔笔触来表达颜色。

让大面积白色纸面自然露出来，
形成：
轻盈感、
透气感、
未完成感、
高级感。

上色逻辑：
- 毛色用松散、稀疏、轻量的线条和色块表现
- 黑色、灰色、棕色、白色、奶油色等毛色，要根据原照片真实分布进行轻量转译
- 眼睛、鼻子、舌头、耳朵内侧、爪垫等局部可以用更明确一些的颜色点亮
- 色彩关系要忠于原照片，但表达方式必须是手绘化、轻量化的

可以保留可见笔触方向、留白缝隙、颜色不均和边缘溢出，
但整体仍需控制得当，不要脏乱。

【构图】
宠物主体完整、清晰、有识别度。

构图以单一主体为核心：
- 主体居中或略偏中
- 保留足够白底留白
- 让宠物成为唯一视觉焦点

画面可以略微夸张宠物最可爱的特征，例如：
- 更有神的大眼睛
- 更蓬松的毛
- 更有记忆点的耳朵
- 更可爱的舌头
- 更软萌的爪子
- 更有表情的脸部轮廓

但夸张必须建立在原照片基础上，
不能把宠物变成完全不同的动物。

整体更接近“高级签名头像”或“纪念肖像插画”，
不是儿童卡通海报。

【背景】
背景必须是纯净白底。

不要添加：
- 家具
- 地板
- 沙发
- 窗户
- 室内结构
- 户外风景
- 玩具
- 食物
- 碗
- 笼子
- 文字气泡
- 装饰图案
- 任何与主体无关的物件

背景的作用只是留白和衬托主体。

【文字】
在画面右下角添加宠物名字：
“{{宠物名}}”

文字要求：
- 使用手写感字体
- 像铅笔或蜡笔随手签名
- 小巧、自然、克制
- 不抢主体
- 颜色使用深灰、黑色，或与宠物局部颜色呼应的淡色
- 可以加一条很随意的短下划线
- 不要过度装饰
- 不要做成商业标题或贴纸文字

【质感】
整体必须具有真实手绘痕迹：
- 彩铅颗粒
- 蜡笔摩擦感
- 粗略轮廓
- 反复描线
- 颜色不均匀
- 局部出界
- 白纸自然露出
- 非机械化边缘
- 轻松、灵动、未完成但成立的手绘效果

整体观感应当：
干净、
可爱、
高级、
轻松、
有纪念感、
有温度。

【风格关键词】
pet portrait illustration,
scribble contour lines,
messy looping sketch lines,
colored pencil texture,
crayon texture,
white background,
minimal composition,
airy unfinished coloring,
hand-drawn pet portrait,
clean memorial pet illustration

【必须避免】
不要真实摄影风。
不要照片滤镜感。
不要厚重涂色。
不要写实油画感。
不要复杂背景场景。
不要家具和室内环境。
不要道具杂物。
不要复杂装饰。
不要卡通贴纸感。
不要矢量扁平风。
不要过度精修。
不要把颜色铺满。
不要让线条太干净。
不要做成封闭整齐轮廓。
不要做成普通可爱头像模板。
不要把宠物画成完全不同的动物。

【生成前检查】
生成前请确保：
- 主体只有宠物本身
- 白底干净
- 宠物核心特征被准确保留
- 姿态和神态与原照片一致
- 轮廓线是凌乱、打圈、重复、潦草的手绘线
- 颜色是轻薄、稀疏、跳跃的
- 大量白色纸面保留可见
- 整体是手绘插画，不是数码精修
- 宠物名字已在右下角自然加入
- 画面有纪念感和高级感

【最终标准】
最终只生成一张独立完整插画。

成图必须同时满足：
- 宠物一眼可识别
- 白底留白充足
- 主体清晰完整
- 线条凌乱、潦草、打圈式
- 上色轻薄、透气、不铺满
- 毛色与五官特征准确
- 整体轻盈、有手绘痕迹
- 右下角有手写感宠物名字
- 干净、可爱、有纪念感

最终效果要像：
一张由插画师用彩铅和蜡笔快速但准确画出的宠物肖像，
既松弛随性，又足够传神，
适合作为收藏型、高级感的宠物手绘纪念画。
```
