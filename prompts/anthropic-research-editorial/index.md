# Anthropic Research 风格研究编辑封面

![预览图](preview.webp)

## Prompt

```text
请根据下面的用户输入，创作一张具有「AI 研究实验室研究报告 / 设计研究手册」气质的极简编辑视觉封面。

整体视觉可以参考 Anthropic Research 一类研究型编辑设计的审美方向，但只提取其抽象设计语言：

纯色背景，
大面积留白，
高对比衬线标题，
极简手绘概念隐喻，
少量低饱和装饰色块，
研究出版物般的理性与人文感。

不要复制 Anthropic 的 Logo、字标、品牌署名、官网组件、固定版式或具体官方视觉资产。

────────────────

【用户输入】

主题：
{{填写内容主题}}

主标题：
{{填写需要准确显示的主标题}}

副标题：
{{可留空；如填写，最多显示一行}}

核心表达：
{{用一句话说明这个主题真正想表达的价值、关系、矛盾或观点}}

画幅比例：
{{5:2 / 16:9 / 4:5 / 3:4 / 9:16 / 其他}}

用途：
{{X 封面 / 文章封面 / 产品介绍 / 教程海报 / 其他}}

背景方案：
{{A 陶土橙 / B 深黑 / C 暖灰 / D 鼠尾草绿 / E 雾霾蓝；未指定使用 A}}

强调色：
{{不使用 / 陶土橙 / 鼠尾草绿 / 雾霾蓝 / 其他低饱和单色}}

不想出现的元素：
{{可留空}}

────────────────

【设计目标】

画面应像：

AI 研究机构发布的一页研究报告，
独立研究杂志封面，
概念设计手册，
或具有思想性的学术编辑视觉。

整体感觉：

克制，
理性，
安静，
具有思辨性，
带少量人文手工感，
但保持现代和专业。

不要做成：

商业营销海报，
科技产品发布会，
PPT 模板，
赛博朋克海报，
复杂信息图，
未来科技 UI。

画面只围绕三个核心元素建立：

一个主标题，
一个核心视觉隐喻，
大面积留白。

保持单一、明确的视觉中心。

────────────────

【背景颜色】

整张图只选择一个纯色背景方案。

如果用户没有指定，默认使用方案 A。

方案 A：
背景 #D97757
主要文字与线稿 #1A1A1A

方案 B：
背景 #1A1A1A
主要文字与线稿 #EFEAE0

方案 C：
背景 #D8D5CF
主要文字与线稿 #1A1A1A

方案 D：
背景 #B8C9B8
主要文字与线稿 #1A1A1A

方案 E：
背景 #8FA9C7
主要文字与线稿 #1A1A1A

背景保持完整的大面积纯色。

不要渐变。
不要纹理背景。
不要霓虹。
不要发光。
不要数字网格。
不要科技蓝光。
不要随机噪点填满背景。

────────────────

【文字】

只显示用户明确提供的文字。

主标题必须准确呈现用户填写的原文：

不要改写，
不要翻译，
不要补充标语，
不要自动增加英文，
不要添加日期，
不要添加页码，
不要添加栏目标签，
不要添加网址，
不要添加署名，
不要添加品牌名称。

如果用户没有填写副标题，则不要生成副标题。

如果填写了副标题：

最多保留一行，
字号明显小于主标题，
放置在主标题附近的留白区域，
保持克制。

────────────────

【字体与排版】

主标题是第一视觉元素，同时承担画面的主要结构作用。

使用具有研究出版物气质的高对比衬线字体。

字体感觉可参考：

Source Han Serif 一类现代中文衬线字体，
Georgia 一类经典衬线字体，
研究杂志与书籍标题的排印气质。

重点是：

清晰，
稳重，
有书籍感，
有编辑感，
具有明显粗细对比。

不要复制具体品牌字体资产。

辅助文字使用简洁现代的无衬线字体，
类似 Inter 的理性气质。

如果确实存在非常少量结构性文字，
可以使用类似 JetBrains Mono 的等宽字体气质，
但不要把等宽字体作为主要风格。

避免同时使用过多字体。

不要把标题处理成：

商业广告口号，
发布会大字报，
霓虹文字，
3D 字体，
描边字体，
金属字体，
复杂渐变字。

────────────────

【版式】

根据用户指定的画幅比例重新组织构图。

不要固定套用同一模板。

主标题通常位于：

左侧，
左上，
偏中心，
或与抽象隐喻形成明显空间关系的位置。

不要机械居中。

标题、核心隐喻与留白共同构成一个整体视觉中心。

保持大量空白区域。

重要元素不要贴边。

画面可以明显不对称，
但整体视觉重量必须平衡。

如果画幅较宽：

可以让标题占据一侧，
抽象隐喻位于另一侧或进入中央空间。

如果画幅较高：

可以让标题位于上部或中上部，
抽象隐喻进入下部或侧下方区域。

如果是方形：

可以使用偏心式编辑构图，
不要默认居中海报模板。

────────────────

【核心视觉隐喻】

根据：

主题
+
核心表达

先理解这个主题真正要讨论的：

关系，
冲突，
过程，
边界，
变化，
连接，
分离，
聚合，
扩散，
限制，
选择，
认知，
反馈，
层级，
方向，
或其他抽象概念。

然后只设计一个主要视觉隐喻。

不要直接把主题名词画出来。

视觉隐喻可以使用：

极简手绘线稿，
抽象人物轮廓，
节点，
路径，
连接线，
边界，
空间关系，
纸张结构，
框架，
容器，
断裂，
交叉，
汇聚，
发散，
嵌套，
重复结构，
简单几何关系，
少量概念符号。

视觉应该让观众先感受到「关系与思想」，
而不是看到一个主题名词的普通图标。

────────────────

【主题转译原则】

如果主题是 AI：

不要画机器人，
不要画机械脑，
不要默认画芯片。

可以通过：

人类轮廓，
认知节点，
思考路径，
多个智能体之间的关系，
人和系统之间的空间关系，
信息流动，

来表达。

如果主题是网页或互联网：

不要默认画电脑、显示器或浏览器截图。

可以把：

页面，
数字空间，
模块，
链接，
入口，
信息层级，

转译为空间结构或抽象关系。

如果主题是知识：

不要画书堆、灯泡或毕业帽。

可以使用：

节点汇聚，
层级结构，
关联路径，
信息片段形成整体，
局部与整体关系，

来表达。

如果主题是协作：

不要简单画握手。

可以使用多个形体、路径或节点之间的协调关系。

如果主题是限制：

可以通过边界、容器、阻隔、穿越或压缩关系表达。

如果主题是增长：

不要直接画上升箭头。

可以通过扩张、分叉、延展、层级变化来表达。

对于其他主题也遵循同样原则：

先理解核心表达，
再寻找视觉关系，
不要把名词直接转成图标。

────────────────

【手绘语言】

核心隐喻采用极简手绘插画语言。

线条应：

简单，
自然，
略带手工痕迹，
但保持编辑设计的精确感。

不要复杂排线。

不要写实素描。

不要儿童涂鸦。

不要大量不规则乱线。

不要追求摄影真实。

插画应更像：

研究者在纸面留下的概念草图，
设计研究中的视觉注释，
或独立杂志中的概念插画。

线稿默认使用：

#1A1A1A

在深色背景中使用：

#EFEAE0

────────────────

【装饰元素】

允许加入 2–4 个小型无功能装饰色块。

装饰元素只用于平衡画面，
不承担信息解释作用。

总面积不要超过整张画面的约 5%。

可以使用：

不规则有机色块，
手绘圆形，
小矩形，
纸张碎片形，
简单几何切片。

装饰元素不要平均分布。

不要形成规则阵列。

不要像 UI 按钮。

不要做成图标列表。

不要制造大量散点。

装饰色可从以下颜色中选择：

#EFEAE0
#CD6F47
#6B8A6F
#8FA9C7
#1A1A1A

如果用户指定强调色，则优先使用用户指定颜色。

除背景、文字和基础线稿色外，
最多只使用一个主要强调色。

强调色保持低饱和。

────────────────

【图文关系】

标题和视觉隐喻必须产生明确关系。

不要出现：

标题在左边，
无关插画在右边，

这种简单拼贴关系。

隐喻元素可以：

靠近标题，
从标题附近延伸，
与标题形成方向关系，
穿过标题周围的空间，
包围某些文字区域，
回应标题的基线或边缘。

但不要遮挡文字。

不要降低文字可读性。

装饰色块只负责填补视觉重量，
不能成为第二视觉主体。

────────────────

【最终视觉效果】

最终画面应该呈现：

一个固定纯色背景
+
一个高对比衬线主标题
+
最多一行副标题
+
一个抽象手绘核心隐喻
+
2–4 个极少量装饰色块
+
大量留白。

整体具有：

研究报告感，
独立出版物感，
设计研究手册感，
知识型编辑设计感，
轻微人文气质，
克制的实验性。

视觉上应该显得经过思考，
而不是经过大量装饰。

────────────────

【生成前内部检查】

生成最终画面前，检查：

是否只有一个主标题；

是否最多只有一行副标题；

是否只有一个核心视觉隐喻；

是否只有一个主要视觉中心；

是否只使用一个纯色背景；

是否保留了大量留白；

是否只有 2–4 个小型装饰元素；

装饰元素总面积是否控制在约 5% 以内；

是否没有添加用户未提供的文字；

是否没有 Logo、品牌署名、页码、日期或网址；

是否把主题转译成了关系或隐喻，而不是直接画主题名词；

是否避免复杂信息图；

是否避免 3D；

是否避免渐变；

是否避免霓虹；

是否避免科技蓝光；

是否避免商业模板感。

────────────────

【避免】

不要复制 Anthropic 的 Logo、字标、品牌署名、官网组件或固定官方版式；

不要科技发布会视觉；

不要商业营销海报；

不要 PPT 封面模板；

不要赛博朋克；

不要机器人；

不要普通电脑；

不要书堆；

不要灯泡；

不要随机芯片；

不要随机电路；

不要无关实验器材；

不要复杂信息图；

不要数据仪表盘；

不要大量文字；

不要 3D 渲染；

不要玻璃拟态；

不要渐变；

不要霓虹；

不要科技蓝光；

不要复杂纹理；

不要多种强调色；

不要均匀装饰阵列；

不要 UI 按钮式元素；

不要大量散点；

不要无意义英文；

不要未经用户提供的品牌标识。
```
