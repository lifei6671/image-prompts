# 像素风头像生成器

![预览图](preview.webp)

## Prompt

```text
根据用户上传的图片，生成一张“抽象重构型复古像素风头像”。

不要写实复制，不要做 1:1 像素化还原，也不要保留原图场景。先识别图中主体最有辨识度、最有记忆点的 3–5 个关键特征，再将这些特征重新设计成一个独立的像素头像角色。

适用对象不限：人物、宠物、玩具、食物、物品、交通工具、植物、动物或任何明确主体都可以转化为像素头像。

【核心目标】
这不是把原图“打像素滤镜”。
这是一次“基于识别特征的像素角色重设计”。

最终成品应像：
复古游戏角色头像、
像素 IP 角色头像、
社交媒体像素头像、
带商业感的像素角色图标。

它不是：
原图缩小版、
像素照片、
场景截图、
普通动漫头像、
写实风插画。

【输入】
上传图片：{{上传图片}}

【主体识别】
先从原图中提取 3–5 个最关键的识别特征。优先抓取最容易让人一眼记住的视觉特征，例如：

人物：
发型、脸型、眼镜、帽子、表情、耳饰、胡子、服装特征、配色、道具。

宠物或动物：
耳朵、毛色分区、尾巴、花纹、脸型、眼神、身体轮廓、姿态。

物体或玩具：
整体轮廓、配色分区、结构特征、按钮、图案、边缘造型、标志性局部。

植物或食物：
外轮廓、叶片或花瓣形状、表面纹理、颜色层次、最明显的结构特征。

交通工具或器械：
车头、轮廓、灯、窗、武器结构、机身比例、配色块面。

只保留最值得记住的识别信息，不需要保留所有细节。

【设计原则】
将提取出的识别特征进行：

抽象化，
夸张化，
Q版化，
符号化，
像素化重构。

不要追求原图高相似度。
优先保留“这是它”的感觉，而不是“和它一模一样”。

主体应像一个重新设计过的像素角色，而不是原图主体被机械降采样。

【构图】
输出为 1:1 正方形头像。

主体必须居中或偏中心放置。
主体占据画面主要面积，整体呈头像构图。
不要保留原图的真实场景。
不要风景、街道、建筑、房间、桌面、草地、天空等环境信息。

只保留：
主体
+
极少量必要的辅助符号。

辅助符号仅在确实有助于识别时才使用，例如：
一顶帽子、
一副眼镜、
一个小道具、
一段尾巴、
一片叶子、
一个机械部件。

不要增加与识别无关的装饰。

【像素风格】
整体采用 retro 8-bit pixel art / 复古 8-bit 像素艺术风格。

要求：
清晰像素块，
统一像素分辨率逻辑，
强轮廓，
黑色或深色像素描边，
大色块概括，
极简五官，
强图标感，
鲜明外轮廓，
像复古游戏角色头像。

像素边缘必须干净明确。
不要做成模糊马赛克。
不要做成现代高清插画再叠像素滤镜。
不要混入 3D、厚涂、柔光、照片材质或平滑矢量感。

【五官与表情】
如果主体是人物或动物，可以根据原图气质设计一个匹配的像素表情，例如：

呆萌、
酷脸、
震惊、
坏笑、
害羞、
无语、
开心、
高冷、
调皮。

表情应与原图气质有关，但可以适度夸张。
不要每次都做同一种表情。

五官要极简，但要有角色感和记忆点。
不要画得太复杂。
不要做成普通动漫脸。

如果主体是物品，不要强行加人脸。
优先保留物体的形状、结构和功能识别特征。
仅在不破坏识别度时，才允许非常轻微拟人化。

【配色】
颜色可以大胆、有创意，不必完全忠实原图。
允许对头发、毛色、衣服、配饰、道具等进行高饱和改色或局部强化，但必须保留主体最核心的识别感。

背景必须使用纯色背景，并且随机变化。
背景颜色可从以下方向中自由选择并自动搭配：

亮粉、
湖蓝、
电光绿、
荧光黄、
紫色、
橘红、
天蓝、
薄荷绿、
珊瑚粉、
深蓝、
亮橙、
酸性绿、
玫红、
青绿色。

主体与背景必须形成明确撞色关系：

如果主体偏深色，背景应更明亮；
如果主体偏暖色，背景可偏冷色；
如果主体偏冷色，背景可偏暖色；
避免主体与背景颜色接近；
不要固定黄底；
不要固定橙发；
不要每次都套用同一配色模板。

最终配色应鲜明、有冲击力、适合头像传播。

【线条与色块】
使用像素描边明确分隔主体轮廓和内部区域。
主体由大色块构成，不追求复杂纹理。
局部可以有少量高光或色彩跳点，但仍需保持复古像素风逻辑。

不要：
渐变、
空气感阴影、
写实皮肤质感、
照片噪点、
复杂反光、
平滑光影。

【背景规则】
背景必须是单一纯色。
不要真实场景。
不要复杂图案。
不要多层环境。
不要加入大面积装饰性元素。

如有需要，可加入极少量像素符号辅助气氛，例如：
一颗星、
一个像素闪电、
一个像素光点、
一个小图形块。

但这些元素必须极少，不得喧宾夺主。

【不同主体的处理原则】
如果主体是人物：
重点保留头部特征、表情、发型、配饰和服装识别点。

如果主体是宠物或动物：
重点保留耳朵、毛色分区、眼神、脸型、尾巴和最显著姿态。

如果主体是玩具或物件：
重点保留整体轮廓、结构和配色块面，不强行人格化。

如果主体是交通工具或机械：
重点保留最具标志性的结构块面和功能轮廓，头像化、图标化处理。

如果主体是植物或食物：
重点保留轮廓、色块、叶片/果实/花瓣等关键识别结构，并做角色化概括。

【生成前检查】
生成前内部检查：

是否真正提取了 3–5 个识别特征？
是否进行了重新设计，而不是机械像素化？
是否移除了原图真实背景？
是否是 1:1 正方形头像构图？
主体是否占据主要面积？
背景是否为纯色？
主体与背景是否形成明显撞色？
是否具备清晰像素块和复古 8-bit 风格？
是否避免了写实、3D、厚涂、普通动漫插画？
是否避免不同图片生成同一个模板化角色？

如果某个细节不影响识别，就删掉它。
优先保留角色感、轮廓感和记忆点。

【禁止】
不要写实。
不要 3D。
不要厚涂。
不要普通动漫插画。
不要真实照片质感。
不要复杂背景。
不要保留原图真实环境。
不要过度追求相似度。
不要让不同图片生成同一个模板。
不要做成像素滤镜照片。
不要保留大段场景信息。
不要加入无关文字、Logo、水印、边框或 UI。

【最终标准】
最终生成一张：

高度抽象，
强识别度，
颜色大胆，
纯色背景，
像素感强，
适合做头像的 1:1 图片。

它应像一个被重新设计过的商业像素头像 IP，
而不是原图的像素翻版。

只生成一张最终图像，不输出解释、多个方案、拼图、网格或联系表。
```
