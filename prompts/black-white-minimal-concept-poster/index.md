````text
# 黑白极简概念海报

## Prompt

```text
创作一张黑白灰现代编辑概念海报，整体气质像高端作品集封面、现代主义展览海报或高质量编辑设计封面。

【输入】
主题词 / 主标题：{{主题词}}
副标题：{{副标题，可留空}}
画幅比例：{{画幅比例}}
语言：{{中文 / 英文 / 中英混排}}
用途：{{用途}}
可选补充语境：{{补充背景，可留空}}
可选情绪倾向：{{理性 / 冷峻 / 先锋 / 秩序 / 压迫 / 孤独 / 希望 / 未来 / 克制，可留空}}
可选禁用元素：{{不想出现的元素，可留空}}

【核心目标】
围绕“{{主题词}}”设计一张黑白极简概念海报。

整张图必须同时具备：
巨型且清晰可读的标题，
克制留白，
锐利明确的网格秩序，
一个准确而有解释力的图像隐喻。

不要把它做成普通宣传页，也不要只剩一排大字。
标题、图像隐喻、留白、边界、层级和网格必须共同形成一个完整的现代编辑画面。

画面要让人第一眼先感受到结构和气场，
第二眼读到隐喻与主题的关系，
第三眼感受到细节中的秩序、空间与思想性。

【整体风格】
整体以黑、白、灰为主色系统。
允许仅出现极少量语义强调色，用于强化一个局部重点，但不能破坏黑白灰主导关系。

整体视觉应具有：
现代主义、
编辑设计感、
理性秩序、
冷静克制、
高端作品集封面气质、
展览海报级别的结构感。

画面强调：
大面积留白、
清晰网格、
锋利边界、
结构化层级、
轻微纸张颗粒、
克制而明确的空间关系。

【标题与文字骨架】
主标题必须巨大、完整、准确、清晰可读，并成为整张海报的结构骨架。

主标题应显示：
“{{主题词}}”

如果有副标题，则显示：
“{{副标题}}”

根据 {{语言}} 组织文字系统：
- 中文：使用厚重现代黑体、几何黑体或窄体黑体气质
- 英文：使用粗黑无衬线、压缩字体或现代主义字形气质
- 中英混排：中英文在字重、尺度、对齐和节奏上保持统一系统感

主标题不只是文字内容，还要像一个可被进入、穿越、依附、切割或承载空间关系的结构体。
它可以像：
建筑、
墙体、
容器、
屏幕、
档案柜、
港口立面、
精神地貌、
秩序边界。

除主标题外，只允许少量小字系统用于补充信息。
可出现的次级信息仅限于：
副标题、
分类标签、
年份、
编号、
账号 ID、
极少量说明性信息。

这些小字必须少、准、清晰，并作为辅助层，不得抢占主标题的视觉重心。

【图像隐喻】
图像隐喻必须控制在 1–3 个关键锚点内。

可选锚点包括但不限于：
微缩人物、
路径、
门、
桥、
阶梯、
窗口、
档案、
终端、
断层、
光束、
机械结构、
数据路径。

隐喻必须准确服务于“{{主题词}}”与“{{补充背景}}”。
优先选择一个最能表达主题关系、冲突、处境、秩序或张力的隐喻，不要贪多。

图像不能像后贴上去的素材。
它必须从排版结构内部生长出来。

可以采用以下关系：
图像嵌入文字内部，
穿过字形，
依附字边缘，
成为字的阴影，
成为字内部的空间，
成为裂缝、地面、路径、容器或界面。

图像与标题必须是同一个系统的一部分，而不是“文字 + 插图”的并置关系。

【构图与网格】
根据 {{画幅比例}} 原生设计构图，不要先生成固定画面再裁切。

使用清晰、锐利、可感知的现代网格系统组织全图。
网格可以显性，也可以通过对齐、边界、留白和元素分布隐性体现。

整体构图强调：
明确主轴、
大块留白、
锐利分区、
紧张而克制的版面秩序、
少量但有效的视觉冲突。

画面可以采用：
中心构图、
偏心构图、
纵向压迫、
横向延展、
上下错层、
局部穿插、
边缘张力、
块面切割。

无论采用哪种方式，都必须让主标题成为空间骨架，让隐喻成为结构中的关键事件点。

【色彩与材质】
以黑、白、灰为主。
允许极少量语义强调色，但只能出现在小范围局部，用于强化一个概念节点、路径、警示、光点或信息焦点。

材质上允许轻微加入：
纸张颗粒、
印刷感、
微弱压印感、
轻度灰阶层次、
极轻微阴影。

这些质感必须克制、现代、干净。
不要做旧，不要过度复古，不要脏乱噪点，不要强纹理堆积。

【情绪控制】
整体情绪根据 {{可选情绪倾向}} 调整。

如果未指定，则默认保持：
理性、
克制、
冷静、
结构化、
略带思想性与现代压缩感。

可以根据主题适度偏向：
冷峻、
先锋、
秩序、
压迫、
孤独、
希望、
未来感。

但情绪必须通过结构、尺度、留白、边界和隐喻来表达，而不是靠花哨装饰。

【用途适配】
这是一张用于 {{用途}} 的成品海报。
在不改变黑白极简概念风格的前提下，使其适合对应场景传播与展示，兼顾识别度、阅读性和视觉完成度。

【必须避免】
不要做成普通广告页或廉价商业插画。
不要只剩大字，没有有效隐喻。
不要让隐喻空洞、随意或与主题脱节。
不要加入花哨装饰、复杂配色或无关图形噪音。
不要过度字体变形，不要让标题失去可读性。
不要堆叠太多隐喻元素。
不要加入写实人物主视觉、普通场景照片感或素材拼贴感。
不要让画面失去留白和秩序。
不要加入 {{可选禁用元素}}。

【最终标准】
最终只输出一张独立完整海报，不要输出样机、拼图、网格预览、多方案或设计过程图。

成图必须同时满足：
主标题巨大且清晰可读；
黑白灰主导明确；
留白克制且有呼吸感；
网格秩序清楚；
边界锋利；
图像隐喻准确且数量受控；
图像从排版结构内部生长出来；
整体像高端作品集封面或现代主义展览海报；
既有设计感，也有思想性与概念张力。
````
