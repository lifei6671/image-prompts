# 暗黑案件风知识图解

![预览图](preview.webp)

## Prompt

```text
围绕用户提供的主题，创作一张“黑金科技漫画编辑 × 模块化知识信息图 × 任务简报界面”风格的单页知识海报。

重点：这是平面编辑设计，不是写实场景插画。

整个画面采用高度固定、稳定、系列化的模板结构：
深黑偏蓝背景、亮黄色主强调色、米白文字、深蓝灰信息卡片、细黄色描边、极粗标题字体、规则网格排版。

禁止生成真实房间、调查现场、人物背影、照片墙、档案纸、报纸剪贴、灯具、写实城市、电影场景。


【输入】
主题 / 主标题：{{主题}}
核心观点：{{一句话说明真正想表达的判断}}
副标题：{{副标题，可留空}}
核心问题：{{这张图试图回答什么问题，可留空}}
关键线索：{{2–5 条短句，可留空}}
关键证据：{{2–4 条短句，可留空}}
关键数据：{{数字、比例、评分、提升幅度等，可留空}}
逻辑链路：{{例如：问题 → 线索 → 方法 → 结果 / 现象 → 证据 → 判断 → 结论}}
最终结论：{{一句短而有力的话，可留空}}
页码：{{例如 01/01，可留空}}
语言：{{中文 / 英文 / 中英混排}}
用途：{{公众号封面 / 文章配图 / 报告题图 / 研究解读 / 知识卡片}}
画幅比例：{{默认 16:9}}
可选情绪倾向：{{犀利 / 调查感 / 理性 / 克制 / 张力 / 深度 / 高级}}
可选禁用元素：{{不想出现的元素，可留空}}

【核心版式】

顶部左侧：
一个小型黄色描边栏目标签，例如 METHOD / EVIDENCE / RESULT / CASE CLOSED，作为章节标识。

顶部右侧：
固定一个大型黄色圆形或被画面裁切的圆形几何块，占据右上角约 20%–30% 区域。
圆形保持纯平面几何图形，可加入非常轻微放射线，不做真实太阳或灯光。

主标题：
位于左上至中上区域。
使用极粗、紧凑、块状的无衬线中文字体。
标题通常 2–4 行。
主要文字为暖白色，1–2 个核心关键词使用亮黄色。
标题必须是整张图最强视觉焦点。

中部内容：
根据主题自动选择一种主要结构：
- 4 条编号知识卡
- 2×2 方法卡片
- 3 个大数字结果卡
- 3 条证据结论
- 简单流程图
- 对比信息块

所有信息模块使用深蓝黑色矩形卡片，
细黄色或灰蓝边框，
内部为白色正文，
黄色编号、小标签或关键词作为强调。

卡片整体偏硬朗方形，
不要使用明显大圆角，
不要使用 SaaS 风格悬浮阴影。

【装饰系统】

背景使用纯深黑 / 深蓝黑。
加入极淡的规则网格线或工程图纸线条。

画面可以有非常轻微的黄色聚光三角形或放射线，
但保持二维平面设计，不形成真实灯光场景。

页面底部加入一组非常简化的“城市天际线 / 音频均衡器”式矩形线框：
由大小不同的深色矩形组成，
使用黄色水平线分层，
作为固定视觉装饰，
不能画成真实城市。

允许在画面右下角或标题旁加入一个小型原创漫画吉祥物：
比例很小，
扁平赛璐璐漫画风，
动作具有速度感，
只作为视觉点缀，
不能成为画面主体。

【颜色】

背景：
#080D10 ～ #10161B 深黑蓝

主强调：
明亮金黄 / 暖黄色

标题：
暖白 + 金黄色关键词

信息卡：
深蓝灰 / 黑蓝

边框：
亮黄色 + 少量灰蓝

正文：
浅灰白

整张图只使用黑、深蓝、黄、白四个主要色系。

【图形语言】

平面矢量感
硬朗矩形
细线边框
黄色编号块
小型标签
极粗大标题
工程网格
几何圆形
二维信息卡
简化城市线框

不要使用：
写实照片
摄影人物
三维场景
纸张拼贴
档案照片
侦探墙
报纸
撕纸
复古旧纸
强颗粒做旧
复杂光影
写实建筑
电影海报构图

【视觉层级】

第一层：超大主标题
第二层：黄色关键词与核心数字
第三层：规则信息卡片
第四层：栏目标签和辅助文字
第五层：底部线框装饰和小型漫画角色

画面必须保持清楚、规整、有呼吸感。
即使信息很多，也像经过专业编辑设计后的知识杂志页面，而不是复杂的信息拼贴。

【整体气质】

黑金科技感，
漫画杂志感，
研究简报感，
任务界面感，
高对比，
模块化，
硬朗，
年轻，
理性但有视觉张力。

最终应该像一套科技知识漫画杂志的固定栏目模板，
而不是“侦探电影海报”。
```
