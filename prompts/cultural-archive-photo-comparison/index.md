# 文化档案式摄影对比海报

## Prompt

```text
请将我上传的一张照片，制作成一张「左右对比式展示海报」。

整体采用横版构图，画面从左到右严格分为两个竖向区域，
左右各占整体宽度的 50%，比例严格为 1:1。

左右直接拼接，可无缝衔接，
也可以仅保留极细微的自然分界。

不要加入厚重边框、复杂装饰边框或额外分栏设计。


【左侧：原始照片】

左侧展示用户上传的原始照片，
尽可能保持原图真实、自然、清晰可辨。

为了适配横版对比构图，
允许对原图进行适度扩展、轻微裁切或构图调整，
但必须保持：

- 主体身份
- 主要轮廓
- 场景关系
- 拍摄角度
- 透视关系
- 空间层次
- 主体位置
- 整体视觉重心

基本不变。

左侧本质上是「原图展示区」。

保持真实摄影质感，
只允许轻微清理、亮度统一和基础画面优化。

不要加入海报排版，
不要加入大量文字，
不要增加旧纸纹理，
不要改变成其他艺术风格。


【右侧：文化档案式设计海报】

右侧必须基于同一张上传照片，
生成一张高质量的「文化档案式现代设计海报」。

严格继承原图中的：

- 主体内容
- 主体身份
- 主要轮廓
- 构图关系
- 拍摄角度
- 透视关系
- 空间层次
- 遮挡关系
- 整体视觉重心

左右两侧必须明显能够看出是同一张照片。

不要改变主体位置，
不要生成不同视角，
不要凭空替换主体，
不要增加与原图无关的新场景。


【整体设计风格】

将右侧照片转化为：

当代文化展览海报、
建筑档案海报、
文旅出版物封面、
摄影与平面设计融合的视觉风格。

整体气质：

高级、
克制、
安静、
沉稳、
具有文化感与专业编辑设计感。

强调「文化出版物」和「档案设计」气质，

不要做成：

廉价旅游宣传海报、
商业广告、
时尚杂志封面、
电影海报、
过度炫技的视觉设计。


【色彩处理】

在保留原始照片结构的基础上：

整体降低饱和度，
压缩中间调，
适度强化暗部，
让阴影形成具有力量感的大块面，

同时保留建筑、人物、环境和主体的重要细节。

推荐色彩体系：

低饱和青黑、
墨蓝黑、
灰绿、
米白、
旧纸黄、
赭石、
褐黄。

可以少量使用：

朱红、
暗红、
橙红

作为视觉点缀。

整体画面统一、沉稳、复古，
带有文化出版物与历史档案的视觉质感。


【纸张与印刷质感】

右侧加入细腻、克制的传统印刷质感：

- 纸张纤维
- 老式胶印颗粒
- 轻微网点印刷
- 轻微油墨渗透
- 旧出版物纸张肌理

质感必须自然、细腻、高级。

属于「高级做旧」，

不要做成：

严重破损、
污渍、
撕裂、
强烈折痕、
街头涂鸦、
粗糙复古滤镜、
强烈电影胶片噪点。


【现代编辑排版系统】

在右侧建立完整的现代编辑排版系统。

排版需要主动利用原照片中的：

天空、
墙面、
地面、
建筑周边、
负空间、
自然留白区域。

文字不要粗暴覆盖主体的重要结构。

整体具有明确的信息层级，
类似：

文化展览海报、
建筑档案、
博物馆出版物、
城市文化视觉档案。

文字内容可以根据照片主体自动生成，
不要求完全按照固定模板，
但必须合理、自然、可信。


【文字层级】

右侧必须包含以下信息层级：


1. 中文主标题

根据照片主体自动识别并生成合适的中文名称。

例如：

故宫
天坛
北海白塔
布达拉宫

中文主标题需要成为画面的重要视觉锚点。

字体风格可以使用：

高对比中文标题字体、
宋体、
明朝体、
现代文化标题字体、
书法感标题字。

可以采用竖排或竖向布局。


2. 大号年份 / 编号

加入一个与主体相关的：

年份、
年代、
建筑年代、
档案编号、
系列编号。

以大尺寸、低对比、半透明方式出现。

作为背景构图元素，
放置在天空、墙面或其他大面积留白区域。


3. 英文辅助标题

加入大号英文辅助标题。

使用：

全大写无衬线字体，
或具有出版物气质的衬线字体。

适当拉大字距。

英文标题作为背景式信息层存在，
透明度略低，

不要抢夺中文主标题的视觉中心。


4. 档案信息

加入一组精致的小字号说明信息，例如：

地点
国家 / 城市
建筑类型
文化分类
主题
系列编号
档案编号
文化遗产属性

形成博物馆档案和策展系统的感觉。


5. 边缘与底部说明文字

在画面底部或边缘加入少量小型说明文字。

可以中英混排。

用于增强：

文化出版物、
展览海报、
建筑档案、
博物馆视觉系统

的设计气质。

文字应克制、精致，
不要形成大面积文字堆积。


【结构线条】

如果照片主体属于：

建筑、
城市空间、
街景、
器物、
文化遗产

可以加入少量：

建筑结构描线、
测绘辅助线、
轮廓线、
建筑草图线稿、
档案标记线。

线条必须细、轻、克制，

用于强化建筑档案和文化研究感。

如果主体不适合，
则不要强行加入。


【左右对应关系】

左右两边必须具有明显的「原图 / 设计稿」对应关系。

尽可能保持：

相同主体位置、
相同视觉中心、
相同拍摄角度、
相近构图比例、
相同建筑关系、
相同空间结构。

让观者一眼看出：

左边是原始照片，
右边是基于这张照片完成的文化视觉设计版本。


【整体关键词】

左右对比展示，
原图 vs 设计稿，
中国文化，
东方美学，
文化档案海报，
建筑档案，
现代主义排版，
编辑设计，
展览视觉，
文化出版物，
旧纸张，
胶印质感，
网点印刷，
低饱和复古，
摄影与平面设计融合，
克制高级，
历史感，
文化遗产视觉系统。


【严格避免】

不要把左侧也设计成海报。

不要改变左右 50% / 50% 的比例。

不要做成上下结构。

不要加入厚重外框。

不要卡通化。

不要赛博朋克。

不要霓虹灯效果。

不要夸张 3D。

不要廉价旅游宣传风。

不要商业广告感。

不要杂乱拼贴。

不要使用过多颜色。

不要可爱风。

不要只是简单套滤镜。

不要使用强烈电影海报风格。

不要改变原始建筑或主体。

不要添加与原图无关的新人物、新建筑或新场景。


【最终输出】

输出一张完整、高质量的横版左右对比图。

左侧：
真实原始摄影照片。

右侧：
基于同一张照片制作的文化档案式现代设计海报。

左右各占整体宽度 50%。

整体画面需要清晰、统一、精致，

具有强烈的：

「原始摄影 / 文化设计」

前后对比展示效果。
````
