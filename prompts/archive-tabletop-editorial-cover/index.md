````text
## Prompt

```text
根据用户提供的主题，创作一张具有“未来创意机构 / 设计工作室 / 博物馆研究档案”气质的顶视角概念静物封面。

整体采用档案桌视觉语言：
淡灰绿色或浅薄荷绿色柔光灯箱桌面，
顶视角真实静物摄影，
少量经过选择的真实物件，
柔和漫反射光，
自然接触阴影，
低饱和专业调色，
克制编辑排版，
大片经过设计的留白。

不要直接复制任何真实产品或品牌的官方视觉。

核心不是“把几个漂亮物件摆在绿色桌面上”，
而是先理解主题，再通过少量物件之间的：
材质，
距离，
方向，
重叠，
数量，
尺度，
缺失，
排列
建立一个清楚的概念关系。

最终画面应像某个研究项目、创意课题或未来档案被临时展开在工作桌上进行观察，
而不是产品广告、固定模板或杂乱桌拍。

【输入】
主题：{{主题}}
主标题：{{主标题}}
副标题：{{副标题，可留空}}
画幅比例：{{5:2 / 16:9 / 4:5 / 3:4 / 9:16 / 1:1 / 其他；根据用途自动选择或保留用户指定比例}}
语言：{{中文 / 英文 / 中英混排}}
用途：{{X封面 / 文章封面 / 产品介绍 / 教程海报 / 项目档案 / 其他}}
核心概念：{{从主题提取的一句话，可留空}}
主视觉物件：{{根据主题自动选择，可留空}}
辅助物件：{{根据主题自动选择，可留空}}
可选补充语境：{{补充背景，可留空}}
可选禁用元素：{{不想出现的元素，可留空}}

【核心目标】
先理解“{{主题}}”与“{{可选补充语境}}”。

如果已经提供 {{核心概念}}，
以该核心概念作为视觉判断依据。

如果没有提供，
内部提炼一句最值得被视觉化的核心观点。

只保留一个核心概念。

不要试图把主题中的所有信息都摆到桌面上。

然后按照：

抽象观点
→ 现实物件
→ 物件关系
→ 空间构图
→ 编辑封面

完成视觉转译。

画面真正需要表达的是“物件之间发生了什么关系”，
而不是“桌面上有什么”。

【物件隐喻】
根据主题选择少量真实存在、具有明确材质感的物件。

可以使用但不限于：

专业工具，
测量仪器，
透明尺，
金属零件，
镜片，
实验器皿，
材料样本，
色卡，
模型，
产品原型，
艺术品，
陶瓷器物，
玻璃物件，
书籍，
单张地图，
少量手稿，
照片，
织物，
植物，
岩石，
木材，
矿石，
颜料，
标本，
收藏品，
机械零件，
线材，
磁带，
胶片，
透明薄片，
模型组件。

这些只是物件词典，不是固定搭配。

每次必须针对当前主题重新选择。

优先使用 1 个主视觉物件 + 1–4 个辅助物件。

物件数量宁少勿多。

【物件关系】
物件之间必须形成清晰的概念关系。

例如：

距离：
两个物件明显分离，表达隔阂、选择或不同路径。

靠近：
两个材料几乎接触，表达协作、融合或即将发生的变化。

重叠：
透明材料覆盖另一个对象，表达认知、解释、过滤或多层现实。

切断：
一个物件被结构线、边界或另一个材料隔开，表达断裂、限制或边界。

收束：
多个细小对象指向一个核心对象，表达聚焦、汇聚或决策。

扩散：
一个对象向周围形成材料变化或数量递减，表达传播、影响或扩张。

替换：
两个相似对象在材质或状态上不同，表达转型、升级或新旧交替。

缺失：
一组完整结构中刻意缺少一个位置，表达缺口、未知或尚未完成。

尺度：
巨大对象与极小样本形成反差，表达系统与个体、宏观与微观。

秩序与自然：
规则排列的人造材料与一个自然物形成对比，表达人工系统与生命、算法与现实、标准化与个体差异。

只选择与当前主题最准确的一种主要关系。

【主视觉物件】
如果用户填写 {{主视觉物件}}，
优先以其作为画面的主要实体。

如果未填写，
根据主题选择最准确、最具有视觉辨识度的一个物件。

主视觉物件应满足：
轮廓清楚，
材质真实，
尺寸适中，
具有概念含义，
能够在顶视角下建立明确视觉中心。

主视觉物件不一定必须放在画面正中央。

允许偏置，
允许靠近边缘，
允许与标题区域形成距离关系。

不要默认每次使用：
书，
地图，
尺子，
纸张，
玻璃球，
金属工具。

每个主题重新判断。

【辅助物件】
辅助物件只能用于：
建立概念关系，
提供尺度，
构成方向，
补充材料对比。

不要只是为了“桌面丰富”加入装饰。

如果一个辅助物件无法解释为什么存在，
删除它。

辅助物件不能形成第二视觉中心。

【真实桌面】
整个画面为严格顶视角真实静物摄影。

镜头垂直向下，
近似 90° 俯拍。

主体是一张大型柔光灯箱桌面或半透光工作台。

不要使用：
斜视角房间，
室内透视场景，
悬浮展台，
3D 空间舞台，
产品陈列台。

桌面应宽阔、平整、真实，
让物件具有可信重量和接触关系。

【背景】
桌面颜色以低饱和淡灰绿色或浅薄荷绿色为主。

可以轻微偏向：
灰绿，
雾绿，
冰薄荷，
浅鼠尾草绿。

整体保持：
柔和，
冷静，
干净，
安静。

不要使用高饱和荧光绿色。

桌面表面可以有极轻微：
磨砂质感，
灯箱透光感，
材质纹理，
细微明暗变化。

不要出现：
复杂纹理，
背景图案，
网格背景，
代码，
科技线路，
颗粒噪点堆积，
渐变光团，
装饰性几何背景。

【光线】
采用大型柔光源产生的漫反射照明。

整体像：
高端编辑静物摄影，
博物馆藏品摄影，
设计工作室作品记录，
专业产品摄影。

物件必须具有自然接触阴影。

阴影：
柔和，
短，
透明，
方向统一。

不能让物件像悬浮在桌面上。

透明材质应保留：
折射，
边缘反光，
轻微阴影，
真实透明度。

金属保留克制反射。
木材保留纤维。
纸张保留折痕和边缘。
织物保留纤维结构。
陶瓷保留哑光或釉面差异。

【材质真实性】
强调真实材质之间的差异：

金属：
冷硬、精密、轻微反射。

玻璃：
透明、折射、细小高光。

木材：
自然纹理、温暖表面。

陶瓷：
哑光或微弱釉面。

纸张：
真实边缘、轻微折痕、纸纤维。

织物：
柔软纤维和自然褶皱。

颜料：
真实涂抹和干湿变化。

自然材料：
保持石材、木头、植物、矿物等真实结构。

可以存在轻微使用痕迹，
但保持整洁。

不要人为制造：
严重磨损，
污渍，
废墟感，
古董做旧，
破损档案。

这是正在使用的专业工作桌，
不是废弃工作室。

【构图】
根据 {{画幅比例}} 原生设计构图。

不要制作固定桌面布局后机械裁切。

横版 5:2 / 16:9：
适合建立左右关系、远近关系或物件之间的大尺度距离。
标题可以位于一侧大片留白中，
物件集中在另一侧或沿水平轴形成关系。

竖版 4:5 / 3:4 / 9:16：
建立上下关系。
物件可以从上向下形成视觉路径，
标题位于顶部、中部留白或下方安静区域。

1:1：
采用偏心结构，
让主物件与标题形成紧凑但不拥挤的关系。

其他比例：
重新安排：
物件尺度，
标题位置，
留白面积，
视觉方向。

不要把所有对象集中在桌面中央。

【留白】
留白是该风格最重要的视觉元素之一。

桌面必须保留大量未被占用的区域。

留白用于：
建立秩序，
拉开物件关系，
承载标题，
形成观察距离，
增强项目档案感。

不要因为空间存在就加入更多物件。

桌面应让人感觉：
创作者刚刚挑选了最重要的几件东西摆下来，
而不是把抽屉里的全部材料倒出来。

【标题】
主标题必须准确显示：

“{{主标题}}”

主标题清楚、锐利，
是画面的主要视觉中心之一。

标题区域必须保持干净。

不要让：
物件，
阴影，
透明材料，
纹理
遮住关键文字。

标题排版应具有高级编辑设计感。

中文可以使用：
现代宋体，
克制黑体，
宋黑混合气质。

英文可以使用：
neutral sans-serif，
modern serif，
Swiss-style sans-serif，
editorial serif。

不要堆叠多种字体。

标题可以：
左对齐，
右对齐，
居中于留白区域，
沿桌面结构排列。

但整体必须稳定、克制。

【副标题】
如果用户提供副标题，
准确显示：

“{{副标题}}”

副标题明显小于主标题，
最多一行或极短两行。

它只补充主题信息，
不要解释整个视觉隐喻。

如果未提供副标题，
不要自动生成长文案。

【文字数量】
画面只保留：
主标题，
可选副标题。

除非用户明确要求，
不要自动加入：
档案编号，
日期，
坐标，
版本号，
项目编号，
机构名称，
随机英文，
说明栏，
标签，
密集小字。

避免为了制造“档案感”而制造大量伪信息。

档案气质主要来自：
物件选择，
观察视角，
材料关系，
留白，
编辑排版，
而不是大量编号。

【图文关系】
标题负责命名主题。

物件系统负责表达主题背后的概念。

二者应该互补，
不要重复解释。

一个物件可以：
轻微靠近标题，
指向标题，
框住标题区域，
与标题边缘形成方向关系。

但不能影响标题阅读。

不要让主标题随意悬浮在一张与主题无关的静物照片上。

物件关系必须使标题看起来“属于这个项目”。

【色彩】
主色：
淡灰绿，
浅薄荷绿，
雾绿色。

辅助色：
米白，
暖白，
浅灰，
银灰，
自然木色，
陶瓷色，
透明玻璃色，
少量黑色。

允许主题物件带有自己的自然颜色，
但整体保持低至中等饱和度。

不要建立高饱和多色系统。

不要使用：
霓虹蓝紫，
大面积电光色，
彩虹渐变，
强烈赛博配色。

【用途适配】
根据 {{用途}} 调整构图。

X 封面：
强化横向空间和左右物件关系，
标题避免过于靠近头像遮挡区域。

文章封面：
主标题识别度优先，
物件数量减少，
概念关系一眼可懂。

产品介绍：
可以让产品原型成为主视觉物件，
但仍然保持项目档案而非商业广告感。

教程海报：
可使用真实工具或材料建立“研究 / 制作”语义，
不要做步骤信息图。

项目档案：
强化材料、样本、模型和研究对象之间的关系，
保持更多留白与观察感。

【整体气质】
最终效果应具有：

未来创意机构，
设计研究工作室，
博物馆研究档案，
编辑静物摄影，
项目视觉档案，
专业创作者工作台

的混合气质。

关键词：
calm,
editorial,
archival,
conceptual,
tactile,
research-oriented,
minimal,
realistic still life photography.

整体：
安静，
理性，
真实，
精致，
略带未来研究感。

但不要制造明显科幻场景。

【必须避免】
不要复制 Kimi 的：
Logo，
字标，
产品界面，
品牌署名，
官方页面，
固定官方版式，
具体品牌视觉资产。

不要让画面伪装成真实 Kimi 官方作品。

不要固定物件组合。
不要每次都使用相同的：
尺子，
书，
地图，
模型，
玻璃片，
纸张。

不要大量使用纸张。
不要文件堆。
不要纸张铺满桌面。
不要杂乱工作台。

不要大量无意义装饰。

不要出现：
复杂 UI，
软件界面，
仪表盘，
蓝紫科技光，
霓虹灯，
赛博朋克，
发光线路，
悬浮屏幕。

不要使用廉价未来感。

不要使用：
插画，
扁平图形，
卡通，
纯 CGI，
3D 渲染，
悬浮产品展台
替代真实静物摄影。

不要出现：
模糊标题，
乱码，
密集小字，
说明栏，
大量编号，
假档案文本，
商业促销文案。

不要加入 {{可选禁用元素}}。

【生成前检查】
生成前内部检查：

是否为严格顶视角真实静物摄影？

是否使用淡灰绿色或浅薄荷绿色灯箱桌面？

是否只有少量真正与主题相关的物件？

是否先理解主题，再选择物件？

物件之间是否存在一个清楚的概念关系？

是否为当前主题重新设计组合，而不是套用固定桌面模板？

是否保留了足够的大面积留白？

标题区域是否干净、锐利、清晰？

是否出现了没有存在理由的装饰物？

是否存在纸张堆、文件堆或杂乱感？

是否误加入品牌 Logo、产品 UI 或复杂科技元素？

如果一个物件不能帮助表达主题，
删除它。

【最终标准】
最终只生成一张独立完整封面。

不要输出：
多个方案，
拼图，
样机，
设计过程，
物件拆解，
联系表。

成图必须同时满足：

严格顶视角真实静物摄影；
淡灰绿色或浅薄荷绿色柔光灯箱桌面；
1 个明确核心概念；
1 个主视觉物件；
少量辅助物件；
物件之间具有清楚的语义关系；
真实材质与自然接触阴影；
大片经过设计的留白；
主标题准确、清楚、锐利；
最多一个副标题；
低饱和专业色彩；
没有固定模板感；
没有品牌仿冒；
没有复杂 UI；
没有无意义档案编号堆叠。

最终第一眼应像：
一个设计研究项目被安静地摊开在未来工作室的灯箱桌面上。

第二眼才发现：
这些物件的位置、距离、材质和方向正在表达“{{主题}}”背后的核心观点。

最终效果不是“绿色桌面上的漂亮物件”，
而是“一份通过真实物件完成视觉思考的项目档案”。
````
