````text
# 商业杂志头版

## Prompt

```text
创作一张商业科技杂志头版式视觉封面。

整体气质参考高端商业杂志、科技编辑设计与数据新闻视觉：
大胆，
锐利，
高对比，
具有明确商业判断，
具有趋势报道感，
同时保持专业、现代和高级媒体传播气质。

不要复制任何真实媒体。
不要出现真实媒体名称、Logo、刊名、版式标识或可识别商标。

【输入】
主题词 / 主标题：{{主题词}}
副标题：{{副标题，可留空}}
画幅比例：{{画幅比例}}
语言：{{中文 / 英文 / 中英混排}}
用途：{{用途}}
行业 / 场景：{{AI / 投资 / 消费 / 餐饮 / SaaS / 创业 / 产业趋势 / 个人成长 / 商业模式 / 组织效率 / 其他，可留空}}
可选禁用元素：{{不想出现的元素，可留空}}

【核心目标】
先理解“{{主题词}}”在 {{行业 / 场景}} 中真正表达的：
趋势，
冲突，
变化，
机会，
风险，
竞争关系，
商业逻辑，
产业结构，
组织问题
或增长机制。

从中提炼一个最值得被看见的商业判断，并把它转译为一个明确、具有传播力的主视觉隐喻。

整张封面只建立一个主要商业隐喻。

可以使用人物，也可以完全使用概念物、数据结构或空间场景。

不要逐字把标题中的关键词画成物品。
不要把多个商业概念同时堆到画面中。

画面需要达到：
第一眼看到一个强烈编辑主视觉；
第二眼理解主题正在讨论什么变化或冲突；
读完标题后能够理解视觉隐喻为什么这样设计。

【商业隐喻】
根据主题选择一个最准确的核心隐喻。

可参考但不限于：
市场迷宫，
撕裂的白皮书，
警示牌，
断裂或加速的增长曲线，
资本流向，
订单流，
商业漏斗，
增长飞轮，
系统界面，
战略地图，
行业版图，
价格结构，
供需路径，
竞争赛道，
结构性断层，
排队系统，
门槛，
市场窗口，
资源管道，
组织机器，
被重新分配的筹码。

这些只是视觉语言库，不要求全部使用。

优先选择一个强隐喻，
最多加入 1–2 个必要辅助锚点。

隐喻必须与标题中的商业关系直接相关，
不能只为了“看起来像商业杂志”而加入无意义的箭头、曲线或数字。

【主视觉】
主视觉占据画面的主要视觉权重。

根据主题可以使用：
人物，
产品或概念物，
几何结构，
数据路径，
市场空间，
微缩场景，
战略地图，
系统结构。

如果使用人物：
人物必须与报道主题存在明确关系，
通过动作、位置、尺度、视线或环境表达商业处境，
不要出现普通西装商务人士摆拍。

如果使用概念物：
必须具有明确商业含义，
不要只是抽象 3D 装饰。

主视觉允许采用：
极端尺度，
怪比例裁切，
局部放大，
边缘裁切，
前后遮挡，
强透视，
非常规留白，
局部出框。

让画面具有真正的编辑封面张力。

【标题系统】
主标题必须准确显示：
“{{主题词}}”

主标题是整个版面的重要结构，不只是覆盖在图片表面的文字。

允许标题与以下结构发生融合：
市场曲线，
路径，
迷宫，
价格标签，
坐标轴，
风险线，
数据流，
系统节点，
战略地图，
商业版图，
图表边界。

可以让标题：
被路径穿过，
沿曲线排列，
嵌入结构内部，
依附在图形边界，
成为地图或系统的一部分，
与主视觉产生遮挡和层次关系。

但必须始终保持完整、准确、清晰可读。

不要为了先锋感过度扭曲字体。

中文使用：
现代黑体，
粗黑体，
几何黑体，
窄体无衬线字体气质。

英文使用：
bold grotesk，
neo-grotesque，
condensed sans-serif，
modern editorial sans-serif。

标题需要：
大胆，
锋利，
简洁，
远距离可识别。

【副标题】
如果提供副标题，则准确显示：
“{{副标题}}”

副标题明显小于主标题，
主要负责补充背景和解释核心判断。

保持：
一行或极短两行，
信息明确，
排版克制，
可快速阅读。

如果没有输入副标题，则不要自动生成。

【编辑信息系统】
允许添加极少量杂志头版式辅助信息，使画面具有真实编辑系统感。

最多使用 2–4 个短栏目标签，例如根据主题自动提炼：
趋势，
观察，
商业，
产业，
增长，
风险，
案例，
技术，
组织。

也可以出现一句非常短的编辑式结论，
但只能基于用户提供的主题语义进行概括，
不要虚构事实、数据、公司结论或新闻事件。

辅助信息可以表现为：
小型栏目标签，
细线信息栏，
编号，
小型索引，
短注释，
轻量坐标信息。

这些信息只承担版面结构作用，
不得形成大量正文。

不要生成无法阅读的伪文字。

【构图】
根据 {{画幅比例}} 原生设计构图，不要先制作固定版式再裁切。

优先建立：
一个强主视觉，
一个明确标题区域，
清楚的编辑层级，
明显留白，
少量辅助信息。

可以使用：
非对称网格，
偏心构图，
满版主视觉，
极端标题比例，
左右失衡构图，
上下压缩，
边缘裁切，
块面切割，
标题与图像重叠，
局部高密度 + 大面积留白。

不要追求绝对居中和平均平衡。

商业杂志头版允许制造视觉张力，但必须保持编辑秩序。

【图形语言】
可以加入少量：
结构线，
箭头，
坐标，
数据点，
路径线，
图表节点，
价格标记，
边界线，
网格，
小面积几何色块。

这些元素必须参与主题表达或版面组织。

不要把画面变成真正的数据仪表盘或信息图。

每一种图形语言都需要服务于核心商业隐喻。

【色彩】
允许使用具有传播力的高饱和主色和强对比配色。

建议控制为：
1 个主色，
1 个辅助色，
黑 / 白 / 深灰等中性色。

可以根据主题选择：
高饱和红，
亮橙，
鲜黄，
电蓝，
深蓝，
绿色，
品红，
黑白高对比。

色块要大胆、纯净、明确。

不要使用大量颜色平均分布。

颜色的作用是：
建立版面层级，
强调风险或机会，
区分信息，
强化商业隐喻，
而不是单纯装饰。

【行业适配】
根据 {{行业 / 场景}} 自动调整隐喻语言。

AI / SaaS：
偏系统、节点、路径、平台、接口、增长结构、效率与竞争格局。

投资：
偏资本流向、筹码、风险线、估值结构、周期、市场版图。

消费：
偏货架、价格、订单、排队、人群流动、渠道、供需。

餐饮：
偏门店、订单流、翻台、成本结构、供应链、规模复制。

创业：
偏赛道、资源、现金流、门槛、竞争地图、增长路径。

产业趋势：
偏产业链、资源流、地图、结构断层、上下游关系。

组织效率：
偏流程、堵点、路径、协作节点、系统结构、资源分配。

个人成长：
偏路径、阶梯、瓶颈、时间、选择、能力结构。

商业模式：
偏飞轮、漏斗、交易关系、价值流、网络结构。

行业隐喻需要具体，但不要堆砌行业符号。

【用途适配】
根据 {{用途}} 调整信息密度。

如果用于公众号、社交媒体或文章封面：
优先保证主标题和核心隐喻在缩略图中仍然清晰，
辅助信息减少。

如果用于完整杂志式视觉：
可以增加少量栏目标签和编辑结构，
但仍保持低文字密度。

如果用于 PPT 或报告头图：
适当增加留白，
减少栏目元素，
让画面更稳重。

【必须避免】
不要出现任何真实媒体名称、真实杂志刊名或 Logo。
不要模仿可识别的真实媒体品牌标识。
不要虚构真实媒体身份。

不要生成假新闻截图。
不要伪造真实报道来源。
不要虚构公司 Logo、股票代码、价格、营收数字或市场数据。

不要塞满栏目文字。
不要生成大段商业说明。
不要制作复杂信息图、仪表盘或数据大屏。

不要使用廉价财经模板。
不要使用股票大屏作为背景。
不要满屏 K 线、数字代码或红绿行情数据。

不要使用与主题无关的西装商务人士。
不要使用握手、会议桌、城市夜景等泛化商业素材作为默认主视觉。

不要出现“标题 + 装饰图标”的简单结构。

不要使用过度圆润、可爱、卡通或廉价 3D 图标风格。

不要加入 {{可选禁用元素}}。

【最终检查】
最终只生成一张独立完整的商业科技杂志头版式封面。

不要输出：
杂志样机，
多页杂志，
拼图，
多方案，
版式拆解，
设计过程。

最终画面必须同时满足：

主标题准确、醒目、清晰；
存在一个强而准确的商业隐喻；
主视觉与标题真正融合；
具有明显编辑网格和视觉层级；
信息量克制；
辅助栏目不超过 2–4 个；
高对比色彩有明确控制；
具有趋势报道感和商业判断气质；
远看具有强传播力；
近看具有编辑设计细节。

最终效果应像一个成熟商业科技媒体为重要趋势报道专门设计的头版视觉：
大胆、锋利、专业、具有判断，
但不存在任何真实媒体品牌冒充或廉价财经模板感。
````
