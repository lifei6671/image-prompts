# 案件调查风知识图解

![预览图](preview.webp)

## Prompt

```text
围绕用户提供的主题，创作一张“案件调查板 × 编辑信息图 × 漫画杂志解读页”风格的知识海报。

【输入】
主题 / 主标题：{{主题}}
核心观点：{{一句话说明真正想表达的判断}}
副标题：{{副标题，可留空}}
案件结论 / 最终判断：{{一句话结论，可留空}}
关键线索：{{2–5 条短句，可留空}}
关键证据：{{2–4 条短句，可留空}}
关键数据：{{数字、比例、对比结果、评分等，可留空}}
逻辑链路：{{例如：现象 → 线索 → 证据 → 结论 / 问题 → 分析 → 判断 → 建议}}
页码：{{例如 01/01，可留空}}
语言：{{中文 / 英文 / 中英混排}}
用途：{{公众号封面 / 文章配图 / 报告题图 / 研究拆解 / 知识卡片}}
画幅比例：{{默认 16:9}}
可选情绪倾向：{{理性 / 犀利 / 调查感 / 轻漫画感 / 克制 / 结论感}}
可选禁用元素：{{不想出现的元素，可留空}}

【核心视觉结构】
整体采用“案件调查现场”式叙事结构，把知识内容包装成一次调查、取证、结案过程，但保持信息图清晰可读。

建议采用以下结构：
1. 顶部案件标签区  
   左上角放一个醒目的红色小标签，像档案编号、案件代号、栏目编号、CASE FILE、EVIDENCE、RESULT、CASE CLOSED 这类调查栏目头。  
   旁边可搭配很小的辅助英文或编号，制造“档案页 / 卷宗页”感觉。

2. 主标题区  
   使用超大、粗黑、左对齐的无衬线标题。  
   标题通常分 2–4 行，强冲击力、强可读性。  
   标题中最关键的 1–3 个词使用高亮色强调，例如亮黄或红色。  
   副标题或解释说明放在标题下方，字号明显更小。

3. 主内容模块区  
   采用模块化知识块排版，每块像“线索卡”“证据卡”“任务条”“调查记录”“分析框”。  
   常见模块形式：
   - 编号列表卡（1 / 2 / 3 / 4）
   - 证据说明卡
   - 双列或四格线索卡
   - 大数字指标卡
   - 对比结果卡
   - 调查结论条
   - 问题与判断框
   - 简要注释框
   - 小型流程箭头或阶段提示

4. 辅助叙事元素  
   可适度加入以下元素增强“调查感”，但不能喧宾夺主：
   - 放大镜图标
   - 斜向连接线
   - 证据框边线
   - 对话框 / 注释框
   - 圆角矩形卡片
   - 页码章
   - 印章感小贴纸
   - 简笔漫画小人物或侦探感角色（仅作为点缀）

5. 页脚与结案区  
   底部可设置一条结论带、总结框或“最终判断”区域。  
   右下角可放清晰页码，例如 01/05、03/05。  
   页脚可加一行很小的栏目说明或主题来源说明，让整张图更像系列杂志页。

【核心原则】
- 核心不是“普通信息图”，而是“把知识内容讲成一宗案件”。
- 核心不是写实侦探插画，而是“调查感编辑设计”。
- 标题必须极强，第一眼就能抓住人。
- 信息虽然多，但层级必须清楚，不能像乱贴便签。
- 模块之间要有明显边界，像一张张调查卡片。
- 所有内容要围绕“发现问题、展示证据、得出判断”展开。
- 整体应像漫画化的研究拆解页、调查式知识专栏，而不是儿童海报或商业广告。

【版式气质】
整体采用“高信息密度的编辑排版 + 轻漫画调查风”的混合方式：
- 左对齐为主
- 模块化拼版
- 清晰分栏
- 信息块边框明确
- 页内层级强烈
- 适度加入倾斜构图与对角线，增强调查现场感
- 局部允许夸张的视觉强调，但整体仍需有秩序

画面观感应接近：
调查报告页、案件分析板、知识漫画专栏、研究结论拆解卡、媒体深度解读版面。

【背景与材质】
背景使用浅米白、浅灰白或略带暖感的纸面底色。  
表面可加入轻微点阵纸、方格纸、浅色圆点或非常淡的网格纹理，带一点印刷纸张与笔记纸混合感。  
背景上可以出现一些浅色辅助线、圆圈、箭头、几何定位线，像手工分析痕迹，但必须非常克制。

【主色系统】
整体色彩必须鲜明但克制，主打“调查档案 + 漫画杂志”风格。推荐如下配色：
- 背景：浅灰白、米白、微暖白
- 主文字：深 navy 蓝 / 近黑蓝 / 炭黑
- 主强调色 1：高亮红色，用于案件标签、警示、小标题章
- 主强调色 2：亮黄色，用于爆点词、贴纸、页码背景、重点提示
- 辅助色：浅蓝线条、浅灰分隔、少量米黄色底块
- 局部强化色：高饱和蓝色块，用于数据卡或对比框

整体色彩关系建议：
- 70%–80% 浅背景
- 10%–15% 深色文字与边框
- 5%–10% 红黄高亮
- 少量蓝色结构辅助

避免过多颜色混杂，禁止彩虹配色、紫蓝渐变、霓虹赛博风。

【字体与文字气质】
标题采用粗黑、极醒目、压迫感强的现代无衬线字体。  
正文与说明采用清晰紧凑的无衬线字体，适合高信息密度阅读。  
小标签、编号、页码可用更硬朗的窄体或档案感字体。  
可加入极少量英文栏目名，例如 CASE / EVIDENCE / RESULT / CLOSED，增强杂志感。  
不要使用手写体、书法体、卡通圆体或过于花哨的装饰字体。

【图形语言】
图形语言应接近“调查卡片 + 杂志信息图 + 漫画提示框”的混合风格：
- 粗黑边框
- 干净矩形卡片
- 高亮数字
- 模块化色块
- 对话框 / 注释框
- 编号圆点
- 小型柱状图或对比数据卡
- 放大镜、小箭头、小印章、贴条
- 放射状扇形图形或半圆高亮构图，用于制造视觉记忆点

允许少量漫画感符号，但重点仍是信息表达，不是插画本身。

【风格总基调】
整体应呈现：
强观点、强标题、强信息块、强调查感、强结论感。  
视觉上像一本把 AI、科技、商业或研究内容“案件化讲解”的知识杂志。  
既有媒体感，也有一点轻漫画感；既有趣味性，也保持理性分析气质。

最终效果应给人一种感觉：
“这不是普通科普图，而像在拆一宗案子，一步一步把证据摆出来，最后给出判断。”

【避免】
不要做成普通白板手绘
不要做成极简纯瑞士风
不要做成商业海报或电商广告
不要大面积写实人物插画
不要使用厚重 3D 特效、玻璃拟态、液态金属、赛博朋克霓虹
不要让元素随意散乱，像真正杂乱的侦探墙
不要把所有模块做得一样大、一样重
不要通篇都是正文堆砌
不要弱化标题冲击力
不要把页面做成严肃论文排版而失去“案件现场”感

【输出要求】
输出的是一张“案件调查风的知识信息图”，
要提炼并延续这种风格的核心特征：
浅底纸面、深色粗标题、红黄蓝强调、模块化证据卡、调查栏目标签、编号线索块、结论式叙事、漫画杂志式张力。
```
