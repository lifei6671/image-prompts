整体视觉固定为：

复古日本科幻动画感，
赛璐璐手绘质感，
锋利轮廓，
硬边分色阴影，

轻微胶片颗粒，

不要现代企业科技风，
不要 3D，
不要写实摄影，
不要普通扁平插画，
不要赛博朋克霓虹堆叠。

【画面机制】
每张图只允许：

1 个视觉中心。

如果加入第二元素，

不要做偶像海报。

90 年代日本科幻动画人物感，

允许：

有戏剧性的衣物褶皱，

不要复制具体动画角色脸型、发型、服装或配色。

如果用户提供了人物设定：

【无人物主体】
当使用无人物画面时：

绝对不要出现：
人物，
人体剪影，
手部，
脸部，
人物倒影。

主体应使用：
代码块，

卡片，
数据模块，

终端，

被撕裂或重组的版面。

关键要求是：
主体必须“正在变化”，而不是静止放在那里。

优先表现：
展开，
转化，
爆发，
穿透，
解锁，
拼合，
启动，
分裂，
重组，
折叠，

单一立方体，
一堆代码字符。

【核心隐喻】
先根据 {{主题词}}、{{主题说明}}、{{补充语境}} 提炼一个最强隐喻。

单一，
直观，
容易动画化，
容易形成动作，
容易形成高冲击构图。

【固定色板】
整张图只允许从以下颜色中选择：

【配色策略】

  深蓝黑或深紫为主背景，
  荧光绿或警示黄做强调。

- 爆发 / 启动 / 冲突：

  深紫或深蓝黑背景，
  亮紫 / 橙色作突破点。

面积关系明确，

【赛璐璐绘制规则】
所有主体都必须以“复古赛璐璐动画”方式绘制：

- 轮廓线清晰锋利
- 线条略带手绘波动
- 明暗采用硬边块面分层
- 阴影不是柔和渐变，而是明确切面
- 高光数量少但清楚
- 不使用空气刷柔雾塑形
- 不使用 3D 建模式真实光影

阴影必须像手工上色的赛璐璐片，

【线稿】

不要变成漫画特效铺满全图。

【透视与空间】
构图必须有强透视或强空间戏剧性。

主体可以像：

在扭曲系统中坠落，
被巨大结构压迫，

允许使用：

斜向透视，
俯冲视角，

不要做平视平铺。
不要普通居中站姿。

【明暗关系】
整体需要强烈明暗反差。

背景与主体之间应形成清楚分离。
允许大面积深色背景，
配合亮色主体或亮色冲击区。

不要柔灰中间调铺满全图。
不要变成柔美插画。

【胶片与年代质感】
加入轻微但克制的年代感：

- 胶片颗粒
- VHS / 扫描轻微粗粝感
- 极轻微印刷或复制噪点
- 轻微边缘抖动
- 少量复古屏幕感

不要：
故障风铺满，
严重彩噪，
严重老化破损，
脏污划痕过度，
低清到看不清。

不要贴边。
不要被主体压住大部分笔画。
不要错字。
不要断裂到无法识别。

【标题字体】

修长、锋利、高对比的明朝体 / 宋体 / Mincho 气质字体。

不要使用：

标题应该有“复古日本科幻动画标题卡”的锋利戏剧感。

【标题布局】

可以采用：

- 标题压住一部分背景切面
- 主体从标题下方冲出
- 标题与透视线共享方向
- 标题成为空间中的牌匾 / 警示卡 / 标题卡层
- 一部分标题位于前景，一部分位于背景
- 标题与主体共同围绕一个冲突中心展开

但标题始终优先清楚可读。

【比例适配】
构图必须根据 {{画幅比例}} 重新设计。

不要先做一张固定图再裁切。

- 方形 / 4:3：

  主体更集中，标题更像标题卡。

- 竖版（4:5 / 3:4 / 9:16）：
  标题在上方或侧边纵排，
  主体沿纵向空间运动，

- 冷静：
