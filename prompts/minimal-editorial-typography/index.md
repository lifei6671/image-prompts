# 极简杂志文字排版

![预览图](preview.webp)

## Prompt

```text
现代极简杂志编辑设计风格，以超大文字排版作为画面的核心视觉。

3:4 竖版构图，背景采用非常浅的薄荷绿、灰绿色或带轻微绿色倾向的暖白色，
低饱和、干净、克制，保留大量留白。

画面不依赖人物、插画或复杂图形，
主要通过字体大小、字重、颜色、行距和留白形成视觉层级。

标题采用超大字号排版，
中文使用具有现代出版物气质的宋体、衬线体或高对比字体，
英文使用经典 Editorial Serif 风格衬线字体。

中英文可以混合排版，
允许根据标题语义自动断行，
形成错落但稳定的纵向文字结构。

主体文字以接近纯黑色为主，
从标题中选择 1～2 个关键词使用鲜明翠绿色、高饱和绿色进行强调，
绿色面积保持克制，只作为视觉焦点。

画面顶部和底部可加入一条细长的绿色水平线，
用于建立版式边界和视觉秩序。

整体采用偏左对齐或左侧视觉重心，
保持宽松页边距，
文字块之间具有明显呼吸感，
避免把画面填满。

排版强调：
超大字体、
强烈字号对比、
黑绿双色、
宽松行距、
大面积留白、
清晰视觉层级、
现代编辑设计、
独立杂志封面感、
文化出版物气质。

根据用户提供的标题自动判断：
哪些文字需要放大，
哪些词适合使用绿色强调，
在哪里换行最自然，
不要机械平均分割每一行。

画面保持二维平面设计，
不要使用渐变光效、立体字、3D 效果、阴影、玻璃质感、复杂纹理或装饰性元素。

不要添加与用户标题无关的文字，
不要生成 Logo、二维码、水印、图标或额外说明。

最终效果应像一张经过专业编辑设计师排版的
极简文化杂志封面或知识类社交媒体海报：
简洁、醒目、克制、具有高级出版物气质。
```
