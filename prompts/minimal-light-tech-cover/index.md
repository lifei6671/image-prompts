```text

整体视觉只依赖四个核心要素：

1. 大面积纯白 / 暖白 / 极浅灰留白；

安静，
干净，
现代，
克制，

【输入】
内容主题：{{内容主题}}

【核心视觉原则】
整张图只建立一个视觉锚点。

如果存在标题：
标题是第一阅读层级；
主视觉锚点是第二视觉层级。

如果画面文字为“无文字”：
主视觉锚点成为唯一视觉焦点。

设计感主要来自：
大面积留白，
标题与锚点之间的尺度关系，
精准位置关系，
极少量渐变，
柔和材质，

不要依靠大量装饰、UI、粒子、线路或复杂背景制造科技感。

【主题判断】
先理解 {{内容主题}} 的整体气质。

根据主题判断封面更适合：
理性，
轻盈，
可靠，
流动，
智能，
透明，
连接，
效率，
创造力，
秩序，
品牌升级

这种判断主要影响：
锚点造型，
渐变色系，
透明度，
圆润程度，
构图位置。

不要因为主题包含 AI、软件、数据、科技等词，

机器人，
芯片，
电路板，
数据流，
代码，
HUD，
全息屏。

按照以下优先级选择主视觉：

第一优先：
如果“是否提供 Logo”为“是”，且确实提供了 Logo，
进入 Logo 锚点分支。

第二优先：
如果没有 Logo，
或者用户明确要求抽象形体，
进入抽象锚点分支。

不要同时使用一个大型 Logo 和一个大型抽象玻璃体。

即使 Logo 被嵌入玻璃结构中，
整体仍然必须被视为一个统一锚点。

【Logo 锚点】

核心图形，
基础比例，
轮廓，
内部结构，
主要色彩关系。

不要：
改变 Logo 基本几何结构，
凭空添加品牌文字，
伪造品牌名称，
替换成相似但错误的符号。

Logo 可以进行非常克制的空间化处理：

轻微立体厚度，
柔和圆角，
轻拟物高光，
非常浅的材质反射，
半透明玻璃包裹，
磨砂渐变载体，
轻微软塑胶质感，
细腻接触阴影。

目标是让 Logo 从二维标识转变为高级产品视觉锚点，

不要变成：
玩具，

气球，
厚重金属徽章，

【Logo 原色】

但核心品牌辨识不能被破坏。

如果 Logo 本身色彩较多，
不要把所有颜色扩散到整个封面。

颜色仍然集中在锚点内部。

【Logo 载体】
Logo 可以：

直接作为轻微立体化锚点；

或嵌入一个极简的：
玻璃圆片，
柔和椭圆，
透明透镜，
渐变胶囊体，
圆角软几何载体。

如果使用载体，
Logo 与载体必须成为一个完整对象。

不要形成：
Logo + 第二个大型 3D 物件
的双焦点结构。

【抽象锚点】
如果没有提供 Logo，
创作一个简洁的抽象轻科技锚点。

可以根据主题与 {{主视觉偏好}} 选择：

柔和 3D 玻璃体，
透镜层叠，
半透明椭圆，
圆角胶囊体，
软流体，
雾面透明块，
渐变球面，
弯曲透明薄片，
一至三层相互交叠的软几何结构。

形体必须简单。

通常控制在：
1 个主体形态，
或最多 1–3 层属于同一主体的结构。

不要为了“高级”叠加大量透明环、玻璃球、曲面和漂浮碎片。

视觉应像一个品牌核心符号，
而不是一堆 3D 装饰素材。

【抽象形体语义】
抽象锚点可以通过形态暗示主题：

连接：
两个柔和曲面在一个中心区域汇合。

流动：
一枚连续弯曲的透明流体形态。

智能：
一个集中、精确、略带层叠关系的透镜结构。

效率：
简洁收束、方向明确的几何体。

协作：
两个结构轻微交叠，但视觉上仍属于一个统一锚点。

生成：
由一个核心逐渐展开的轻柔形态。

透明 / 开放：
清晰玻璃层与开放负空间。

这些只是关系参考，
不要机械匹配。

【背景】
背景固定保持在非常浅的中性色范围：

纯白，
暖白，
象牙白，
极浅冷灰，
极浅暖灰。

背景必须：
平整，
安静，
明亮，
干净。

允许极轻微的环境明暗变化，
但整体仍应被感知为浅色纯净背景。

不要在背景使用：
大面积彩色渐变，
网格，
颗粒噪声，
光团，
代码，
电路纹理，
复杂阴影，
背景插画。

彩色视觉全部集中在唯一锚点附近。

【留白】
大面积留白是该风格最重要的设计元素之一。

不要因为画面空而加入更多内容。

标题与锚点之间必须保留清楚距离。

锚点四周也需要足够空间，
让它看起来像经过精确放置的产品视觉对象。

留白承担：
高级感，
秩序，
品牌气质，
视觉停顿，
阅读区域。

整体目标是：
少而精，
而不是丰富。

【文字模式】
如果 {{画面文字}} 为“无文字”：

画面中不出现任何可见文字。

不要生成：
标题，
副标题，
英文标签，
品牌名称，
日期，
编号，
说明文字，
随机字符。

只保留：
浅色背景
+
唯一主视觉锚点。

如果 {{画面文字}} 不是“无文字”：

画面中的所有可见文字必须与用户提供的内容完全一致。

不得：
改写，
扩写，
翻译，
缩写，
增加副标题，
增加英文，
增加品牌口号，
增加日期，
增加随机小字。

【标题】
如果存在画面文字，
使用现代超粗黑体 / 粗体无衬线。

中文倾向：
现代黑体，
几何黑体，
超粗无衬线，
结构饱满的现代字体。

英文倾向：
bold grotesk，
neo-grotesque，
geometric sans-serif，
modern bold sans-serif。

标题颜色：
黑色，
近黑色，
炭黑。

不要使用彩色标题作为默认方案。

标题必须：
清楚，
锐利，
稳重，
现代，
具有明显视觉重量。

但不要粗暴铺满整个画面。

【标题处理】
标题保持正常二维排版。

不要：
渐变字，
描边字，
发光字，
阴影字，
3D 挤压字，
透明玻璃字，
弯曲变形，
夸张斜排，
无理由竖排，
复杂横竖混排。

标题不与锚点穿插。

不要让文字：
穿过锚点，
遮挡锚点，
贴到画面边缘，
压缩到无法阅读。

标题与锚点应该形成安静、清楚的空间关系。

【横版构图】
5:2 / 16:9：

优先使用非对称横向构图。

常见关系：

左侧或偏左：
标题。

右侧或偏右：
唯一主视觉锚点。

中间保留明显呼吸空间。

允许镜像：
左锚点 + 右标题。

不要机械五五分。

5:2 超宽比例中，
进一步减少锚点尺寸，
增加横向留白，
强化高级 Banner 感。

不要为了填满宽幅而：
拉长渐变，
增加多个锚点，
增加说明文字。

【竖版构图】
4:5 / 3:4 / 9:16：

标题优先位于：
顶部，
中上区域，
左上区域。

锚点位于：
标题下方，
中下区域，
或轻微偏侧。

锚点尺寸必须克制。

不要让大型 3D 形体占满整个纵向页面。

上下都需要留出呼吸空间。

【正方形】
1:1：

可以采用：
居中标题 + 偏下锚点，
偏左标题 + 偏右锚点，
或非常安静的偏心结构。

不要把标题和锚点同时放得巨大。

【自定义比例】
根据目标比例重新决定：

标题尺度，
锚点大小，
两者间距，
留白，
视觉重心。

禁止从固定横版直接裁切。

【渐变系统】
渐变只能存在于：
锚点内部，
锚点透明层，
锚点紧邻的折射区域。

不要把渐变铺到整个背景。

根据 {{渐变色系选择}} 执行：

自动选择：
根据内容主题和 {{配色补充说明}} 自动判断。
优先考虑蓝绿、冰川、银蓝、薄荷或低饱和冷色等轻科技体系，
但不是固定选择。

蓝绿系：
天空蓝 → 青蓝 → 青绿。

蓝紫系：
靛蓝 → 冷蓝 → 雾紫。

紫粉系：
雾紫 → 柔粉，
保持低饱和，
避免甜腻少女感。

青绿系：
湖绿 → 青绿 → 冷青。

薄荷系：
浅薄荷 → 青白 → 淡青绿。

冰川系：
冰蓝 → 冷白青 → 极浅银蓝。

银蓝系：
银灰高光 + 冷蓝透明层。

金橙系：
柔金 → 淡橙，
保持明亮和克制，
不要出现促销金色。

黑金系：
锚点内部可以使用近黑结构 + 极少量金色高光，
但背景仍保持白色 / 暖白，
不要制作暗黑整版。

低饱和暖色系：
雾杏，
浅陶，
暖灰，
奶茶色，
柔和暖橙。

低饱和冷色系：
雾蓝，
灰青，
鼠尾草绿，
浅银灰。

其他：
严格根据 {{配色补充说明}} 建立统一渐变。

【配色补充】
如果 {{配色补充说明}} 与预设色系发生冲突，

【颜色面积】
整张图的大部分面积都应该是浅色背景。

彩色面积应明显小于背景面积。

不要使用大面积彩色色块与标题竞争。

渐变不是背景主题，
而只是用于强调视觉锚点的局部材料语言。

【材质】
锚点允许使用：

柔和玻璃，
半透明磨砂材质，
雾面液态材质，
细腻渐变塑料，
轻拟物软材质，
精致半透明透镜。

材质应该：
光滑但不油腻，
通透但不廉价，
立体但不沉重，
未来但不赛博。

不要使用：
重金属，
铬面，
强镜面，
粗糙机械表面，
复杂工业结构，
高饱和塑料玩具感。

【光线】
采用明亮、柔和、干净的产品摄影式光线。

光源可以接近：
顶部大型柔光，
前侧柔光，
柔和环境光。

锚点内部允许出现：
精致高光，
轻微折射，
透明层重叠，
微妙色彩过渡。

但不要使用：
强霓虹光，
硬边聚光，
激光，
体积光，
舞台光，
大面积背光光晕。

【阴影】
锚点下方可以存在一个极淡的接触阴影。

阴影必须：
短，
浅，
柔和，
自然，
干净。

它只负责建立轻微落地感。

不要：
长投影，
深黑阴影，
戏剧性阴影，
复杂多方向阴影。

也不要让锚点明显漂浮在空中。

【参考图】
如果用户提供参考图：

如果 {{参考图说明}} 表示“只作气质参考”，
只提取：
留白比例，
视觉轻重，

光影程度，
整体高级感。

主体，
Logo，
构图，
文字，
品牌元素。

如果表示“构图参考”，
可以借鉴视觉重心和空间关系，

不要机械复刻参考图。

【风格气质】

高级 SaaS 产品发布视觉，

不要赛博朋克。

不要：
霓虹描边，
故障风，
粒子爆炸，

不要同时使用：

多个大型渐变形体，

不要填满画面。

画幅比例，

Prompt 原文，

用户未提供的说明文字。

不要使用：
立体标题，

【生成前检查】
生成前内部检查：

背景是否保持纯白 / 暖白 / 极浅灰？

如果提供 Logo，是否优先使用 Logo 作为唯一锚点？

如果没有 Logo，抽象锚点是否足够简洁？

是否存在第二个不必要的大型视觉主体？

标题是否与用户提供文字完全一致？

如果用户要求无文字，是否彻底没有文字？

标题是否使用现代粗黑体并保持正常平面排版？

标题与锚点之间是否保留足够呼吸空间？

是否错误加入了：
UI，

第二个 3D 形体？

是否存在可以删除的装饰？
```
