# 极简战略编辑知识图解

![预览图](preview.webp)

## Prompt

```text
创作一张“极简战略编辑设计 × 商业知识图解”风格的横版封面。

整体像一本高级商业研究刊物、战略咨询报告专题页或现代思想杂志封面：

大面积暖白留白，
深海军蓝超大中文标题，
严格但克制的编辑网格，
少量灰色文字层级，
右侧一个非常简洁的抽象关系图，
极细线条，
少量小型符号，
极低信息噪声。

重点不是做传统信息图，
而是把“一个观点 + 一个关系模型”设计成一张具有高级出版物气质的编辑封面。

整体应：
理性，
安静，
精确，
高级，
有思想性，
有商业判断，
但不冰冷。

【输入】
主题 / 主标题：{{主题}}
核心观点：{{一句话说明真正想表达的判断}}
副标题：{{副标题，可留空}}
核心关系：{{例如：聚焦 → 转化 → 价值 / 输入 → 收束 → 输出 / 多因素 → 一个结果，可留空}}
关键维度：{{2–4 个短词，可留空}}
最终结果：{{一个短词或短句，可留空}}
画幅比例：{{默认 16:9}}
语言：{{中文 / 英文 / 中英混排}}
用途：{{文章封面 / 公众号封面 / 报告题图 / 商业观点图 / 知识卡片}}
可选情绪倾向：{{理性 / 专注 / 克制 / 深度 / 高级 / 未来 / 研究}}
可选禁用元素：{{不想出现的元素，可留空}}

【核心视觉结构】
整张画面只表达一个核心观点。

画面分为两个主要视觉区域：

左侧约 52%–60%：
超大主标题、完整主题、副标题和极少量编辑文字。

右侧约 35%–43%：
一个极简抽象关系图。

中间保留明显呼吸空间。

不要把左右两部分做成两个独立卡片。
它们属于同一个连续白色页面。

整体形成：

强标题
+
弱图形
+
大留白

的视觉层级。

【背景】
背景使用：
暖白，
象牙白，
极浅冷灰白。

接近干净高级的艺术纸或报告纸。

整体几乎纯白，
只允许非常轻微的纸面颗粒或印刷质感。

不要：
明显纸纹，
做旧，
污渍，
渐变，
光斑，
彩色背景，
复杂纹理。

背景主要作用是让文字和细线结构获得充分呼吸空间。

【主色系统】
整张图使用严格克制的颜色体系：

主色：
深海军蓝 / 深靛蓝。

辅助色：
冷灰，
蓝灰，
浅银灰。

背景：
暖白或极浅灰白。

原则上不需要高饱和强调色。

如确实需要强调，
最多只使用一个非常小面积的深蓝或冷灰变化。

不要使用：
红黄蓝多色信息图配色，
渐变，
霓虹，
彩虹色，
高饱和装饰色。

【主标题】
主标题必须准确显示：

“{{主题}}”

主标题是整张图的绝对第一视觉。

使用：
现代中文黑体，
现代宋黑混合，
具有出版物气质的粗黑无衬线，
或略带书籍标题感的现代字体。

标题特点：

大，
有重量，
笔画清楚，
稳定，
理性，
不圆润，
不花哨。

颜色使用深海军蓝。

标题可以占据左侧区域的较大空间，
但不能铺满整个画面。

标题较长时自然拆成 2–3 行。

每行保持清楚节奏和充足行距。

不要为了塞下文字而缩得很小。

【关键词层级】
如果标题中存在最重要的 2–6 个字，
可以让其中一部分：

更大，
更粗，
颜色稍深，

或将次一级文字使用灰蓝色。

可以形成类似：

核心词 A
核心词 B + 核心词 C
完整主题说明

这样的层级。

但不要把每个词都做不同效果。

整张标题区域最多只建立 2–3 个文字层级。

【灰色辅助字】
允许标题中的少量次级文字使用：

灰蓝，
银灰，
浅石墨灰。

它们用于制造文字层级和节奏，
不是为了装饰。

深蓝文字承担主要语义，
灰色文字承担次级语义。

不要使用透明渐变文字。

【副标题】
如果提供：

“{{副标题}}”

准确显示一次。

位于主标题下方。

字号明显小于主标题，
使用现代无衬线字体，
深蓝或灰蓝。

副标题保持：
短，
清楚，
一行或极短两行。

不要写成长段解释。

【顶部微型编辑信息】
允许在顶部边缘加入极少量“杂志编辑系统”式信息。

例如：

左上：
一个极短栏目名、主题分类或英文小标签。

右上：
年份、期数或项目编号。

这些信息必须：
非常小，
非常轻，
不抢主标题。

如果用户没有提供具体内容，
使用抽象、中性的编辑信息，
或直接省略。

不要虚构真实媒体名、品牌名或出版机构。

不要复制参考图中的固定文字。

【左侧次级说明】
主标题下方可以存在一组非常克制的小型编辑信息。

例如：

一个短标签
+
一条竖线
+
一个非常短的英文或中文补充语。

视觉作用是建立出版物层级。

不要超过 1–2 行。

不要形成大段正文。

【核心关系图】
右侧只设计一个极简关系图。

不要画完整流程图。

不要画复杂商业模型。

根据 {{核心关系}} 或 {{核心观点}}，
提炼成：

2–4 个输入维度
→
一个收束 / 聚焦 / 转化结构
→
一个最终结果。

整个图形只讲一个关系。

【关系图结构】
推荐结构：

左侧：
2–4 个非常小的关键词节点。

中间：
极细曲线或直线逐渐汇聚。

中心：
一个极简抽象结构，
例如：
窄门，
双椭圆，
收束环，
透镜，
焦点，
阈值，
窄通道，
交汇点。

右侧：
一条清楚水平箭头
→
最终结果。

整体可以表达：

分散输入 → 聚焦 → 结果
多种能力 → 收束 → 价值
多个变量 → 过滤 → 核心输出
复杂信息 → 对齐 → 行动

但不要机械使用固定模型，
根据主题重新设计。

【关键维度】
如果提供：

{{关键维度}}

将其作为关系图左侧的 2–4 个短标签。

每个维度可以配一个非常简单的线性符号：

圆环，
时钟，
三条线，
靶心，
波纹，
小节点。

符号必须：
极小，
统一线宽，
深蓝或灰蓝，
只负责快速区分。

不要使用彩色图标。

不要制作复杂插画。

【连接线】
使用非常细的灰蓝色或浅蓝灰线。

线条可以：
轻微弯曲，
优雅汇聚，
保持大量空白。

不要粗线。

不要复杂箭头网络。

不要交叉形成蜘蛛网。

关系线应让人感觉：
安静，
数学化，
精确，
具有战略分析气质。

【中心隐喻结构】
中间的收束结构可以是：

两条细椭圆；
一组极细同心轮廓；
一个窄通道；
一个焦点；
一个透明边界；
一个简单的几何过滤结构。

它只负责表达：

聚焦，
过滤，
收束，
对齐，
转化。

不要做成 3D 装置。

不要增加立体科技效果。

只使用极细线条。

【结果节点】
最终结果位于右侧。

如果用户提供：

{{最终结果}}

准确显示。

结果文字比输入节点略大、略粗。

旁边可以有一条小箭头或极简方向线。

结构例如：

→ 价值创造
→ 最终结果
→ 关键能力
→ 目标状态

只保留一个最终结果。

不要再继续展开第二阶段。

【底部微型路径】
允许在右下或页面底部增加一条非常克制的“概念路径”。

例如：

概念 A  ›  概念 B  ›  概念 C  ›  概念 D

使用极小深灰或灰蓝文字。

它只是补充阅读方向，
不能成为完整流程图。

最多 3–5 个极短短语。

如果没有必要，
完全省略。

【图形语言】
所有图形采用：

极细描边，
线性图标，
灰蓝细线，
简单箭头，
小圆点，
极简椭圆。

不要：
实心大图标，
彩色图标，
复杂节点，
渐变线，
发光线，
3D 图标，
复杂数据图。

右侧整体应该像：
“编辑设计师画出的一个概念模型”。

不是：
“产品经理制作的流程图”。

【构图】
整体使用现代瑞士网格和高级编辑版式。

重点：

左重右轻；
大标题与小图形成明显尺度反差；
严格边距；
大量留白；
元素之间距离舒展；
视觉中心明确。

不要将所有内容居中。

不要平均五五分。

不要画卡片边框。

不要把图形放进独立白色模块。

整个页面是一块连续空间。

【文字对齐】
主标题优先左对齐。

副标题与主标题共享左边界。

顶部小字遵循页面网格。

右侧图形拥有自己的轻量对齐轴。

不要复杂错位。

不要随意倾斜。

不要横竖混排。

【字体系统】
建议最多使用两套字体气质：

1. 中文主标题：
   现代粗黑体 / 现代宋黑 / 编辑标题字体。

2. 正文与图解：
   现代无衬线，
   Swiss-style sans-serif，
   中性黑体。

英文可以使用：
neutral grotesk，
neo-grotesque，
modern sans-serif。

不要：
手写体，
卡通字体，
书法体，
科技发光字体，
像素字体。

【尺度关系】
标题字号非常大。

图解节点文字非常小。

副标题居中层级。

形成清楚的：

大
→
中
→
小

视觉对比。

这种尺寸反差是风格的重要部分。

不要所有文字字号接近。

【纸面与印刷质感】
整体保持非常轻的编辑印刷感。

允许：

轻微纸张颗粒，
极弱墨点，
极细边缘柔化。

不要：

强颗粒，
复古脏污，
套印错位，
撕纸，
重度做旧。

视觉仍然必须干净、现代。

【情绪适配】
根据 {{可选情绪倾向}} 轻微调整：

理性：
加强网格、对齐和细线关系。

专注：
增大留白，让右侧关系明显收束。

深度：
使用更深海军蓝和更克制灰色。

高级：
进一步减少信息和装饰。

未来：
增加极少量抽象几何，但不要科技 UI 化。

研究：
加强微型标签和结构关系。

无论情绪如何，
都保持白底、深蓝、灰色、极简编辑气质。

【用途适配】
文章 / 公众号封面：
主标题识别优先，
右侧关系图进一步简化。

X 封面：
强化横向空间，
标题与图解分布更舒展。

报告题图：
提高理性与留白，
减少小型编辑装饰。

知识卡片：
可以让右侧关系模型略微清楚一些，
但仍避免信息图化。

【必须避免】
不要做成普通信息图。

不要 PPT 风格。

不要咨询公司内容页。

不要大量卡片。

不要复杂流程图。

不要仪表盘。

不要多个模块框。

不要蓝紫渐变科技背景。

不要霓虹。

不要 3D。

不要大量彩色图标。

不要大面积装饰图形。

不要复杂人物插画。

不要摄影人物。

不要背景图片。

不要标题过于粗暴压满画面。

不要大量英文碎字。

不要虚构媒体 Logo、刊名、编号或品牌。

不要加入 {{可选禁用元素}}。

【生成前检查】
生成前内部检查：

是否只有一个核心观点？

左侧是否以超大标题作为第一视觉？

右侧是否只有一个极简关系模型？

两部分之间是否有足够留白？

是否采用深海军蓝 + 灰蓝 + 暖白的克制配色？

关系图是否只有 2–4 个输入节点？

是否只有一个收束结构？

是否只有一个最终结果？

图形线条是否足够细？

是否错误地做成完整流程图？

是否出现卡片、UI 或信息图组件？

如果有，继续简化。

小字是否只是辅助？

是否有无意义的编辑装饰文字？

如果有，删除。

最终画面是否更像：

“高级思想杂志封面”

而不是：

“商业报告中的一页 PPT”？

如果不是，
继续减少元素、扩大留白、强化标题层级。

【最终标准】
最终只生成一张完整独立封面。

不要输出：
多个方案，
拼图，
样机，
分析过程，
版式拆解，
联系表。

最终画面必须同时具备：

暖白或极浅灰白背景；
大量干净留白；
深海军蓝超大中文标题；
清楚的标题层级；
极少量灰蓝辅助文字；
现代编辑网格；
右侧一个极简关系模型；
2–4 个小型输入节点；
一组极细汇聚线；
一个简单收束 / 聚焦结构；
一个最终结果；
最多一条微型底部路径；
没有复杂信息图组件；
没有多余装饰；
没有商业 PPT 感。

远看时：

先看到一个极有力量的大标题。

第二眼：

看到右侧那个很轻、很理性的关系结构。

第三眼：

发现几个概念正在经过聚焦、收束或转换，
最终指向一个明确结果。

整体效果应像：

一本高端商业思想杂志，
只用大标题、细线、少量文字和大片白色空间，
把一个复杂观点压缩成一张具有思考感的编辑封面。

不是“把知识画成流程图”，

而是：

“让一个观点，以最少的文字和最轻的图形，被设计成一张高级视觉命题。”
```
