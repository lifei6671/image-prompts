# 复古水彩手账教程图解

![预览图](preview.webp)

## Prompt

```text
创作一张“复古水彩手账 × 分步骤教程 × 编辑信息图”风格的横版知识图解。

整体视觉像一本精心整理的手绘教程手册、学习笔记或复古生活方式杂志中的操作指南页：

暖米白纸张背景，
深蓝色手写标题，
柔和水彩色块，
三段式或多段式步骤卡片，
真实界面 / 示意图嵌入，
手绘箭头和重点标注，
底部关键提示，
少量植物、书本、纸张或可爱人物插画作为边缘装饰。

重点不是做成普通 UI 教程截图，
而是把“操作步骤、截图、手写批注和纸面插画”重新组织成一张有阅读节奏、有手账温度、又足够清楚专业的教程海报。

【输入】
主题 / 主标题：{{主题}}
章节编号：{{例如 01 / 起步；可留空}}
副标题：{{副标题，可留空}}
步骤数量：{{默认 3；建议 2–4 个}}
步骤内容：{{每一步的标题、说明和对应截图 / 示意内容}}
关键提示：{{可留空}}
画幅比例：{{默认 5:2；可指定 16:9 / 4:3 / 3:2 / 其他}}
语言：{{中文 / 英文 / 中英混排}}
用途：{{教程封面 / 操作指南 / 产品教程 / 知识图解 / 社交媒体长图}}
可选界面参考：{{上传截图或描述界面内容，可留空}}
可选装饰主题：{{植物 / 书本 / 文具 / 可爱人物 / 自动判断 / 无}}
可选禁用元素：{{不想出现的元素，可留空}}

【核心目标】
将用户提供的教程内容整理成一张“一眼知道主题、顺着箭头就能完成操作”的视觉图解。

阅读顺序必须非常清楚：

章节 / 主题
↓
完整主标题
↓
简短副标题
↓
步骤 1 → 步骤 2 → 步骤 3
↓
关键提示 / 最终提醒。

不要把所有文字和截图平均铺满画面。

每一步只保留完成操作真正需要的信息。

如果内容复杂，
优先提炼，而不是缩小字体或增加大量小字。

【整体视觉气质】
整体气质：

清楚，
亲切，
治愈，
轻复古，
有手绘温度，
有编辑排版感，
像一本被认真做过视觉设计的教程手册。

视觉介于：

手账教程，
水彩编辑插画，
复古学习笔记，
生活方式杂志，
现代知识图解

之间。

不要做成：
企业 PPT，
SaaS 仪表盘，
纯截图拼贴，
冷冰冰的操作文档，
电商促销页。

【背景】
使用暖白、奶油白、浅象牙白或轻微米黄色纸张背景。

背景保持：

明亮，
柔和，
干净，
有极轻微纸张纤维和印刷颗粒。

可以有非常轻的旧纸气质，
但不要严重泛黄或做旧。

不要：
脏污，
折痕，
破损，
烧焦边缘，
复杂背景纹理。

整张图应该仍然有很强的“白纸感”。

【主色系统】
整体以以下颜色关系为主：

深海军蓝 / 墨蓝：
主标题、正文、线条和主要文字。

柔和朱红 / 珊瑚红：
步骤编号、重点提示、局部箭头。

浅蓝：
第一步骤区域或局部提示。

浅薄荷绿：
第二步骤区域。

浅薰衣草紫：
第三步骤区域。

暖橙 / 淡黄色：
少量按钮或关键操作位置。

颜色整体保持：

柔和，
明亮，
低至中等饱和，
水彩感。

不要同时使用大量高饱和颜色。

每个步骤可以有一个自己的浅色识别色，
但全图必须属于同一套粉彩系统。

【顶部标题区】
画面顶部约占整体高度 20%–25%。

左上或顶部主体区域依次建立：

章节编号；
大号主标题；
一行副标题；
一条细长分隔线。

例如视觉结构：

02 / 设置
注册账号与安全设置
简单几步，快速完成基础配置
────────────────

章节编号要小。

主标题必须是整个画面的第一视觉。

副标题明显较弱。

不要把顶部区域塞入太多说明。

【主标题】
主标题必须准确显示：

“{{主题}}”

主标题使用具有明显手写感、毛笔感或马克笔感的中文字体气质。

特点：

粗细略有变化；
笔画有轻微人工不规则；
整体仍然清楚；
具有手账标题和编辑书写感；
比普通黑体更有人情味。

颜色使用深蓝。

可以配合非常轻微的蓝色手绘下划线或淡水彩笔触。

不要：
书法作品式复杂飞白；
儿童字体；
过度潦草；
难以辨认。

主标题必须优先保证可读。

【章节标签】
如果用户提供 {{章节编号}}，
放在顶部左侧，以较小尺寸呈现。

可以采用：

01 / 起步
02 / 设置
03 / 实战

等格式。

编号或斜杠可使用朱红色，
文字使用深蓝或灰蓝。

旁边可以有一条很细的水平线。

章节标签只是编辑结构，
不能比主标题醒目。

【副标题】
如果用户提供：

“{{副标题}}”

准确显示一次。

副标题位于主标题下方，
使用较小的现代无衬线字体或轻手写字体。

颜色为深蓝或灰蓝。

保持一行或极短两行。

如果没有提供，
不要自动生成长说明。

【步骤结构】
教程主体使用 2–4 个大型步骤卡片。

默认 3 步最适合此风格。

横版推荐：

步骤 1
→
步骤 2
→
步骤 3

每个步骤作为一个独立但统一的教程模块。

每张步骤卡包括：

大号圆形步骤编号；
步骤标题；
界面截图 / 示意界面；
1 条核心说明；
必要的箭头或框选提示。

不要在单张卡片内塞入多个子步骤。

【步骤卡片】
步骤区域使用极浅的水彩底色或半透明纸片式色块。

不同步骤可以分别采用：

浅蓝，
浅薄荷绿，
浅淡紫。

卡片边界：

非常细的彩色手绘线；
轻微圆角；
边缘略带手绘不规则感。

不要使用现代 UI 卡片的厚阴影。

不要明显悬浮。

视觉应像：
在一张教程笔记上，
用淡彩笔给不同步骤轻轻框出了区域。

【步骤编号】
步骤编号是重要视觉锚点。

使用大号：

1
2
3
4

放在圆形或轻水彩圆斑中。

每一步的编号可以使用对应的步骤颜色：

蓝，
绿，
紫，
红。

数字使用白色或深色，
保持清楚。

编号圆形与步骤标题位于同一行附近。

不要做成复杂徽章。

【步骤标题】
步骤标题使用深蓝色手写或手写黑体气质。

例如：

点击注册
填写信息
开启验证

标题需要：
短，
明确，
动作导向。

不要写成长句。

字号明显大于正文说明，
但小于顶部主标题。

【界面示意】
步骤卡中的操作界面可以来自：

用户上传的真实截图，
用户描述的 UI，
或者根据教程内容创建通用示意界面。

如果用户提供截图，
保留最重要的界面结构和操作位置，
但允许为了信息图阅读性进行适度简化。

如果没有截图，
使用简洁的“界面示意”形式，
表现：

页面标题，
关键按钮，
输入框，
开关，
菜单，
操作区域。

不要制造复杂完整 App UI。

只表现当前步骤需要看的区域。

【截图处理】
界面区域整体保持接近真实产品 UI，
但与整个水彩手账风格融合。

可以使用：

白色界面底；
细黑 / 深灰线条；
极轻水彩色边框；
局部红色框选；
手绘箭头。

不要把截图做成完全卡通插画。

界面文字必须尽可能清楚。

如果原始截图包含大量无关信息，
主动裁减或弱化，
只突出当前步骤。

【品牌处理】
如果用户明确提供品牌、产品 Logo 或真实截图，
可以保留用户提供内容中的必要品牌信息。

如果用户没有提供，
不要虚构真实品牌 Logo、支付卡组织、机构名称或商标。

生成通用教程时使用中性的：

“应用”
“账户”
“用户中心”
“注册”
“安全设置”

等界面语言。

不要为了复刻参考图而自动生成其中的真实品牌。

【操作重点】
使用少量红色或橙红色手绘标记突出关键位置。

允许：

细红框；
红色箭头；
手绘圈；
简短下划线；
一小段重点批注。

重点标记必须非常明确。

不要在同一个界面里圈出十几个位置。

每张步骤卡通常只强调：

1 个主要操作点，
最多 2 个。

【箭头】
步骤之间使用清楚的手绘箭头。

颜色可以是：

深蓝，
蓝紫，
步骤之间自然过渡的中性色。

箭头大小适中，
不要过粗。

它只负责告诉读者：

下一步在哪里。

不要制作复杂流程连接线。

【底部关键提示】
底部建立一块横向关键提示区域。

可以采用：

左侧：
红色小标签“关键提示”

中间：
一条细竖线

右侧：
一句较大的深蓝色结论或提醒。

例如：

关键提示
│
{{关键提示}}

这句话必须简短、直接、有行动意义。

底部区域可以使用非常浅的蓝色水彩边框或淡色底。

不要写多条提醒。

一条最重要的信息即可。

【人物插画】
允许在右下角加入 1 位非常小的可爱手绘人物作为编辑点缀。

人物可以：

拿着文件；
指向教程；
阅读说明；
举手提醒；
思考；
拿手机操作。

人物风格：

日系轻插画感，
水彩 + 细线稿，
清爽，
可爱但不过度幼稚。

人物只能占很小区域。

人物不是教程主角，
只是帮助画面建立亲和力。

不要复制任何真实动漫角色、品牌角色或知名 IP 造型。

服装和配饰保持原创、简单。

【装饰元素】
允许使用极少量生活化装饰：

书本，
纸张，
绿色植物，
笔记本，
简单文具，
小型卡片，
淡色台面。

装饰主要分布在：

边缘，
角落，
画面安全区之外的视觉过渡处。

不要进入步骤信息核心区域。

不要因为“手账风”而把整个画面塞满贴纸和小物件。

【顶部装饰】
顶部右侧可以有一个与主题相关的小型概念物件或抽象产品道具，
用于平衡大标题。

例如：

卡片，
书本，
设备，
文件夹，
小型物品。

它必须与当前主题相关，
而且不能比标题醒目。

如果没有合适物件，
可以不添加。

【植物装饰】
可以在画面边缘加入非常轻量的绿色叶片。

例如：

左下角露出几片叶子；
右上角出现少量植物枝叶。

叶片可以略有水彩感和景深感。

不要形成完整室内场景。

植物只是柔化边缘。

【版式边框】
可以在整张画面边缘加入非常细的双线或单线编辑边框。

颜色使用深蓝或浅蓝。

边框可以带：

非常轻的古典书页转角；
微弱装饰性折角；
极简细线。

不要使用厚边框。

不要做成证书、奖状或邀请函。

【字体系统】
整张图建议使用 3 类文字气质：

1. 主标题：
   手写毛笔 / 马克笔式中文标题。

2. 步骤标题：
   清楚的手写黑体或自然手写体。

3. 界面与正文：
   现代无衬线字体。

必要的英文、代码、账号字段可以使用：
等宽字体或简洁无衬线。

不要全图都用同一种手写字体。

也不要混用太多字体。

【纸面和水彩质感】
加入非常轻的：

纸张颗粒，
水彩边缘，
淡彩刷痕，
轻微墨水不均，
印刷颗粒。

这些质感用于增加手账与印刷气质。

不要让画面变脏。

文字和界面必须保持清楚。

【边缘水彩】
允许在画面 1–2 个角落加入淡淡的水彩刷痕。

例如：

左下角暖红 / 橙红色水彩；
右上角浅蓝 / 深蓝色水彩。

色彩像干刷或颜料边缘，
带一点颗粒和自然毛边。

不要形成四周完整彩色边框。

它们只负责增加视觉平衡和手工感。

【比例与构图】
默认采用 5:2 超宽横版。

5:2 特别适合：

顶部大标题；
中间横向 3 步教程；
底部一条关键提示；
右下角小人物；
边缘少量装饰。

如果使用 16:9：
适当增加上下留白，
步骤卡可以稍高。

如果步骤只有 2 个：
放大卡片，但不要填满画面。

如果步骤为 4 个：
适当减少卡片宽度，
仍然保持清楚阅读。

不要机械把同一版式裁切成其他比例。

【信息层级】
阅读顺序必须严格清楚：

1. 主标题
2. 副标题
3. 步骤编号与步骤标题
4. 操作界面
5. 红色重点标记
6. 底部关键提示
7. 人物与装饰细节

不要让装饰与教程信息竞争。

【信息密度】
信息密度保持中等。

这不是极简封面，
但也不是完整操作说明书。

每一个步骤卡只回答：

“这一阶段要做什么？”
“最重要的操作位置在哪里？”

详细解释应被省略。

不要在图里完整复制一篇教程文章。

【生成前检查】
生成前内部检查：

主标题是否是一眼最醒目的内容？

是否存在清楚的 2–4 步教程结构？

每一步是否有：
编号 + 标题 + 界面 / 示意 + 一个重点？

步骤之间是否有明确箭头？

界面是否只展示当前步骤必要的信息？

红色标记是否足够少且明确？

底部是否只有一个关键提示？

人物是否最多只有一位，而且足够小？

植物、书本等装饰是否只存在于边缘？

整体是否仍然有足够留白？

画面是否更像一本高级手绘教程手册，
而不是 PPT 或 App 截图拼贴？

如果某个装饰不能帮助：
层级，
平衡，
亲和力，
阅读，

删除它。

【必须避免】
不要企业 PPT。
不要 SaaS 仪表盘。
不要纯截图拼贴。
不要复杂流程图。
不要大量小字。
不要密集 UI。
不要霓虹科技风。
不要深色背景。
不要 3D。
不要写实人物摄影。
不要大量高饱和色。
不要贴纸合集。
不要儿童手账风。
不要让人物抢主体。
不要虚构用户未提供的品牌 Logo。
不要复制知名动漫角色或品牌角色。
不要让水彩纹理影响文字阅读。
不要出现 {{可选禁用元素}}。

【最终标准】
最终只生成一张完整独立教程图解。

不要输出：
多个方案，
拼图，
样机，
版式拆解，
分析过程，
联系表。

最终成图必须同时具备：

暖米白纸张背景；
深蓝色大号手写标题；
小型章节标签；
一行清楚副标题；
2–4 个横向教程步骤；
每一步有大号彩色编号；
柔和浅蓝 / 浅绿 / 浅紫步骤区域；
清楚的界面截图或示意；
少量红色手绘箭头和框选；
清楚的步骤间连接箭头；
底部一个关键提示区域；
最多一个右下角小型手绘人物；
少量书本、植物或纸张边缘装饰；
轻微水彩和纸张质感；
明显的编辑网格与信息层级；
充足留白。

最终效果应像：

一本精致的手绘产品教程，
被重新排版成一张横向杂志式知识图解。

第一眼看到主题，
第二眼看懂三步操作，
第三眼注意到红色重点和底部提醒，
最后才发现角落里的水彩、植物和小人物。

不是“截图加说明”，

而是“把一个操作教程做成一张温暖、清楚、值得收藏的手绘编辑信息图”。
```
