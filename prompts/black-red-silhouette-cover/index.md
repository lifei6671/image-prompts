# 黑红剪影封面

![预览图](preview.webp)

## Prompt

```text
请根据下面的用户输入，创作一张「黑红剪影」风格的极简视觉封面。

整张画面严格使用：

红色
+
黑色
+
白色

三种颜色。

红色负责空间、情绪和整体视觉基调；
黑色负责主体、剪影和主要叙事；
白色只负责标题、极少量高光和必要点睛。

整体应像：

一块巨大的纯红舞台
+
一个具有明确动作和叙事关系的黑色剪影
+
少量克制的白色文字。

画面必须极简、干净、直接、有冲击力。

不要依靠复杂效果制造视觉张力，
而是通过：

红黑面积关系，
主体轮廓，
动作，
空间，
方向，
比例，
负空间

完成设计。

────────────────

【用户输入】

主题词 / 主标题：
{{填写必须准确显示的主标题}}

副标题：
{{可留空}}

画幅比例：
{{5:2 / 16:9 / 4:5 / 3:4 / 9:16 / 1:1 / 其他}}

语言：
{{中文 / 英文 / 中英混排}}

用途：
{{公众号封面 / X 封面 / 视频封面 / 海报 / 文章封面 / 其他}}

核心场景：
{{可留空；未指定时根据主题自动设计一个最合适的场景}}

主体动作：
{{可留空；未指定时根据主题自动选择一个最有表达力的动作}}

视觉隐喻：
{{可留空；未指定时根据主题自动提炼一个清晰、直接、容易理解的隐喻}}

补充语境：
{{内容背景 / 行业 / 受众 / 场景，可留空}}

情绪倾向：
{{冷峻 / 紧张 / 专注 / 速度 / 压迫 / 秩序 / 克制 / 高级 / 其他，可留空}}

不想出现的元素：
{{可留空}}

────────────────

【设计目标】

先理解主题真正要表达的：

人物，
行为，
关系，
冲突，
状态，
方向，
压力，
速度，
控制，
观察，
突破，
等待，
风险，
选择，
竞争，
或其他核心含义。

然后将其压缩为：

一个核心场景，
一个主要主体或不可拆分的主体组合，
一个明确动作，
一个清晰视觉隐喻。

不要把多个概念同时塞进画面。

最终画面应做到：

远看：
先看到红色空间和黑色主体。

再看：
理解主体动作和隐喻。

最后：
读取标题信息。

视觉叙事的重要性高于文字。

────────────────

【颜色系统】

严格只使用三种颜色：

红色，
黑色，
白色或暖白色。

不得出现其他综合色彩。

红色：

承担大部分背景面积，
形成强烈、完整、统一的视觉空间。

优先使用鲜明但不过度荧光的正红、深红或略带复古感的高纯度红色。

整张图只使用一种主要红色。

不要同时使用多个不同红色建立复杂层次。

黑色：

承担核心主体，
主要剪影，
环境结构，
必要的道具，
少量空间切割。

黑色应形成完整、清楚、容易识别的大形。

白色：

只用于：
主标题，
副标题，
极少量关键高光，
必要的视觉点睛。

白色面积必须保持克制。

综合色彩优先级：

红色面积最大，
黑色第二，
白色最少。

────────────────

【背景】

背景使用大面积纯红色。

让红色像一个完整舞台、幕布或抽象空间。

背景保持：

平坦，
干净，
纯粹，
安静。

不要加入：

渐变天空，
写实环境，
复杂建筑背景，
综合色块拼贴，
纹理墙面，
纸张质感，
颗粒，
做旧，
污渍，
光晕，
霓虹，
复杂照明。

如果场景确实需要环境信息，
只使用极少量黑色几何结构建立空间。

例如：

一条地面线，
道路，
平台，
门框，
窗框，
桌面，
屏幕轮廓，
远处城市剪影，
极简建筑边缘。

所有环境必须服从核心主体。

────────────────

【核心主体】

每张图只保留一个主要视觉主体，
或者一个不可分割的主体关系。

主体必须以黑色剪影为主。

要求：

轮廓明确，
动作清楚，
姿态有辨识度，
远距离仍能理解主体在做什么。

不要依赖：

面部细节，
服装纹理，
真实材质，
复杂内部结构

来建立识别。

优先通过：

头部角度，
身体姿态，
手臂位置，
腿部方向，
道具轮廓，
主体与环境的空间关系

传达行为。

人物不表现写实五官。

如果脸部方向对于叙事必要，
最多使用非常少量白色负形或轮廓切口建立方向感。

不要画真实人脸。

────────────────

【视觉隐喻】

视觉隐喻必须：

简单，
直接，
容易理解，
能够被一个画面表达。

不要为了“有设计感”而增加与主题无关的元素。

避免默认使用：

巨大的手，
锁链，
齿轮，
流水线，
机械装置，
芯片，
复杂网络，
随机箭头。

只有当这些元素与主题存在直接语义关系时才使用。

优先寻找动作本身形成的隐喻。

例如：

追逐 → 竞争 / 速度

攀爬 → 突破 / 困难

观察屏幕 → 分析 / 控制 / 工作

站在巨大结构前 → 压力 / 未知

穿过门或边界 → 转变 / 突破

被结构包围 → 限制 / 压迫

人与机器相对 → 人机关系

多主体面对同一方向 → 协作 / 共同目标

主体与隐喻尽量合并成同一个视觉事件，
而不是“人物 + 一个额外符号”的简单拼贴。

────────────────

【主题转译原则】

根据主题类型选择更自然的场景语言。

工具 / 教程类：

优先表现“人正在实际使用工具”。

可以使用：

人物，
屏幕，
键盘，
鼠标，
终端轮廓，
光标，
简单工作台。

重点表现人与工具之间的动作关系，
不要把界面做成复杂 UI 截图。

AI 主题：

优先使用：

人，
屏幕，
光标，
极简脑形符号，
节点，
对话关系，
人机交互，
极简界面轮廓。

不要默认画机器人。

金融 / 投资主题：

可以使用：

牛或熊的简化轮廓，
观察者，
价格曲线，
高低差，
上升 / 下跌空间结构，
博弈关系。

不要制作复杂金融信息图。

速度主题：

可以使用：

车辆，
道路，
奔跑人物，
远方目标，
速度方向，
极简速度线。

速度线必须少而明确。

电影 / 文化主题：

优先寻找：

最具有代表性的姿态，
人物关系，
场景轮廓，
动作瞬间。

不要复刻复杂电影截图。

安全 / 风险主题：

可以使用：

边界，
门，
观察者，
阻挡结构，
危险方向，
主体与巨大黑色结构之间的关系。

协作主题：

可以使用：

两个或少量主体的同步动作，
共同推动，
共同观察，
共同前进。

不要简单使用握手图标。

其他主题也遵循同样原则：

先理解核心关系，
再设计动作和场景，
不要简单把主题名词画成一个图标。

────────────────

【剪影语言】

主体采用高度概括的黑色平面剪影。

重点保留：

最有辨识度的外轮廓，
关键动作，
重要道具，
主体关系，
空间方向。

删除：

服装细节，
皮肤细节，
复杂五官，
材质，
高频纹理，
不必要结构。

允许使用少量红色负形切入主体内部，
帮助区分：

手臂，
腿部，
道具，
人物之间的重叠。

必要时允许极少量白色高光，
但只用于真正需要强调的关键点。

剪影应像：

舞台动画中的图形角色，
极简政治海报中的人物符号，
现代编辑插画中的平面形体。

不要变成普通照片抠图后的纯黑轮廓。

需要主动重新概括和设计形状。

────────────────

【动作】

主体必须有明确动作或状态。

优先选择具有方向性的动作，例如：

走，
跑，
坐，
站，
抬头，
低头，
观察，
操作，
伸手，
拉动，
推开，
攀爬，
驾驶，
追逐，
等待，
对峙，
穿越，
奔向远方。

不要默认生成：

人物正面站立，
双手自然下垂，
没有叙事的静态肖像。

如果主题适合静态表达，
也应通过：

身体方向，
人与空间的比例，
视线方向，
环境关系

形成张力。

────────────────

【构图】

严格按照用户填写的画幅比例设计。

比例只决定画布尺寸，
不要显示比例文字。

构图根据：

主体方向，
动作，
标题长度，
画幅比例，
视觉隐喻，
负空间

自适应调整。

不要套用固定模板。

红色负空间是重要构图元素，
不要害怕大面积空白。

画面需要形成一个非常明确的黑色形状重心。

主体可以：

偏左，
偏右，
居中，
靠近底部，
被画面边缘适度裁切，
沿对角线运动，
进入或离开画面。

位置由动作决定。

不要机械居中。

────────────────

【横版构图】

横版封面优先利用水平方向建立叙事。

可以使用：

左侧主体 + 右侧空间，
右侧主体 + 左侧空间，
主体沿水平方向运动，
近景主体 + 远方目标，
黑色主体与大面积红色负空间形成对比。

标题放在：

居中偏左，
居中偏右，
上方留白，
或主体运动方向之外的空白区域。

文字必须避让主体。

主体场景始终是第一视觉。

────────────────

【竖版构图】

竖版优先强化：

高度，
上下关系，
人物动作，
压迫感，
距离，
空间层级。

主体可以占据画面中部或中下区域。

标题优先放在：

顶部中央，
顶部偏左 / 偏右，
或底部中央。

标题不要占据过多面积。

中间主体必须成为绝对主视觉。

────────────────

【文字】

只显示用户明确提供的文字。

允许：

主标题，
副标题。

除此之外不要增加任何文字。

不得自行添加：

英文翻译，
日期，
编号，
标签，
Logo，
品牌名，
网址，
说明文字，
装饰性假文字，
宣传语。

如果副标题为空，
只显示主标题。

如果主标题和副标题均为空，
不要生成文字。

────────────────

【主标题】

主标题使用白色或暖白色。

必须准确呈现用户提供的原文：

不改写，
不删减，
不自动翻译。

字体要求：

清晰，
简洁，
有力量，
适合极简海报。

中文可使用：

现代黑体，
几何黑体，
粗黑体，
窄体黑体。

英文可使用：

sans-serif，
grotesk，
condensed sans-serif。

字体不需要花哨。

主要通过：

字号，
字重，
位置，
留白

形成力量感。

不要使用：

复杂描边，
立体字，
霓虹字，
渐变字，
复杂投影。

────────────────

【副标题】

副标题如果存在：

使用白色或暖白色，
字级明显小于主标题，
视觉权重明显较弱。

保持简洁清楚。

不要把副标题设计成第二主标题。

────────────────

【图文关系】

主体场景必须比文字更重要。

观看顺序应该是：

黑色剪影
→
动作与场景
→
红色空间关系
→
主标题
→
副标题。

不要让超大文字覆盖整个画面。

不要用文字替代视觉表达。

文字的位置应由主体轮廓决定。

标题可以与主体：

并置，
错位，
上下对应，
沿空间边缘排列，

但不要遮挡主体的关键动作。

────────────────

【视觉层级】

第一层：
黑色核心主体和动作。

第二层：
纯红色空间以及主体形成的视觉隐喻。

第三层：
白色主标题。

第四层：
副标题和极少量白色点睛。

如果出现其他视觉信息，
应主动删除。

────────────────

【最终视觉效果】

最终作品应呈现：

大面积纯红背景
+
一个清晰黑色剪影主体
+
一个明确动作
+
一个简单视觉隐喻
+
极少量白色文字
+
强烈的红黑面积关系。

整体感觉：

极简，
冷峻，
直接，
有力量，
克制，
高级，
具有戏剧张力，
具有现代编辑封面感。

即使缩小到很小尺寸，
仍然应该清楚看到：

一个红色画面，
一个黑色主体，
一个明确动作。

不要依赖细节才能理解主题。

────────────────

【生成前内部检查】

生成最终画面前检查：

是否严格只有红、黑、白三种颜色；

红色是否承担大部分画面面积；

是否只有一个核心场景；

是否只有一个主要动作；

是否只有一个清晰视觉隐喻；

主体是否主要使用黑色剪影；

主体轮廓是否远距离仍然容易识别；

是否避免写实人物五官；

是否避免复杂环境；

是否只显示用户提供的主标题和副标题；

主体场景是否明显比文字更重要；

是否保留了足够红色负空间；

是否没有为了设计感加入无关元素。

────────────────

【避免】

不要出现蓝色；

不要出现紫色；

不要出现绿色；

不要出现棕色；

不要出现金色；

不要出现银色；

不要出现彩色综合色调；

不要出现灰脏色；

不要使用复杂渐变；

不要霓虹光效；

不要赛博蓝光；

不要真实摄影感；

不要写实人物脸；

不要复杂五官；

不要 3D 渲染；

不要玻璃质感；

不要金属质感；

不要纸张颗粒；

不要复古做旧；

不要脏污纹理；

不要磨损边缘；

不要仿旧印刷；

不要复杂背景；

不要密集装饰；

不要复杂 UI；

不要大量信息面板；

不要复杂信息图；

不要无关大手；

不要无关锁链；

不要无关机械装置；

不要未经用户提供的额外文字；

不要让标题成为画面唯一主视觉；

不要让文字压过主体场景。
```
