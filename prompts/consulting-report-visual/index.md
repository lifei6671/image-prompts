# 咨询报告视觉

## Prompt

````text
# 咨询报告视觉

## Prompt

```text
创作一张高端管理咨询报告式视觉封面。

整体采用“文字主导 + 标题结构重构 + 单一商业隐喻 + 瑞士现代主义网格 + 克制完整的报告层级 + 专业限色系统”。

这不是普通 PPT 封面、解释型信息图或粗体自媒体海报。

观者第一眼应看到经过结构化设计的核心词，
第二眼读取完整标题，
第三眼理解隐藏在文字、网格和空间结构中的商业判断。

图形必须从文字结构内部生长，
而不是在标题旁边另外摆放图表、图标或插画。

【输入】
主题词 / 主标题：{{主题词}}
副标题：{{副标题，可留空}}
画幅比例：{{画幅比例}}
语言：{{中文 / 英文 / 中英混排}}
用途：{{用途}}
可选补充语境：{{补充背景，可留空}}
可选情绪倾向：{{情绪倾向，可留空}}
可选禁用元素：{{不想出现的元素，可留空}}

【核心目标】
先理解“{{主题词}}”与“{{补充背景}}”真正表达的商业问题。

从以下关系中寻找最重要的一种：
战略方向，
增长约束，
竞争边界，
风险阈值，
资源配置，
组织效率，
价值兑现，
市场窗口，
技术突破，
产业迁移，
决策取舍，
结构性变化。

提炼一个单一、明确、有判断力的商业观点，
并把它转译成：

1 个主视觉核心词，
1 个核心商业隐喻，
1 套连续空间结构。

整张图只围绕这个观点展开。

不要试图把文章里的所有观点、章节、步骤和分析框架同时画出来。

最终效果应该更像“提出一个高级商业判断”，
而不是“解释一套方法”。

【信息层级】
整个封面建立三个严格层级：

A 层：主视觉核心词
B 层：完整标题与副标题
C 层：少量报告标签与版式信息

视觉优先级必须明确：
A 层 → B 层 → C 层。

不要让三个层级拥有相同视觉重量。

【A 层：主视觉核心词】
如果 {{主题词}} 较长，
自动从完整标题中提炼 2–8 个最有张力、最适合结构化表达的中文字符或等量英文核心词。

A 层是整张封面的视觉主体。

核心词可以巨大，
但不要依赖 extra-bold、超粗黑或压缩文字制造冲击力。

优先通过以下方式建立张力：
尺度，
结构，
负空间，
透视，
切割，
错位，
路径，
轮廓，
空间深度，
网格关系。

A 层文字可以进行：
切割，
镂空，
分层，
错位，
框架化，
路径化，
收束，
断层化，
空间化，
矩阵化，
轮廓与实体混合。

但必须保持原文字准确、完整可识别。

不要生成乱码、伪字或破坏阅读的实验字体。

【文字成为商业结构】
A 层文字不能只是普通标题。

它本身要成为商业隐喻的空间载体。

例如：

战略路径可以进入字形内部；
路径可以沿笔画延伸并最终收束到一个目标点；

风险断层可以切开部分字形，
形成一道明确但克制的结构裂隙；

坐标轴可以成为文字的骨架，
让字形存在于一个分析空间中；

窗口可以出现在文字负空间内部；

阈值线可以穿过字形，
形成“突破前 / 突破后”的结构关系；

价值阶梯可以由文字底部向某个方向延伸；

多条细线可以从字形内部逐渐收束到一个消失点。

商业隐喻必须真正改变文字结构，
或者从文字结构内部生长出来。

禁止使用：
普通标题 + 独立图标，
普通标题 + 漏斗，
普通标题 + 矩阵，
普通标题 + 泡泡图，
普通标题 + 流程图。

【核心商业隐喻】
整张图只使用一个核心商业隐喻。

根据主题自动选择最准确的一种，例如：
战略路径，
阈值，
防线，
结构断层，
坐标，
收束点，
市场窗口，
矩阵边界，
价值阶梯，
风险轮廓，
决策终点，
突破界面。

这里只选择一个。

其他线条、节点和标注只负责强化这个隐喻，
不得发展成第二套叙事。

隐喻应让观者在看到标题后能够理解：
为什么文字被这样切割，
为什么路径朝这个方向延伸，
为什么某个点被强调，
为什么某条线成为边界。

【B 层：完整标题】
完整保留用户输入的：
“{{主题词}}”

B 层负责承担完整语义。

可以放置在：
页眉，
标题带，
画面边缘，
右上角信息区，
左下角报告信息区，
主视觉附近的次级区域。

字号明显小于 A 层，
但必须清晰可读。

不要因为 A 层已经提炼核心词而省略完整标题。

如果输入副标题，则准确显示：
“{{副标题}}”

副标题明显小于完整标题，
最多一行或极短两行，
不要扩展成长说明。

【C 层：报告标签】
C 层只保留 1–3 个非常短的报告级信息。

可以包括：
年份，
章节编号，
研究标签，
行业名称，
报告类型，
简短栏目索引。

例如视觉形式：
2026
STRATEGY
INSIGHT 01
SECTOR REVIEW
AI / SaaS

这些只是版式家具，
不是内容主体。

不要生成大量小字。
不要使用徽章、胶囊按钮或社交媒体标签形式。

如果用户没有提供足够信息，
宁可减少标签，
不要虚构公司名称、机构、数据或报告出处。

【整体报告气质】
整体呈现高端管理咨询报告、战略研究报告和董事会级材料的视觉气质。

关键词：
理性，
精准，
克制，
可信，
结构化，
高级，
专业，
决策导向，
boardroom-ready。

结合瑞士现代主义设计原则：
严格网格，
明确对齐，
非对称平衡，
清楚层级，
大量负空间，
精确细线，
功能性排版。

不要做成普通企业 PPT 模板。

【背景】
背景优先使用：
纯白，
极浅冷灰，
银灰白，
带轻微冷调的纸面白。

保留大面积干净留白。

但留白不能意味着“什么都没有”。

背景至少建立一套连续、完整、能够被感知的空间系统。

可选择其中一种作为主结构：
单点透视网格，
坐标系统，
同心风险轮廓，
结构断层线，
构造网格，
路径残影，
分析等高线，
远处收束线。

整个系统应覆盖或连接画面的大部分区域，
让留白本身具有方向和结构。

不要只画几根几乎看不见的辅助线。

【网格与空间】
建立严格而克制的瑞士式网格。

可以存在：
主网格，
次级透视线，
边缘坐标，
细小刻度，
结构轮廓，
阈值边界。

网格必须参与：
文字定位，
隐喻构建，
空间组织，
阅读路径。

不要只是背景装饰。

可以通过单点透视让所有结构最终收束到一个远处目标点。

也可以让核心词位于一个抽象分析空间中，
细线从字形边缘向远处延伸，
建立理性而具有方向感的深度。

【背景分析标注】
允许围绕同一个核心隐喻加入 2–4 个极短背景标注。

例如根据主题语义自动提炼：
技术突破，
行业复制，
组织采用，
商业兑现。

或者：
成本，
规模，
风险，
价值。

这些标注必须存在于同一个坐标或分析空间中。

它们只是分析注释，
不是四步骤流程。

不要加入：
01 → 02 → 03 → 04，
四张卡片，
多个流程节点，
完整时间线。

【结构线】
图形只使用极简精准的结构语言。

可以包括：
极细直线，
坐标轴，
轮廓线，
一个方向箭头，
少量节点，
单一终点，
消失点，
阈值线，
细线框架。

所有图形都必须服从核心词。

最多存在一个明确方向箭头或一个强调节点。

不要堆叠大量箭头、连线和节点。

【可选风险轮廓】
如果主题涉及：
风险，
不确定性，
扩散，
预期，
边界，
影响范围，

可以使用：
半透明同心轮廓，
波纹，
弧形边界，
等高线，
风险泡沫边界。

但这些轮廓必须与：
字形，
坐标，
路径，
阈值
发生直接结构关系。

不要单独放一个泡泡图作为插图。

【构图】
根据 {{画幅比例}} 原生设计构图。

优先采用：
宽阔横向报告封面，
严格网格，
大面积负空间，
偏心视觉中心，
不对称平衡。

建议整体形成：
一个大型 A 层核心词区域，
一个清晰 B 层完整标题区域，
少量 C 层报告信息，
一套贯穿背景的空间系统。

不要把页面平均切成多个模块。

不要使用多个同等权重的卡片。

页眉、页脚和边缘信息带可以存在，
但必须：
轻，
薄，
小，
准。

【字体】
中文使用：
现代黑体，
克制的现代无衬线，
宋黑混合气质，
现代编辑字体。

英文使用接近：
Helvetica，
Neue Haas Grotesk，
Univers，
Swiss-style sans-serif
的现代主义无衬线气质。

A 层字重优先：
Regular，
Medium，
适度 Semi-bold。

允许：
细线轮廓字，
半镂空字，
实体与轮廓混合，
结构化字体。

不要默认使用超粗黑。

字体可以巨大，
但画面不能形成一堵沉重的黑色文字墙。

视觉张力主要来自：
空间，
结构，
尺度，
负空间，
透视，
而不是单纯靠字体粗度。

【色彩】
整体采用专业咨询报告限色系统。

主要使用：
白，
深蓝，
冷黑，
冷灰，
浅灰，
银灰。

最多选择一种强调色。

可选：
蓝，
橙，
红，
绿。

强调色只能用于一个关键语义点，例如：
决策点，
风险点，
突破点，
价值点，
终点，
唯一方向箭头。

面积必须非常小。

不要同时使用多个强调色。

不要使用：
大面积暖色，
彩虹渐变，
蓝紫霓虹，
高饱和赛博配色，
广告式渐变光。

【质感】
整体保持干净的哑光纸面和高级印刷感。

允许：
极轻微纸张颗粒，
细腻印刷纹理，
非常浅的空间阴影，
精准细线，
轻微层次差。

这些质感只负责增强实体报告封面的完成度。

不要使用：
玻璃拟态，
塑料 3D，
金属高光，
科技 HUD，
强发光，
厚重投影。

【情绪】
根据 {{可选情绪倾向}} 微调构图。

理性：
强化网格、对齐和冷色秩序。

战略：
强化方向、路径和远处终点。

风险：
突出阈值、边界与唯一风险点。

增长：
强调向上或向远处收束的结构。

转折：
使用明确断层、错位或跨越关系。

未来：
增加抽象空间深度，但仍保持专业克制。

压迫：
缩小安全空间，让边界或阈值逼近主体。

情绪必须通过结构表达，
不要加入装饰性视觉特效。

【用途适配】
根据 {{用途}} 调整封面信息密度。

咨询报告封面：
保持最完整的 A / B / C 三层结构和报告家具。

PPT 首页：
适当减少 C 层信息，扩大留白。

公众号 / 社交媒体封面：
提高 A 层与 B 层在缩略图下的识别度，
减少过细的背景标注。

研究报告：
可以适量增加报告索引、年份和研究标签，
但仍然保持封面而非内容页。

【必须避免】
不要生成虚假详细数据。
不要虚构复杂图表。
不要生成密集小字。
不要伪造咨询机构、企业、研究机构或报告出处。

不要把完整长标题做成巨型 extra-bold 文字墙。
不要使用粗黑、拥挤、压迫性的自媒体标题。

不要制作：
三步以上流程，
节点时间线，
完整漏斗，
完整矩阵，
复杂路线图，
仪表盘，
方法论说明页。

不要让结构图成为画面主体。
不要让图形和标题相互独立。

不要堆叠：
大量图标，
大量箭头，
大量节点，
大量标签，
模块卡片，
说明文字。

不要让 A 层核心词孤立漂浮在近乎空白的背景中。
必须存在连续背景空间系统。

不要省略 B 层完整标题。
不要把完整标题缩小到无法阅读。

不要使用：
廉价商务模板，
握手照片，
办公会议场景，
普通商务人物，
通用科技素材。

不要加入 {{可选禁用元素}}。

【最终检查】
最终只生成一张独立完整的高端咨询报告封面。

不要输出：
多方案，
拼图，
样机，
内容页，
图表页，
设计过程，
版式拆解。

最终成图必须同时满足：

A 层：
存在一个经过结构重构的主视觉核心词；

B 层：
完整标题清晰可读，副标题按输入保留；

C 层：
只有极少量报告级标签；

存在且只有一个核心商业隐喻；

商业隐喻真正嵌入文字结构；

背景存在一套连续、可感知的细线空间系统；

拥有严格网格、大面积经过设计的负空间和明确视觉中心；

色彩专业克制，只存在一种极少量强调色；

文字承担主要视觉权重，
但没有粗黑社媒海报感；

图形精准、少量、服从标题；

远看像成熟战略咨询报告封面，
近看具有精确的网格、坐标、路径、标注和印刷细节。

最终效果应该像一份专门针对“{{主题词}}”进行视觉构思的高级战略研究报告：
理性、准确、克制、有判断，
能够直接用于董事会、战略会议、产业研究或专业咨询场景。
```
````
