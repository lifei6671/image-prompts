# 极简视觉隐喻风

## Prompt

````text
# 极简视觉隐喻风

## Prompt

```text
围绕用户提供的完整标题，创作一张高级、极简、可读的商业科技编辑封面。

不要直接把标题中的名词画出来。

先理解标题真正表达的：
主体，
对象，
关系，
动作，
变化方向，
最终结果。

再从中提炼一个最重要的“核心动作”，
将这个动作转译成一个真实存在、结构精确的小型抽象实体装置。

整个画面的视觉逻辑是：

完整标题负责准确命名主题；
抽象装置负责表达关系、动作与结果。

最终效果应像一件被放入当代画廊中的编辑雕塑：

安静，
精确，
克制，
真实，
具有明确语义，
但不直白。

不是图标，
不是信息图，
不是 PPT，
不是说明书插图，
也不是泛化的科技 3D 装饰。

【输入】
主题词 / 完整标题：{{主题词}}
画幅比例：{{5:2 / 16:9 / 1:1 / 4:5 / 其他}}
语言：{{中文 / 英文 / 中英混排}}
用途：{{X 封面 / 公众号封面 / 文章封面 / 报告题图 / 其他}}
核心动作：{{连接 / 汇聚 / 对齐 / 推进 / 拆解 / 穿透 / 折叠 / 平衡 / 转化 / 生长 / 跨越 / 其他，可留空}}
抽象实体：{{根据主题自动设计，可留空}}
人物动作：{{调整 / 连接 / 推进 / 观察 / 完成最后一步 / 不使用人物，可留空}}
可选补充语境：{{补充背景，可留空}}
可选情绪倾向：{{冷静 / 精确 / 克制 / 推进 / 平衡 / 其他，可留空}}
可选禁用元素：{{不想出现的元素，可留空}}

【核心原则】
整张封面只允许：

1 个完整标题；
1 个核心动作；
1 个抽象装置；
1 个视觉故事；
1 个明确视觉中心；
最多 1 位小比例人物。

不要同时表达多个观点。

不要建立多个隐喻。

不要设计多个同等权重的物体组合。

一张图只回答一个问题：

“这里正在发生什么？”

【语义转译】
生成前先在内部分析“{{主题词}}”。

提炼：

谁或什么正在发生变化？
两个对象之间是什么关系？
变化从哪里开始？
动作朝什么方向进行？
结果是什么？

再从中选择一个最能代表主题的核心动作。

优先使用：

连接，
汇聚，
对齐，
推进，
拆解，
穿透，
折叠，
平衡，
转化，
生长，
跨越。

如果用户已经提供 {{核心动作}}，
围绕该动作建立装置。

如果没有提供，
自动选择最准确的一种。

不要展示分析过程。

【动作必须可见】
核心动作不能只存在于概念解释中。

它必须通过真实空间关系被直接看见。

例如：

连接：
两个独立模块通过唯一接口发生接触。

汇聚：
多条结构逐渐收束到一个共同核心。

对齐：
原本错位的模块正在进入同一轴线。

推进：
一个实体沿明确路径推动另一个结构进入下一状态。

拆解：
一个完整结构沿清楚逻辑逐层分离。

穿透：
一个实体穿过另一层材料或边界。

折叠：
一个连续结构从展开状态转入压缩状态。

平衡：
两个不同重量或体量的对象形成稳定关系。

转化：
同一个结构从一种材料、形态或秩序逐渐变成另一种状态。

生长：
一个基础模块沿单一方向延伸、复制或展开。

跨越：
一个结构正在通过连接件、桥梁或悬跨关系跨过明确间隔。

观众即使暂时不看标题，
也应能够感到：

“某个关系正在发生变化。”

【抽象装置】
将核心动作设计成一个小型实体雕塑装置。

装置应介于：

高级编辑静物，
建筑模型，
工业设计原型，
当代画廊雕塑

之间。

如果用户提供 {{抽象实体}}，
优先围绕该实体构建。

否则自动设计。

装置必须：

结构简单；
比例可信；
具有真实重量；
接触关系明确；
能够在现实中被制作出来；
轮廓在缩略图中仍然清楚。

优先使用 2–5 个真正必要的结构组件。

不要堆叠几十个小零件。

【实体关系】
每一个物体都必须承担语义。

它可以承担：

起点，
终点，
阻碍，
路径，
连接，
支撑，
边界，
压力，
变化后的状态。

如果一个物体删除后完全不影响主题理解，
删除它。

不要为了丰富画面加入：

球体，
圆环，
玻璃片，
小方块，
线条，
平台

等无语义装饰。

【材料系统】
材料严格控制在：

哑光石墨金属，
炭黑精密模块，
磨砂半透明墨绿色玻璃。

可以少量使用深灰结构材料。

整体必须具有真实材料表现：

重量，
接触，
摩擦，
透明度，
折射，
厚度，
边缘，
连接方式。

石墨金属：
哑光、细腻、沉稳，不产生镜面高光。

黑色模块：
精密、结构清楚、边缘克制。

墨绿色玻璃：
低饱和、半透明、磨砂，可看到轻微内部层次和折射。

不要引入额外高饱和颜色。

【材质逻辑】
材质选择应帮助表达主题。

例如：

稳定结构可以使用石墨金属；

发生变化、过渡或连接的部分可以使用半透明墨绿色玻璃；

关键接口可以通过黑色精密模块表达。

不要为了好看随机更换材质。

材料变化本身可以成为隐喻的一部分。

【人物】
人物不是默认元素。

只有当人物能明显增强：

尺度，
动作，
叙事触点

时才使用。

最多一人。

人物必须明显小于抽象装置。

可以让人物：

调整一个模块，
连接最后一个节点，
推动结构，
观察变化，
完成最后一步。

人物姿态：
自然，
真实，
克制，
有明确目的。

不要：
面对镜头，
摆 Pose，
夸张动作，
表现戏剧化表情。

人物不是主角。

装置和核心动作才是主视觉。

如果删除人物后隐喻反而更纯粹，
完全省略人物。

【避免字面科技】
主题即使涉及：

AI，
模型，
软件，
Agent，
算法，
数据，
云计算，
自动化，
互联网

也不要默认使用：

机器人，
机器人头部，
AI 大脑，
芯片，
服务器机柜，
科幻城市，
发光网络，
全息屏幕，
代码雨，
复杂机械。

这些只是科技名词的图标化表达，
不是视觉隐喻。

优先画：
关系，
方向，
接触，
连接，
状态变化。

【背景】
背景固定使用：

暖白，
米白，
极浅暖灰。

可以保留极轻微纸张纹理。

背景必须：
连续，
安静，
干净，
没有真实环境信息。

不要出现：

办公室，
家居空间，
桌面环境，
摄影棚背景布，
展台，
房间，
建筑空间，
地平线。

装置像被直接置于一个无限、安静的编辑空间中。

【留白】
留白必须占据明显视觉面积。

不要填满画布。

留白用于：

突出标题，
突出装置，
制造观察距离，
增加高级感，
形成阅读停顿。

视觉应该像经过策展：

每一个对象都有准确位置，
每一块空白都有存在理由。

【横向构图】
5:2 / 16:9：

默认采用安静的左右关系。

标题位于左侧，
约占画面 50%–55%。

抽象装置位于右侧，
约占画面 40%–45%。

中间保持足够空气。

标题与装置不互相遮挡。

可以通过：

装置朝向，
结构方向，
路径，
开口，
移动方向

让右侧装置在语义上指向标题或与标题建立关系。

不要机械左右五五分。

5:2 超宽比例中进一步减少装置面积，
增加横向留白。

【竖向构图】
4:5 或其他竖版：

标题位于上方或中上区域。

装置位于中下区域。

上下保持明确距离。

不要把标题贴在装置上。

装置尺寸应保持精巧，
不要占满整个画面。

【方形构图】
1:1：

采用偏心结构。

可以：
左上标题 + 右下装置，
上方标题 + 下方装置。

不要平均切成两个相同模块。

保留一块连续的大面积负空间。

【主标题】
必须完整、准确显示：

“{{主题词}}”

不得：

改写，
摘要，
省略，
翻译，
补充，
生成错别字。

标题较长时，
自动按照语义自然断行为 2–4 行。

不要把标题压缩到很小。

也不要让它变成整面黑色文字墙。

【字体】
标题使用高级现代中文无衬线字体气质。

中文倾向：

现代黑体，
Swiss-style 中文无衬线，
几何黑体，
中等至半粗字重。

英文倾向：

modern grotesk，
neo-grotesque，
Swiss sans-serif。

标题颜色主要为：

深石墨色。

字重克制但必须清楚。

不要使用：

超粗标题党黑体，
书法体，
手写体，
装饰字体，
3D 字体，
渐变文字，
发光文字。

【关键词强调】
可以自动从完整标题中选择：

1 个最关键的词，
或
1 个关键数字

使用低饱和墨绿色进行强调。

最多一处。

其余所有文字保持深石墨色。

不要同时强调多个词。

如果强调会破坏整体克制感，
可以完全不使用强调色。

【文字限制】
除了完整标题，
画面中不得出现任何其他可读文字。

不要：

副标题，
英文装饰，
随机单词，
数字编号，
栏目标签，
日期，
注释，
Logo，
品牌，
水印，
边框文字。

标题就是唯一语言信息。

【标题与装置关系】
标题负责：

准确告诉观众“这是什么主题”。

装置负责：

告诉观众“这个主题中发生了什么关系”。

标题与装置必须语义一致，
但不要视觉重叠。

不要：

让标题贴在装置上；
让装置遮挡标题；
让文字变成装置的一部分。

本风格的高级感来自：

两个独立视觉区域，
共同表达同一个观点。

【光线】
采用柔和、真实、方向明确的编辑静物摄影光线。

类似：
大型柔光箱，
自然侧前方柔光，
高端静物摄影。

光线只负责表现：

体积，
材料，
透明度，
接触，
空间距离。

允许：

非常轻的高光，
柔和玻璃折射，
轻微材质明暗。

不要：

轮廓霓虹，
强背光，
硬聚光灯，
大面积发光，
激光，
广告式高光。

【阴影】
阴影必须非常自然。

只使用：
轻微接触阴影，
柔和短投影，
层间细小阴影。

阴影不能变成画面主体。

不要：
深黑阴影，
长距离戏剧投影，
多方向复杂阴影。

装置必须看起来有真实重量，
不是漂浮在空气中。

【色彩系统】
严格使用：

暖白 / 米白；
石墨黑；
炭灰；
低饱和半透明墨绿色。

不要再增加辅助色。

整体彩色面积很小。

墨绿色主要用于：

关键玻璃结构，
变化区域，
唯一关键词强调，
或核心动作发生的位置。

不要大面积铺绿色背景。

【情绪】
根据 {{可选情绪倾向}} 微调空间关系。

冷静：
增加留白和稳定水平关系。

精确：
强化轴线、嵌合和材料边界。

克制：
减少结构数量与人物。

推进：
让装置具有明确单向运动趋势。

平衡：
强化重量和支撑关系。

无论选择什么情绪，
仍然保持：
安静，
高级，
编辑化。

不要依赖视觉特效制造情绪。

【用途适配】
X 封面：
加强横向呼吸感，
标题和装置分别保持清晰。

公众号 / 文章封面：
保证缩略图中标题与核心装置关系仍然明显。

报告题图：
进一步减少装置复杂度，
增加理性和留白。

其他用途：
优先保持“标题 + 单一装置 + 大留白”的核心结构。

【必须避免】
不要把主题做成图标。

不要字面插图。

不要说明书场景。

不要：

信息图，
流程图，
矩阵，
仪表盘，
节点网络，
多个并列步骤。

不要：

赛博朋克，
霓虹，
蓝紫渐变，
机器人，
AI 大脑，
芯片，
科幻城市，
复杂机械，
满屏 UI。

不要：

卡通，
家居摆件风，
廉价 3D，
游戏建模，
塑料材质，
夸张玻璃玩具，
浮夸人物。

不要：

装饰英文，
副标题，
小字，
Logo，
水印，
边框，
无语义装饰线。

不要让标题：

缺字，
错字，
变形，
遮挡，
裁切，
过小，
无法阅读。

严格排除：
{{可选禁用元素}}

【生成前检查】
生成前内部检查：

标题真正表达的关系是什么？

是否只选择了一个核心动作？

不用标题时，
是否仍然能够感觉：
某种连接、汇聚、对齐、推进、折叠、转化或其他关系正在发生？

是否只有一个视觉故事？

装置中的每个组件是否都有语义作用？

是否存在可以删除的物体？

如果删除后不影响主题，
删除。

装置是否真实、可制作、有重量？

是否严格使用：
暖白，
石墨黑，
炭灰，
墨绿色？

是否误用了蓝紫、霓虹或高饱和色？

人物是否真的必要？

如果人物只是装饰，
删除。

标题是否逐字准确、完整、清晰？

画面中是否存在标题以外的其他文字？

如果有，
删除。

留白是否足够？

最终画面看起来是：
画廊中的编辑雕塑，
还是廉价科技 3D？

如果更像后者，
继续简化。

【最终标准】
最终只生成一张独立完整封面。

不要输出：
多个方案，
拼图，
样机，
装置拆解图，
分析过程，
联系表。

最终画面必须同时满足：

1 个完整准确的标题；
1 个核心动作；
1 个抽象实体装置；
1 个视觉故事；
1 个视觉中心；
最多 1 位小比例人物；

暖白或米白背景；
大量连续留白；
哑光石墨金属；
精密黑色模块；
磨砂半透明墨绿色玻璃；
真实重量和接触关系；
柔和统一自然光；
克制接触阴影；
没有多余文字；
没有泛化科技符号；
没有第二隐喻；
没有无意义装饰。

远看时：

先看到准确、安静的标题与一个精巧抽象实体。

近看时：

再发现两个模块之间正在连接、靠近、穿透、折叠、推进、转化或完成最后一个动作。

最终效果应像一件为“{{主题词}}”专门设计的当代编辑雕塑：

标题负责命名，
装置负责思考。

不是把科技画得更复杂，

而是用最少的实体关系，
把最重要的变化说清楚。
````
