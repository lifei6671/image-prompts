# 极简线描白板封面

![预览图](preview.webp)

## Prompt

```text
围绕用户提供的主题，创作一张“极简线描白板插画 × 扁平图标叙事 × 低信息密度知识封面”风格的横版封面。

这不是写实插画，也不是复杂信息图。
重点是：用非常简洁的黑色线描人物、少量图标符号和少量高饱和强调色，做出干净、轻松、现代、易读的知识型封面。
整体像白板手绘图解、科技博客插图、产品说明配图或 YouTube / 公众号知识封面。

【输入】

主题 / 主标题：{{主题}}
核心观点：{{一句话说明真正想表达的判断，可留空}}
副标题：{{副标题，可留空}}
核心元素：{{例如：人物 / 电脑 / 手机 / 灯泡 / 箭头 / 图表 / 齿轮 / 对话框 / 文档 / 云朵 / 放大镜，可留空}}
关键关系：{{例如：输入 → 处理 → 输出 / 学习 → 理解 → 增长 / 创作 → 发布 → 增长，可留空}}
画幅比例：{{默认 16:9}}
语言：{{中文 / 英文 / 中英混排}}
用途：{{文章封面 / 公众号封面 / 博客题图 / 教程配图 / 视频封面 / 知识卡片}}
可选情绪倾向：{{理性 / 轻松 / 清晰 / 友好 / 专注 / 成长 / 乐观}}
可选禁用元素：{{不想出现的元素，可留空}}

【核心视觉结构】

使用典型的“左侧标题 + 右侧插画”横版封面结构。

左侧约占画面 35%–45%，作为主标题区。
右侧约占画面 55%–65%，作为主体插画区。

左侧放置主标题：
“{{主题}}”

标题必须清晰、完整、准确，优先保证可读性。
标题建议分成 2–4 行排布，不要压成很小的一行。
标题整体左对齐，位于左侧视觉中心略偏上位置，保留充足留白。
如有副标题，则放在主标题下方，字号更小，字距舒展，作为补充说明。

右侧使用简洁线描插画表达主题。
可以围绕一个核心人物和 2–4 个核心图标展开。
人物通常为简单可爱的扁平线描人物，黑色轮廓，少量表情，姿态自然。
图标元素可以是电脑、灯泡、箭头、图表、相机、文件、齿轮、聊天气泡、播放按钮、数据增长曲线等。
各元素彼此之间保持适当距离，不要拥挤，不要堆满。

底部可加入一条细黑色水平基线，用来承托人物和图标，让画面更稳定。
个别元素可以略微高低错落，形成节奏感，但整体仍然简洁克制。

【核心原则】

1. 风格优先级：
清晰度 > 版式稳定性 > 标题可读性 > 图标叙事 > 装饰性。

2. 画面必须简洁：
避免高信息密度，避免复杂背景，避免大量说明文字，避免密集小元素。

3. 插画语言必须统一：
所有对象都用统一粗细的黑色线条绘制，保持一致的圆润感、卡通感和简笔感。

4. 人物处理方式：
人物是简洁二维手绘卡通人物，不写实，不复杂，不强调细节纹理。
面部只需简单五官：眼睛、眉毛、嘴巴。
姿态自然友好，可以坐着、站着、指向、点赞、思考、操作电脑等。

5. 图标处理方式：
图标尽量几何化、扁平化、符号化。
不要做成立体图标，不要金属质感，不要复杂阴影。

6. 标题区域与插画区域要明确分工：
左侧负责标题阅读，右侧负责视觉解释。
不要让插画压进标题区，也不要让标题进入右侧主体区。

【标题设计】

主标题使用简洁醒目的无衬线字体风格，字重偏粗，现代、清楚、亲和。
可以是黑色或深灰黑色。
如有重点词，可用蓝色强调，但整体不宜花哨。
文字不需要描边，不需要发光，不需要立体效果。
标题区整体风格要像科技知识图解封面，而不是商业海报广告字。

副标题如果存在，可使用更小的字重和更浅的深灰色，保持简洁。

【插画元素组织方式】

右侧插画通常采用以下方式之一：

A. 单人物 + 3 个图标
例如：
人物坐在电脑前，周围搭配灯泡、箭头、图表。

B. 单人物 + 单设备 + 单结果符号
例如：
人物 + 笔记本电脑 + 上升箭头。

C. 单场景简图
例如：
人物在操作设备，旁边配一个代表“想法”的灯泡和一个代表“增长”的上升曲线。

D. 多元素串联
例如：
输入符号 → 操作设备 → 结果箭头。

所有元素之间留有明显空隙，方便快速扫视理解。

【线条风格】

使用干净、流畅、略圆润的黑色线描。
线条粗细统一，中等偏粗，像高质量白板马克笔或数码简笔插画。
边缘平滑，造型简洁，不追求真实比例。
细节尽量减少，用最少线条表达清楚对象。

不要粗糙草稿感。
不要过多手写涂抹。
不要复杂排线。
不要纹理堆叠。

【背景】

背景使用纯净、明亮、接近白板或浅暖灰白的纯色背景。
推荐：
米白色、浅灰白、暖白色、极浅奶油灰。

背景必须非常干净，不加复杂纹理，不加场景，不加渐变天空，不加桌面实景。
可以有极轻微纸感，但整体观感仍然接近简洁白板背景。

【主色系统】

整体配色非常克制，以黑色线条为主，少量高亮强调色点缀。

推荐配色结构：

主线条色：
黑色 / 深灰黑

背景色：
暖白 / 浅灰白 / 米白

强调色 1：
亮蓝色或钴蓝色
用于箭头、按钮、部分设备边缘、重点图标

强调色 2：
暖黄色或橙黄色
用于灯泡、灵感、强调点

辅助中性色：
浅灰
用于电脑外壳、局部填充、弱化次要部分

颜色比例建议：
70% 背景浅色
20% 黑色线条
10% 蓝色和黄色点缀

不要使用大面积多彩配色。
不要使用霓虹色、紫色渐变、玻璃拟态、发光效果。

【风格总基调】

整体气质应当是：

简洁
现代
友好
清楚
轻松
理性
知识感强
低门槛易理解

像互联网科技内容创作者常用的知识型封面插画，
也像产品教程、创作者经济、效率提升、AI 工具说明类内容中常见的清爽图解风格。

它应当让人一眼明白：
这是一个“讲清楚某件事”的内容封面。

【画面控制】

避免写实阴影。
避免照片感。
避免复杂场景透视。
避免背景装饰花纹。
避免大量小字说明。
避免厚重 UI 面板。
避免过于儿童绘本化。
避免日系厚涂。
避免水彩、油画、赛博朋克、3D 渲染、黏土风、等距插画。
避免把画面做成 PPT 截图感。

【最终效果】

最终画面应像一张高质量极简知识封面：

左侧是清晰醒目的标题，
右侧是由简洁黑色线描人物和少量蓝黄图标构成的主题插画，
背景干净，信息密度低，结构稳定，
整体具有白板手绘、科技图解、知识说明型内容封面的统一视觉语言。
```
