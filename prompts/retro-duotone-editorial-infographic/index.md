````text
# 复古双色编辑知识图解

## Prompt

```text
创作一张“复古双色编辑设计 × 知识流程图解”风格的横版信息海报。

整体视觉像一本旧时代技术杂志、知识手册或编辑部制作的专题说明页：
暖米白纸张背景，
深靛蓝主文字，
朱红色强调信息，
细线分隔，
模块化知识卡片，
少量箭头，
轻微印刷颗粒，
局部蓝红油墨刷痕，
以及一个极小的手绘人物或编辑插画。

重点是：
信息清楚，
版式稳定，
知识层级明确，
复古但不陈旧，
有编辑出版物气质，
不是现代 UI 信息图。

【输入】
主题 / 主标题：{{主题}}
副标题：{{副标题，可留空}}
核心知识点：{{需要解释的流程、步骤、方法或框架}}
步骤数量：{{默认 3 个，可根据内容调整为 2–4 个}}
关键结论：{{可留空}}
画幅比例：{{默认 16:9}}
语言：{{中文 / 英文 / 中英混排}}
可选人物：{{无 / 男性 / 女性 / 自动判断}}
可选补充语境：{{可留空}}
可选禁用元素：{{不想出现的元素，可留空}}

【整体视觉】
背景固定为温暖米白、奶油白或轻微泛黄的纸张底色。

纸面保持：
干净，
柔和，
低对比，
略有细微纤维与印刷颗粒。

不要严重做旧。
不要污渍、折痕、烧焦、破纸或脏乱纹理。

整体像：
复古编辑印刷品，
旧技术杂志，
知识手册，
文化刊物，
课程讲义封面页。

【核心配色】
主要使用三类颜色：

1. 深靛蓝 / 墨蓝
用于：
主标题，
正文，
线条，
模块标题，
人物线稿。

2. 朱红 / 番茄红
用于：
步骤编号，
小标题，
关键词，
重点提示，
局部强调。

3. 暖米白纸色
作为大面积背景和卡片底色。

可允许非常少量浅灰、淡蓝灰或浅米色用于层级区分。

整体保持“蓝 + 红 + 米白”的复古双色印刷气质。

不要加入大量第三、第四高饱和颜色。

【顶部标题区】
画面顶部建立明显的编辑标题区。

结构可以包括：

左上角小型章节编号或栏目标签；
一条很短的细线；
一个超大中文主标题；
一行简短副标题；
一条横向细分隔线。

主标题是第一视觉。

标题使用具有传统出版感的中文字体气质：
现代宋体，
高对比宋体，
标题宋体，
带一点旧杂志印刷感的衬线中文字体。

标题颜色使用深靛蓝。

字号巨大但不过度压满画面。

如果标题较长，
可自然拆成 1–2 行。

不要使用现代互联网黑体作为主标题默认字体。

【小栏目标签】
左上角可以使用类似：

01 / 起步
02 / 方法
03 / 实践
STEP 01
SECTION 01

这样的微型栏目结构。

数字或重点词使用朱红色，
其余信息使用深蓝或灰蓝。

小标签必须很小，
只负责建立杂志编辑感。

不要生成大量编号系统。

【主体信息区】
中部为主要知识内容区域。

优先采用 2–4 个横向排列的步骤卡片。

如果默认 3 步，视觉结构类似：

01  第一阶段
→
02  第二阶段
→
03  第三阶段

每张卡片包含：

大号红色编号；
简短步骤标题；
一条短说明；
必要时 1–2 行文件名、关键词、术语或辅助信息。

卡片之间用简单细箭头连接。

不要使用复杂流程线。

【步骤卡片】
卡片保持浅米白或比背景略浅的纸面色。

使用非常轻的矩形边界、浅色块或纸片感区分，
不要现代 UI 阴影卡片。

每张卡片的层级：

第一层：
红色步骤编号。

第二层：
深蓝粗体步骤标题。

第三层：
较小的说明文字。

第四层：
可选的英文、文件名或术语。

卡片之间保持明显间距。

不要拥挤。

【步骤编号】
步骤编号是重要视觉识别元素。

使用：
01
02
03
04

等两位数字。

颜色使用朱红色。

字号明显大于普通正文，
但小于主标题。

数字可以与一条细竖线、短横线或标题形成简单编辑结构。

不要做成圆形徽章、彩色胶囊或现代 UI 标签。

【箭头】
步骤之间使用极简细线箭头。

箭头：
深蓝或墨蓝，
线条细，
结构简单，
方向清楚。

不要使用：
粗箭头，
渐变箭头，
发光箭头，
流程节点圆点。

箭头只是阅读方向提示。

【底部结论区】
画面底部可以建立一条独立的总结区域。

结构可以包括：

左侧一个红色小标签，例如：
关键提示
核心原则
IMPORTANT

中间或右侧：
一句较大的深蓝色结论。

例如：
“{{关键结论}}”

结论文字明显大于普通正文，
但小于主标题。

通过上下细线或大面积留白与主体步骤区分开。

底部结论应该让读者一眼知道：
“这张图最后要记住什么。”

不要写成长段说明。

【人物插画】
如果选择人物，
只加入 1 个极小比例的编辑插画人物。

人物通常放在：
右下角，
底部边缘，
或结论旁边。

人物风格：
深蓝手绘线稿，
轻微赛璐璐或编辑漫画感，
复古杂志插图气质，
少量浅蓝或米色填充。

人物可以：
拿文件阅读，
思考，
查看笔记，
指向信息，
坐着观察。

人物表情保持自然、理性、轻松。

人物只是视觉点缀和尺度参照，
不能成为主视觉。

不要加入多个角色。

【版式】
整体采用严格但不僵硬的编辑网格。

主要结构建议：

顶部：
栏目标签 + 主标题 + 副标题。

中部：
2–4 张横向步骤卡片。

底部：
关键结论 + 极小人物插画。

使用：

细横线，
短竖线，
卡片边缘，
留白
建立信息秩序。

所有元素保持清楚对齐。

不要做成复杂信息图。

【复古印刷效果】
加入轻微旧印刷质感：

纸张颗粒；
轻微油墨扩散；
细小套色偏移；
低强度半调网点；
局部墨量不均；
非常轻微的扫描感。

这些效果只负责建立纸媒气质。

不要让标题模糊。
不要影响小字阅读。

【边缘色彩刷痕】
允许在画面边缘加入少量蓝色或红色的复古印刷刷痕、油墨拖影或粗糙色带。

例如：

右上角一小块深蓝色干刷纹理；
左下角一小块朱红色油墨刷痕；
画面边缘少量颗粒状色彩侵入。

这些色块只位于边缘，
不能进入核心文字区域。

作用是增加：
印刷感，
时代感，
构图张力。

不要四周全部铺满。

建议最多使用 1 个蓝色边缘刷痕 + 1 个红色边缘刷痕。

【文字系统】
主标题：
高对比中文宋体 / 编辑衬线字体，
深靛蓝，
大字号。

步骤标题：
现代宋黑混合或中粗黑体，
深蓝。

步骤编号：
朱红色，
大号衬线数字或出版物式数字。

正文：
清晰中文字体，
深蓝或墨蓝，
字号较小。

英文、文件名或技术术语：
可使用等宽字体或打字机式字体，
进一步强化技术手册感。

例如：
analysis.md
outline.md
draft.md
review.md

仅在内容确实需要时出现。

不要随机生成英文。

【信息密度】
整体为中等信息密度。

要求：
一眼能看到主题；
第二眼能理解步骤；
第三眼看到关键结论和辅助细节。

不要满屏文字。

每个步骤说明尽量控制在 1–2 行。

每张卡片只表达一个阶段。

如果内容太多，
优先提炼而不是缩小文字。

【画幅】
默认 16:9 横版。

横向画面重点利用：
标题横向展开，
步骤卡片横向排列，
底部结论形成第二条水平轴。

避免主体全部集中在中央。

四周保持安全边距。

不要让任何主要文字贴边。

【整体气质】
画面应具有：

复古，
理性，
编辑感，
知识感，
轻技术感，
出版物感，
清楚，
克制，
略带人文气质。

它应该像：
一本老式技术杂志被重新设计成现代知识卡片。

不是：
互联网运营海报，
PPT，
商业培训模板，
App UI，
现代 SaaS 仪表盘。

【必须避免】
不要大面积渐变。
不要霓虹。
不要 3D。
不要玻璃拟态。
不要现代 UI 卡片。
不要科技蓝紫背景。
不要复杂图标系统。
不要密集流程图。
不要大量人物。
不要写实人物摄影。
不要花哨字体。
不要卡通儿童风。
不要现代电商海报。
不要大量彩色。
不要让边缘刷痕遮挡标题。
不要随机添加编号、英文或说明。

不要加入 {{可选禁用元素}}。

【生成前检查】
生成前内部检查：

是否有清楚的顶部标题区？

主标题是否足够醒目？

是否保持“深蓝 + 朱红 + 米白”的统一配色？

中间是否只有 2–4 个清楚步骤？

每个步骤是否只有：
编号 + 标题 + 短说明？

箭头是否足够简单？

是否有一句真正值得强调的底部结论？

人物是否只有一个且足够小？

是否存在大量留白？

纸张和印刷颗粒是否自然？

蓝红边缘刷痕是否只作为局部点缀？

画面是否更像编辑杂志，
而不是 PPT？

如果一个元素不能帮助：
阅读，
理解，
层级，
复古编辑气质，

删除它。

【最终标准】
最终只生成一张独立完整图解。

不要输出：
多个方案，
拼图，
样机，
版式拆解，
分析过程，
联系表。

最终画面必须同时具备：

暖米白复古纸张背景；
深靛蓝主标题；
朱红色步骤编号和重点提示；
一个强主标题区；
2–4 个清楚步骤卡片；
极简流程箭头；
一句醒目的关键结论；
可选的一个小型编辑人物插画；
少量红蓝边缘油墨刷痕；
轻微纸张与印刷颗粒；
清楚的杂志网格；
充足的留白。

远看时：
首先看到主标题和三段式 / 多段式知识结构。

近看时：
再看到步骤说明、文件名、技术术语、关键提示和印刷细节。

最终效果应像：

一本具有现代排版意识的复古技术杂志，
用深蓝、朱红和米白三种核心色，
把一个复杂方法拆成几步讲清楚。

不是“普通三步信息图”，

而是“具有复古出版物气质的编辑型知识图解”。
````
