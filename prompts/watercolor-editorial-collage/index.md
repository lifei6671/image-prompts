# 复古水彩编辑拼贴封面
![预览图](preview.webp)

## Prompt

```text
围绕用户提供的主题，创作一张“复古水彩编辑插画 × 纸本拼贴 × 视觉叙事”风格的横版封面。

这是一张具有真实纸张触感、杂志编辑气质和艺术手账感的主题封面。
重点不是绘制一个写实场景，而是使用水彩、纸张、墨线、手绘草图和主题象征物，共同构成一个具有叙事性的编辑拼贴画面。

【输入】

主题 / 主标题：{{主题}}
核心观点：{{一句话说明文章真正想表达的内容，可留空}}
副标题：{{副标题，可留空}}
核心视觉隐喻：{{希望使用的核心象征，可留空，由模型根据主题自动推导}}
关键概念：{{2–5 个关键词，可留空}}
画幅比例：{{默认 16:9}}
语言：{{中文 / 英文 / 中英混排}}
用途：{{公众号封面 / 博客题图 / 知识文章 / 专题封面 / 视频封面}}
可选情绪倾向：{{理性 / 思考 / 创作 / 探索 / 怀旧 / 深度 / 温暖 / 安静}}

【整体构图】

采用明显的“左疏右密”横向编辑构图。

画面左侧约占整体宽度 30%–35%，保持大面积安静留白，
主要承担标题区域。

画面右侧约占 65%–70%，形成丰富但有秩序的水彩拼贴视觉叙事，
所有主要视觉元素集中在右侧，并从画面中央向右侧自然展开。

左右之间不要形成生硬分栏，
而是通过淡水彩晕染、细墨线、弧线、纸张边缘和少量元素延伸，
让两个区域自然连接。

整体重心偏右，
左侧保持呼吸感和高级留白。

【左侧标题设计】

在左侧留白区域加入主标题：

“{{主题}}”

标题必须清晰、准确、完整，
优先保证文字正确性和阅读性。

标题位于左侧视觉中心附近，
可略微偏上，
距离画面左边缘和上下边缘保持充足留白。

根据标题长度自动分成 2–4 行，
不要把标题压缩成很小的一行。

标题字体采用具有传统出版物气质的中文宋体感、衬线字体感或轻微手工印刷感，
笔画清晰、克制、成熟。

文字使用深靛蓝、深蓝灰或墨蓝色，
颜色与右侧插画中的深色墨线统一。

文字边缘可以具有极轻微的油墨渗透、纸张吸墨和旧式印刷质感，
但必须保持高度可读。

避免现代科技感无衬线大黑体，
避免霓虹字体，
避免立体字，
避免发光，
避免夸张描边。

如果提供副标题：

“{{副标题}}”

放置在主标题下方，
字号明显更小，
字距舒展，
颜色可使用低饱和蓝灰色。

除主标题、副标题以及用户明确要求的文字外，
画面中不要自动生成大量可阅读文字。

【右侧核心视觉结构】

根据主题自动寻找一个最适合表达核心概念的视觉隐喻，
并将其作为右侧拼贴区域的视觉锚点。

核心主体可以是：

纸张、
书页、
画布、
机器、
建筑、
人物剪影、
植物、
设备、
抽象结构、
知识网络、
流程结构、
技术对象、
自然物体，
或其他与主题高度相关的象征物。

核心主体不要孤立存在。

围绕主体加入多层纸本视觉材料，例如：

水彩小画，
速写稿，
照片感纸片，
手绘草稿，
图表，
概念草图，
卡片，
便笺，
抽象几何纸片，
线稿，
符号，
箭头，
路径，
数据曲线，
纸质资料。

这些内容像研究者或设计师工作桌上的视觉资料，
被重新组织成一张具有编辑设计感的艺术拼贴。

不同主题应自动改变具体象征物，
不要固定使用某一种道具组合。

【拼贴方式】

使用真实纸张拼贴逻辑。

纸片之间允许：

轻微旋转，
大小变化，
局部覆盖，
前后遮挡，
自然错位，
边缘不完全对齐。

部分纸张可以像旧书页、素描纸、水彩纸、照片纸或便笺纸。

纸张边缘可以具有：

自然毛边，
轻微磨损，
纤维质感，
不规则裁切，
淡淡阴影。

阴影必须非常柔和，
只用于表达纸张层次，
不要形成现代 UI 卡片式悬浮效果。

整个拼贴应显得经过设计，
但仍保留手工创作留下的自然随机感。

【水彩表现】

主体视觉采用透明水彩与淡彩混合媒介。

水彩具有真实纸张渗透感：

颜料自然扩散，
边缘轻微晕染，
局部颜色沉积，
深浅不均，
自然水痕，
纸张纹理透出。

允许出现少量干笔刷痕、
飞溅墨点、
半透明色块和不完整笔触。

不要把所有区域填满颜色。

大量区域应保留纸张本身的暖米白色。

水彩更多承担气氛、层次和视觉连接，
而不是把所有对象完整涂实。

【线条系统】

使用纤细、自然、不完全规则的深蓝灰或墨蓝手绘线条。

线条可以表现：

轮廓，
箭头，
路径，
草图，
连接关系，
运动轨迹，
抽象弧线。

部分长线条可以穿过不同纸片和水彩区域，
将原本分散的视觉元素串联起来。

线条要有手绘感，
不要像计算机生成的完美贝塞尔曲线。

不要形成复杂流程图。

这些线条首先是视觉叙事语言，
其次才是信息表达。

【背景】

整个画面使用暖米白色天然水彩纸作为背景。

背景具有非常细腻的：

纸浆纤维，
微弱颗粒，
浅淡污渍，
自然色差，
旧纸触感。

背景整体干净，
不要做成明显发黄的古董纸。

颜色应接近：

象牙白，
暖米色，
亚麻纸色，
淡奶油色。

允许在右侧出现大面积透明水彩晕染，
逐渐向左侧减弱并消失。

左侧标题区域必须保持足够干净。

【主色系统】

整体采用低饱和、自然、具有纸本艺术气质的颜色。

主色：

暖米白
象牙纸色
灰蓝
靛青
蓝绿色
深海军蓝

辅助色：

陶土橙
柔和赭石
浅杏色
淡沙色

强调色只少量出现。

整体颜色关系：

暖米白背景
+
蓝灰冷色主体
+
少量陶土橙暖色点缀。

冷暖形成温和对比，
但整体保持低饱和。

不要使用高亮纯色。

【视觉层次】

画面应同时具有三个层次：

第一层：
暖米白纸张背景和非常淡的水彩痕迹。

第二层：
纸片、草图、水彩画、抽象色块和主题资料。

第三层：
核心主题象征物、深色线条以及少量视觉强调元素。

右侧局部信息可以丰富，
但画面不能变成密集信息图。

远看首先感受到构图和色彩，
近看才发现纸片、线稿和各种细节。

【风格总基调】

整体视觉接近：

独立杂志编辑插画，
艺术家视觉手账，
水彩研究笔记，
设计师灵感板，
旅行艺术日志，
复古出版物插图，
纸本视觉档案，
诗意知识封面。

它应该有明显的“人工创作痕迹”，
而不是数字软件制作出来的完美图形。

画面安静、自然、知识感强，
略带怀旧，
但不是古董风。

精致，
但不商业广告化。

丰富，
但不拥挤。

艺术化，
但主题仍然可以被快速理解。

【材质要求】

重点表现以下真实材料：

粗纹水彩纸，
半透明水彩颜料，
铅笔草稿，
细墨水笔，
旧式纸张，
艺术打印纸，
轻微纸张折痕，
纸纤维，
干笔刷。

所有材质应融为统一的纸本艺术语言。

【画面控制】

保持左侧标题区安静，
右侧负责视觉叙事。

不要平均填满整个画布。

不要使用严格对称构图。

不要采用规整卡片网格。

不要形成 PPT 页面。

不要形成现代 SaaS 信息图。

不要使用玻璃拟态、发光渐变、霓虹灯、赛博朋克、高饱和科技蓝。

不要使用塑料质感或光滑 3D 渲染。

不要把水彩处理成儿童绘本风格。

不要使用粗黑漫画描边。

不要让画面过度可爱或卡通。

不要加入品牌 Logo、水印、二维码或无意义文字。

最终效果应像一位插画师、编辑设计师和水彩艺术家共同完成的一张横版专题封面：

左侧是克制、清晰、具有出版气质的主题标题，
右侧是一组由水彩、纸张、线稿和主题象征物组成的视觉叙事，
两者共同形成安静、温暖、富有思考感的现代纸本编辑插画。
```
