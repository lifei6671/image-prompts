# 复古时代错位编辑封面

![预览图](preview.webp)

## Prompt

```text
根据用户提供的主题，创作一张“复古时代错位 × 现代编辑设计”的概念封面。

核心视觉公式：

1940s–1960s Mid-century 商业插画人物
×
只属于今天或未来的事物
×
一个清晰的人物动作
×
一个简单但聪明的视觉隐喻
×
现代极简编辑排版
×
大面积暖白留白。

最终画面应像一本属于今天的独立杂志，
邀请一位来自 1958 年的顶级商业插画师，
去描绘一个只有今天才可能发生的话题。

第一眼看到标题；
第二眼看到人物正在做什么；
第三眼发现人物和事物来自两个不同年代；
第四眼理解这种时代错位为什么与主题有关。

【输入】
主题 / 主标题：{{填写主题或标题}}
副标题：{{可留空，留空则自动判断是否需要}}
画幅比例：{{自动 / 1:1 / 4:5 / 3:4 / 9:16 / 16:9 / 5:2 / 3:1 / 自定义}}
人物设定：{{自动判断 / 女性 / 男性 / 一男一女 / 双人 / 指定人物身份}}
情感倾向：{{自动判断 / 温暖 / 治愈 / 理性 / 克制 / 浪漫 / 神秘 / 怪诞 / 冷峻 / 幽默 / 戏剧化}}

除用户明确指定的内容之外，
自动判断：
主题色彩，
是否需要人物，
人物数量，
人物年龄，
身份职业，
动作，
镜头角度，
服装，
现代道具，
超现实程度，
标题层级，
版式，
构图。

人物不是强制元素。

如果主题使用物体、空间或抽象关系表达更准确，
可以不出现人物。

如果出现人物，
总数最多 3 人。

不要固定使用同一张漂亮女性脸、同一个男性脸，
也不要每次默认“一男一女”。

【核心原则】
整张封面只保留：

1 个核心主题；
1 个主要动作；
1 个核心现代 / 未来事物；
1 个视觉隐喻；
1 次主要时代错位；
1 个明确视觉中心。

所有其他元素都必须服务于这一个视觉故事。

不要同时讲多个观点。
不要同时设置多个超现实事件。
不要用大量道具解释主题。

一个准确的动作，
优先于十个相关图标。

【主题理解】
生成前先在内部理解“{{主题或标题}}”。

判断：

主题表面讲什么；
真正重要的观点是什么；
人物处于什么状态；
发生了什么行为变化；
最核心的矛盾是什么；
什么东西属于今天而不属于过去；
哪一个瞬间最值得被画出来。

不要展示分析过程。

不要看到标题关键词就直接寻找对应物件。

按照：

核心观点
→ 人的处境
→ 人的动作
→ 核心物体
→ 反常关系
→ 时代错位

完成视觉转译。

【视觉隐喻】
优先建立：

人的动作
+
一个核心物体
+
一个不符合常识或时代的关系。

这种反常关系必须：
一眼能够理解，
第二眼略感荒诞，
但回到标题后又非常合理。

例如可以是：

一个 1950 年代编辑正在训练 AI；

一位复古秘书把代码像纸带一样从终端中抽出来整理；

一个老派工程师坐在巨型现代键盘上调试系统；

一位 Mid-century 摄影师正在拍摄数字人；

一名复古驾驶员从电脑文件夹中开车出来；

一个 1960 年代学者把知识图谱像星图一样铺在桌面上；

一位旧时代主持人正在操作现代视频剪辑时间线；

一个复古旅行者把导航地图当作真实道路展开。

这些只是关系示例，
不是固定场景。

每次根据主题重新构思。

【隐喻数量】
整张图只允许一个主要视觉隐喻。

最多增加一个非常轻的辅助细节，
用于让隐喻更完整。

不要出现：
屏幕里一套隐喻，
桌上另一套隐喻，
背景又一套隐喻。

如果某个元素无法帮助理解主题，
删除它。

【人物视觉语言】
如果使用人物，
人物必须明显属于 1940s–1960s 美国商业广告、旧杂志插图和 Mid-century illustration 世界。

人物特征包括：

复古商业插画式面部；
略带理想化但具有个性的五官；
自然红润脸颊；
经典年代发型；
复古服装剪裁；
旧广告插图式身体比例；
轻微手绘和印刷质感。

服装可以根据人物身份选择：
衬衫，
领带，
套装，
连衣裙，
针织衫，
工作服，
实验室服装，
旅行服，
编辑或工程师式着装。

但不要所有人物都像时尚广告模特。

【人物多样性】
根据主题自然改变：

年龄，
脸型，
发型，
肤色，
职业，
体态，
气质，
服装，
镜头角度。

可以出现：

年轻人，
中年人，
导师，
学者，
编辑，
程序员，
工程师，
摄影师，
主持人，
旅行者，
研究员，
创作者，
工作搭档。

人物应当属于当前故事，
而不是为了好看临时加入。

【人物动作】
人物不能只是：

站着，
看镜头，
微笑摆拍。

人物必须正在做事。

动作可以包括：

输入，
写作，
阅读，
拍摄，
驾驶，
观察，
调试，
连接，
组装，
整理，
主持，
讲述，
讨论，
设计，
创造，
操控，
拆解，
递交，
拉动，
推开，
查看，
面对一个意外事件。

动作是理解主题的核心信息。

【多人关系】
如果出现两人或三人，
他们必须围绕同一个事件产生关系。

可以：
共同操作，
交谈，
递交物品，
一起观察，
一人操作一人回应，
发生轻微冲突，
共同面对一个异常现象。

不要：
并排站立，
看镜头合照，
平均分布，
变成团队宣传照。

【镜头】
不要固定使用标准正面半身像。

可以根据视觉故事使用：

侧脸，
背影，
回头，
俯视，
仰视，
手部特写，
局部身体，
近景，
人物探出画面，
人物被巨大道具局部遮挡。

画面应像：
故事正在发生到一半，
被杂志插画师截取了最有意味的一瞬间。

【时代错位】
时代错位是本风格最重要的结构。

复古人物必须与一个只属于现代或未来的核心对象建立明确关系。

现代 / 未来对象可以是：

laptop，
AI assistant，
coding interface，
terminal，
database，
server，
knowledge graph，
digital human，
drone，
rocket，
modern car，
camera，
smartphone，
video editing timeline，
creative software，
3D printer，
robotic arm，
cloud system，
modern navigation，
AI-generated media，
data system。

但现代物件必须由主题决定。

不要看到 AI 就自动加入：
机器人，
芯片，
全息屏。

即使主题是 AI、Coding、知识库或数字人，
也优先表达：

“这个人在利用科技做什么？”

而不是：

“这个科技设备长什么样？”

【一次主要错位】
整张图只设置一次主要时代错位。

例如：

复古人物 + AI；

复古人物 + laptop；

复古人物 + drone；

复古人物 + modern software；

复古人物 + rocket。

不要同时加入：
AI + 无人机 + 机器人 + VR + 火箭 + 手机。

如果多个现代元素确实属于同一个对象，
可以作为一个统一系统存在，
但不能成为多个独立焦点。

【超现实程度】
超现实应当轻微、聪明、容易理解。

允许：

人物进入屏幕；
人物坐在巨型键盘上；
人物驾驶从文件夹中驶出的汽车；
代码变成可以搬运的实体纸带；
知识图谱成为可以触摸的地图；
声音变成带状物；
软件时间线成为真实道路；
一个应用窗口成为门洞；
数据库抽屉变成真实档案柜；
现代设备出现违反正常尺度的巨大化。

超现实关系必须服务主题。

不要为了怪异而怪异。

【背景】
背景使用：

白色，
暖白，
象牙白，
奶油白。

只允许轻微纸张纹理。

不要绘制完整的：
办公室，
城市，
实验室，
街景，
房间，
复杂室内空间。

环境只通过必要的：
一张桌子局部，
椅子，
平台，
纸张边缘，
单一道具，
少量空间阴影
进行暗示。

让大面积白色背景参与构图。

【留白】
大面积留白是该风格核心之一。

留白承担：

编辑气质，
时代反差，
标题空间，
视觉停顿，
高级感，
主体聚焦。

不要因为画面空就补元素。

宁可空，
不要乱。

【横版构图】
16:9、5:2、3:1：

默认建立明显的左右不对称结构。

通常：

左侧约 65%–75%：
标题，
副标题，
编辑排版，
大面积留白。

右侧约 25%–35%：
人物，
动作，
现代物件，
核心视觉事件。

整体形成：
左轻，
右重。

但如果当前主题明显更适合反向关系，
可以镜像处理。

关键不是固定左右，
而是必须保留明显不对称和大面积横向呼吸感。

【5:2 与 3:1】
超宽比例尤其需要减少元素。

只保留：
标题，
主体，
核心道具，
必要副标题。

禁止：
主体居中，
左右五五分，
满版插画，
把方形海报直接裁成长条。

让视觉事件集中在一个区域，
另一区域承担大面积文字与留白。

【竖版】
4:5 / 3:4 / 9:16：

标题优先放在：
上方，
左上，
或大片负空间区域。

人物与时代错位事件位于：
下方，
右下，
中下区域。

保持明显不对称。

不要让人物和标题从上到下平均分配空间。

【方形】
1:1：

采用明显偏心构图。

不要：
左半标题，
右半人物
的机械二分结构。

通过主体偏置、标题比例和留白建立编辑张力。

【插画边缘】
人物与视觉事件不能像一张规则矩形图片贴在白色背景上。

插画边缘应自然消失到背景中。

可以使用：

irregular feathered edges，
faded ink edge，
dry brush dissolve，
paper collage erosion，
halftone fade，
uneven ink edge。

让复古插画像从一张旧杂志中被剪下，
又自然融入当代编辑版面。

不要使用：
圆角卡片，
规则矩形相框，
照片边框，
UI 卡片容器。

【主标题】
主标题必须准确显示：

“{{主题或标题}}”

主标题是整个封面的第一视觉。

使用现代 Editorial Typography，
与复古人物形成明显时代反差。

中文可以使用：

高对比现代宋体，
现代宋体，
克制黑体，
窄体黑体。

英文可以使用：

Didone，
Bodoni-like Serif，
Editorial Serif，
Condensed Sans，
Modern Grotesk。

不要使用复古广告字体去模仿人物年代。

真正的视觉张力来自：

现代标题
×
复古人物。

【标题层级】
标题必须：

完整，
准确，
清楚，
具有强封面识别度。

如果标题较长，
可以自然拆成 2–3 行。

允许突出：
一个数字，
一个关键词，
一个动词。

但不要使用大量彩色文字。

标题不能被：
人物，
现代物件，
墨点，
纹理
遮挡到无法阅读。

【副标题】
如果用户输入副标题，
准确显示：

“{{副标题}}”

如果副标题留空，
判断是否真的需要。

只有当它能补充一个重要判断时才自动增加。

如果不需要，
保持空白。

副标题应：
短，
轻，
最多 1–2 行，
明显弱于主标题。

不要扩展为正文。

【辅助文字】
原则上只保留：

主标题，
可选副标题。

只有版面确实需要时，
允许加入一行极小的英文 editorial note。

不要自动增加：

栏目列表，
卖点，
功能说明，
时间，
日期，
编号，
假刊号，
品牌名，
大段英文。

不要用大量小字制造所谓杂志感。

【图文关系】
标题与人物事件必须在语义上互相完成。

标题告诉观众：
“这件事是什么。”

人物事件告诉观众：
“为什么这个主题值得看。”

不要把标题像贴纸一样放在一张无关复古插画旁边。

视觉事件必须是标题的另一半。

【色彩】
背景固定在：
白色，
暖白，
象牙白，
奶油白
范围内。

人物和道具使用 Mid-century 复古印刷色。

可选择：

Tomato Red，
Faded Coral，
Mustard Yellow，
Avocado Green，
Olive Green，
Teal，
Powder Blue，
Burgundy，
Dusty Pink，
Lavender，
Warm Brown。

每张图根据主题重新选择。

通常限制为：

1 个主强调色；
1–2 个辅助色；
黑色或深色文字；
白色背景。

整张图主要颜色控制在约 3–5 种。

不要平均使用所有颜色。

【情绪与配色】
根据 {{情感倾向}} 调整色彩和动作。

温暖：
奶油白、珊瑚、芥末黄，动作亲切。

治愈：
低饱和蓝绿、暖米色，人物动作柔和。

理性：
灰蓝、橄榄绿、深色文字，构图更加精确。

克制：
降低颜色数量和超现实程度。

浪漫：
Dusty Pink、Burgundy、奶油色，关系更柔软。

神秘：
深绿、酒红、暗蓝，增加负空间和轻微荒诞感。

怪诞：
通过比例、动作和不合理关系制造幽默，不依赖恐怖。

冷峻：
灰蓝、深棕、冷绿，人物表情和构图更硬。

幽默：
强化人物认真对待荒谬现代物件的反差。

戏剧化：
扩大动作幅度和尺度冲突，但仍保持版式克制。

【复古印刷质感】
人物和道具必须具有真正的 Mid-century 商业插画印刷感。

加入克制的：

halftone dots，
旧印刷颗粒，
faded ink，
screen print texture，
纸张纤维，
轻微套色偏移，
边缘磨损，
不均匀颜料覆盖，
局部褪色。

这些纹理必须自然。

人物仍应保持：
轮廓清楚，
动作明确，
面部可读。

不要把整个画面做成脏旧纸张。

现代排版仍然保持干净锐利。

【材质反差】
复古人物：
具有印刷颗粒和手绘感。

现代物件：
可以稍微更加精准、清晰、现代，
但仍必须被转译到同一个编辑插画世界中。

不要直接把写实现代产品照片贴入复古插画。

时代反差来自：
造型，
语义，
技术年代，
而不是视觉质量完全割裂。

【用途感】
最终画面要像：

独立杂志封面，
文化评论封面，
科技思想文章头图，
趋势观察视觉，
编辑专题主视觉。

不要像：
广告 Banner，
PPT，
产品功能页，
电商促销页，
新闻信息流卡片。

【必须避免】
禁止默认科技视觉：

AI 蓝紫渐变，
霓虹灯，
赛博朋克，
发光芯片，
AI 大脑，
机器人头像，
科技粒子，
全息 HUD，
大量漂浮 UI，
代码雨。

禁止：

写实摄影，
现代光滑数字绘画，
3D CG，
动漫，
统一精致网红脸，
现代时尚摄影感。

禁止：

人物静态正面站立，
双人并排合照，
多人平均排列，
无互动团队照。

禁止：

多重隐喻，
多个同等视觉中心，
复杂满版背景，
大量无关道具，
卖点列表，
功能图标，
密集小字。

禁止：

Logo，
水印，
假杂志刊名，
虚构出版信息，
卡片边框，
规则相框。

不要为了丰富画面而堆东西。

不服务主题的元素全部删除。

【原创性】
整体只借鉴 Mid-century 商业插画、旧广告印刷和现代编辑设计的通用视觉语言。

不要复制：
具体旧广告，
特定杂志封面，
真实商业插画作品，
真实品牌人物，
品牌 Logo，
现成广告文案。

最终应是针对当前主题重新构思的原创视觉。

【生成前检查】
在最终生成前内部检查：

是否只有一个核心主题？

是否只有一个主要人物动作？

是否只有一个核心现代 / 未来物件？

是否只有一次主要时代错位？

这个人物动作是否真正解释主题？

现代物件是否真的与主题有关？

如果去掉标题，
画面是否仍然能暗示主题？

如果去掉人物或核心道具，
隐喻是否会失效？

如果某个元素删除后完全不影响表达，
删除它。
```
