````text
# 品牌协同连接

## Prompt

```text
根据输入的两个 Logo，创作一张“品牌协同 / 工具连接”主题的极简横版封面。

核心视觉只有两个主体：
左侧 Logo A，
右侧 Logo B。

将两个输入 Logo 分别转译为统一视觉体系的高级轻拟物 3D 圆角应用图标，并通过一条连续、轻盈、平滑的双向连接线建立两者之间的连接关系。

整体保持浅灰白背景、大面积留白、干净现代、克制高级，呈现企业级软件产品、技术教程或产品集成发布封面的视觉气质。

不要制作复杂信息图。

【输入】
Logo A：{{上传图片或引用路径}}
Logo B：{{上传图片或引用路径}}
主题词 / 主标题：{{主题词}}
副标题：{{副标题，可留空}}
画幅比例：{{5:2 / 16:9 / 2.35:1}}
语言：{{中文 / 英文 / 中英混排}}
用途：{{教程封面 / 公众号封面 / X封面 / PPT头图 / 产品宣传封面}}
品牌名称：{{品牌 A + 品牌 B，可留空；留空时根据输入 Logo 或标题判断}}
可选补充语境：{{工具连接 / 自动化工作流 / 知识管理 / 数据同步 / 产品集成 / 品牌联动，可留空}}
可选情绪倾向：{{极简 / 科技感 / 企业级 / 高级轻拟物 / 清爽留白 / 干净现代 / 克制，可留空}}
可选重点字符：{{标题中需要强调的数字、符号、关键词或品牌名，可留空}}
可选禁用元素：{{不想出现的元素，可留空}}

【核心目标】
先识别 Logo A 与 Logo B 的核心视觉特征，包括：
主轮廓，
关键符号，
主要颜色，
内部结构，
辨识度最高的图形关系。

必须保留两个输入 Logo 的品牌识别性。

不要重新设计 Logo。
不要改变其核心符号。
不要把它们改造成陌生图案。

只对 Logo 的承载方式、体积、材质、阴影和空间表现进行统一，使两者自然属于同一个视觉系统。

最终画面表达一个明确概念：

Logo A ⇄ Logo B

即两个产品、品牌或工具之间正在建立连接、同步、协作、集成或数据交换关系。

整张图只表达这一层关系，不增加第二套叙事。

【整体视觉】
背景使用：
浅灰白，
微冷白，
非常浅的雾面灰。

背景保持平整、克制、干净，并拥有大量留白。

允许极轻微的环境明暗变化，用于建立空间层次，但不要形成明显背景图案。

整体视觉关键词：
极简，
企业级，
现代，
高级，
清爽，
克制，
精致，
轻科技感。

避免游戏化、赛博朋克或消费电子广告式的夸张视觉。

【Logo 图标化】
Logo A 位于左侧。
Logo B 位于右侧。

将两个输入 Logo 分别置于统一规格的圆角方形 3D 应用图标中。

两枚图标需要：
尺寸一致或非常接近，
圆角半径一致，
厚度一致，
透视一致，
光照方向一致，
阴影风格一致。

图标具有高级轻拟物质感：
柔和圆角，
细微立体厚度，
克制的表面高光，
非常轻的材质反射，
细腻柔和阴影，
干净边缘。

质感接近高端操作系统应用图标或企业级 SaaS 产品视觉。

不要制作成：
塑料玩具，
软糖，
膨胀气球，
厚重黏土，
夸张玻璃，
金属徽章。

Logo 本身必须清晰、完整且易于辨认。

如果原始 Logo 带透明区域、复杂轮廓或不规则结构，可以为其设计简洁的图标底板，但不能改变 Logo 核心结构。

【品牌色系统】
从 Logo A 自动提取一个主要识别色。
从 Logo B 自动提取一个主要识别色。

左侧区域轻微偏向 Logo A 的颜色体系。
右侧区域轻微偏向 Logo B 的颜色体系。

颜色主要应用于：
Logo 本身，
连接线局部，
小节点，
标题中的极少量重点字符。

整体仍然以浅灰白背景和中性色文字为主体。

品牌色必须克制。

不要因为 Logo 本身颜色丰富，就把整张画面变成多彩渐变海报。

【连接线】
在两枚图标之间建立一条连续、完整、轻盈的连接线。

连接线从 Logo A 内侧自然开始，
延伸至 Logo B 内侧，
形成明确的双向连接关系。

线条可以：
轻微弧形，
柔和 S 曲线，
极轻微波形，
近似水平的柔和路径。

不要使用僵硬折线或复杂线路。

连接线颜色从 Logo A 的主色逐渐、自然地过渡到 Logo B 的主色。

渐变必须：
柔和，
高级，
透明度克制，
没有廉价彩虹感。

线条宽度适中，视觉存在感低于两个 Logo，但必须清晰可辨。

不要使用：
多条并行线，
线路网络，
复杂数据流，
粒子轨迹，
密集箭头，
多级分支。

【中央连接节点】
在连接线中心附近加入一个非常小的连接节点。

节点可以选择：
细线圆环，
实心圆点，
轻微发光点，
双层小圆环。

节点用于表达：
同步，
桥接，
握手，
中转，
集成完成。

节点必须明显小于 Logo。

它只是连接关系中的视觉停顿点，不是第三个主体。

不要把节点扩展成：
第三个 Logo，
服务器，
云端，
数据库，
控制中心，
复杂按钮，
大型发光球。

【图文关系】
Logo 连接关系是第一视觉层级。
标题是第二视觉层级。
副标题是第三视觉层级。

横版优先采用：

左侧 Logo —— 中央连接节点 —— 右侧 Logo

                  主标题
                  副标题

两个 Logo 位于同一水平视觉轴附近。

标题位于中下区域，并与上方连接结构之间保持明确留白。

不要让文字进入连接结构。

不要让连接线穿过文字。

不要让 Logo 与标题发生遮挡。

【标题】
主标题必须准确显示：
“{{主题词}}”

如果存在副标题，则准确显示：
“{{副标题}}”

不要自动增加其他正文。

标题使用现代无衬线字体气质。

中文适合：
现代黑体，
几何黑体，
中粗黑体。

英文适合：
modern sans-serif，
neo-grotesque，
geometric sans-serif。

文字整体保持：
稳重，
清晰，
简洁，
企业级。

主标题可以使用深黑、炭黑或深灰色。

{{可选重点字符}} 可以使用 Logo A 与 Logo B 的主色之一，或者使用两种品牌色形成极小面积的视觉呼应。

强调色只能用于少量字符。

不要把整句标题做成彩色渐变。

【品牌名称】
如果提供 {{品牌名称}}，可将品牌组合关系作为主标题上方的一行小型辅助信息，例如：

品牌 A + 品牌 B

或

品牌 A × 品牌 B

或根据语义使用简洁连接符。

如果没有提供品牌名称，并且无法可靠从 Logo 或标题中识别，则不要擅自生成品牌名称。

不要猜测、不确定或伪造品牌文字。

【副标题】
副标题仅在输入中存在时显示。

副标题必须：
明显小于主标题，
字重更轻，
使用中性色，
保持一行或极短两行，
与主标题之间留有舒适距离。

不要把副标题变成长段说明。

根据 {{画幅比例}} 原生设计画面，不要先制作固定尺寸再机械裁切。

5:2：

两个图标和连接线位于中上区域或视觉中心附近。

连接线成为贯穿画面的主要水平视觉节奏。
标题保持集中，不要分散到左右两端。

【空间与光照】
两枚图标必须处于同一个空间和同一种环境光下。

采用柔和、宽阔、方向统一的产品摄影式环境光。

阴影应：
柔和，
很浅，
边缘自然，
不抢视觉。

允许图标产生极轻的悬浮感，但不要漂浮过高。

背景与图标之间需要有足够明度差，使白色或浅色 Logo 仍然保持清晰边界。

不要使用强烈聚光灯、霓虹背光、电影级烟雾或复杂反射。

【用途适配】
根据 {{用途}} 调整视觉重心。

教程封面：

不要出现拥挤、倾斜、裁切错误、大小严重失衡或元素错位。

不要改变 Logo 核心轮廓。
不要扭曲 Logo。
````
