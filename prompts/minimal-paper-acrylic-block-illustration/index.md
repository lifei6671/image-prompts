# 极简纸感丙烯色块插画

![预览图](preview.webp)

## Prompt

```text
根据用户提供的照片或主题，创作一张“极简纸感 + 手绘线条 + 丙烯色块 + 大面积留白”的封面插画。

不要写实复刻照片，也不要把照片简单转成线稿。

先识别输入内容中最值得被记住的：
主体，
外轮廓，
动作，
姿态，
空间关系，
结构特征，
关键颜色，
最具辨识度的视觉瞬间。

然后进行高度提炼与删减，
只保留真正影响识别和表达的部分，
用极少的手绘线条和几块鲜明、完整的丙烯色面重新表达。

核心视觉公式：

粗糙白纸
+
小型主体
+
极简手绘线条
+
明确丙烯色块
+
70%–90% 留白
+
最多 4 种主要颜色。

最终效果应像一张小幅纸上丙烯作品、极简绘本插画或经过高度提炼的编辑封面插图。

【输入】
照片或主题：{{上传一张照片或填写一个主题}}
画幅比例：{{默认 1:1；可指定 3:4 / 4:5 / 16:9 / 自定义}}
名称或文字：{{可留空；头像通常不添加文字}}
用途：{{头像 / 头像衍生图 / 纸感插画 / 主题卡片，可留空}}
情绪倾向：{{安静 / 克制 / 童趣 / 轻松 / 诗意 / 自动判断}}
需要保留的特征：{{可留空}}
不想出现的元素：{{可留空}}

【核心原则】
整张图尽量只保留：

1 个主体，
或
1 个象征性小场景；

1 个明确动作或结构关系；

2–4 种主要颜色；

少量必要线条；

大量真实白纸留白。

不要把输入内容中的所有细节都搬进画面。

如果删除一个元素不会影响：
主体识别，
动作理解，
主题表达，
构图关系，

就删除它。

“少画但准确”优先于“画得完整”。

【照片输入】
如果输入是一张照片：

先提取照片中最具有辨识度的视觉特征。

人物重点判断：
姿态，
身体方向，
发型轮廓，
服装大形，
手部动作，
标志性配饰，
关键颜色。

宠物重点判断：
体型，
耳朵，
头部轮廓，
毛色分布，
姿势，
尾巴，
最有辨识度的动作。

建筑重点判断：
整体外轮廓，
主要体块，
屋顶或立面特征，
关键门窗，
标志性结构，
主色关系。

物体重点判断：
整体外形，
功能结构，
最重要的部件，
标志性颜色。

只保留这些最核心的信息。

不要追求照片级相似度，
而是让观众通过几个最重要的视觉线索认出原主体。

【主题输入】
如果输入的是抽象主题：

不要把主题词逐个变成图标。

先判断这个主题最值得被记住的一个：
动作，
物体，
关系，
姿态，
小场景，
结构。

再将它压缩为一个极小、简单、清晰的视觉瞬间。

例如可以通过：
一个人物动作，
一个小物体，
一栋极简建筑，
一只动物，
一个人与物的关系，
两个形体之间的距离
来表达。

不要堆叠多个图标解释主题。

【主体提炼】
主体必须经过明显的形体归纳。

复杂形状压缩为：
大轮廓，
主要色块，
少量结构线。

不要完整描绘每一处细节。

人物：
不需要写实五官，
只保留必要的脸部方向、发型、姿态和服装特征。

建筑：
不画满砖瓦、纹理、窗格，
只留下最重要的外形和少量结构。

植物：
归纳为少量枝干和色块。

宠物：
重点保留轮廓、耳朵、姿态和毛色关系。

物品：
保留功能性轮廓和核心识别结构。

整个主体应像被视觉设计师“压缩”过。

【主体尺度】
主体默认只占整个画面的约 10%–20%。

不要因为画布很大就放大主体。

主体需要像一个被安静放置在白纸上的小型视觉事件。

根据主题和比例，
主体可以稍微偏离中心，
但仍保持唯一视觉中心。

头像用途可以适当提高到约 15%–25%，
保证缩略图仍能识别，
但不要变成满版头像。

不要让主体：
贴边，
顶满画面，
占据绝大多数区域。

【纸张背景】
背景固定为真实感粗糙白纸。

可以是：
自然白，
暖白，
略带米色的白，
极浅冷白。

必须能看到轻微：
纸纤维，
细小颗粒，
不完全均匀的纸面质地。

背景整体保持干净。

不要：
泛黄做旧，
严重污渍，
折痕，
破损边缘，
烧焦痕迹，
仿古羊皮纸感。

这是干净的艺术纸，
不是旧档案纸。

【线条】
线条只负责帮助结构成立。

使用：
细黑线，
深灰线，
少量手绘结构线。

线条特点：
轻，
细，
自然，
略微不稳定，
偶尔断开，
轻微歪斜，
不完全闭合。

可以留下极少量手工犹豫感，
但不要凌乱。

不要使用：
精确矢量描边，
工程制图式直线，
大量排线，
密集阴影线，
复杂素描结构。

不要给所有色块都加完整黑色外轮廓。

部分轮廓可以直接通过色块边缘成立。

【线条与色块关系】
视觉优先级必须是：

色块 > 轮廓 > 细节线。

线条负责提示：
这里是什么。

色块负责决定：
画面为什么成立。

不要让插画退化成：
黑色线稿 + 一点点轻微颜色。

必须让丙烯色块具有明显视觉存在感。

【丙烯色块】
上色是本风格最重要的部分之一。

使用明显、完整、清楚的手绘丙烯平涂色块。

色块应具有：
不透明覆盖感，
稍微可见的笔触，
轻微颜料厚度，
不完全规则的边缘，
纸张颗粒透出的局部变化。

色块不是完美数字填充。

边缘可以：
略微抖动，
有轻微刷痕，
局部超出线条，
少量区域没有完全覆盖。

但整体仍然必须干净、克制。

【禁止错误材质】
这不是：

水彩；
彩铅；
蜡笔；
马克笔；
粉彩；
油画；
纯数字矢量填色。

不要出现：
水彩透明晕染，
蜡笔颗粒粗痕，
彩铅细密排线，
油画厚重堆叠，
数字渐变。

目标是“小幅纸上丙烯平涂”。

【颜色数量】
整张画最多使用 4 种主要颜色。

黑色或深灰轮廓线不计算在主要颜色中。

白色主要来自纸张本身，
不要使用大面积白颜料覆盖。

根据输入内容自动选择 2–4 种颜色。

优先选择：
红，
黄，
蓝，
绿，
以及它们的克制变化。

也可以根据原照片保留关键识别色。

颜色需要：
鲜明，
纯粹，
清楚，
具有区分度。

但不要所有颜色同等饱和。

建立一个主要颜色，
其余颜色作为辅助。

【颜色关系】
如果输入来自照片：

优先保留照片中最具有辨识度的 1–3 个关键颜色。

不需要忠实复刻所有环境色。

如果输入来自主题：

根据 {{情绪倾向}} 选择协调限色系统。

安静：
蓝、灰绿、米黄等低刺激组合。

克制：
减少颜色数量，使用 2–3 色。

童趣：
使用更纯净、明亮的红黄蓝绿组合，但控制面积。

轻松：
使用柔和明亮的自然色。

诗意：
使用稍低饱和的蓝、绿、暖黄或砖红。

不要使用：
复杂渐变，
荧光光效，
霓虹，
大面积阴影色，
几十种近似色。

【留白】
留白是主要视觉结构。

四周应保留约 70%–90% 的纸面空间。

留白承担：
呼吸，
安静，
尺度，
诗意，
主体聚焦，
封面感。

不要觉得画面空就增加东西。

“空”本身就是视觉内容。

整个画面需要给人一种：
一个小小的记忆片段被安静保存在白纸上的感觉。

【构图】
构图保持单一视觉中心。

可以使用：
居中，
轻微偏左，
轻微偏右，
略偏下，
略偏上。

主体可以很小，
但不能小到失去识别。

不要使用：
复杂透视，
多场景拼接，
左右平均分栏，
多个同尺寸主体，
复杂前中后景，
满版构图。

主体周围至少保留一块明显连续的空白区域。

【不同画幅】
根据 {{画幅比例}} 原生调整构图。

1:1：
最适合小主体 + 四周均衡留白。
主体可居中或轻微偏心。

3:4 / 4:5：
适合纵向小场景。
主体可以位于中下部或偏中区域，
顶部保留更多呼吸空间。

16:9：
适合横向关系。
主体可以偏左或偏右，
利用另一侧留白形成诗意距离。

自定义比例：
重新安排主体大小和位置，
不要从固定方图直接裁切。

【背景元素】
通常不完整重建背景。

如果背景确实有助于识别主体，
最多使用：
1–3 条结构线，
一个极小色块，
一个简单地面关系
进行暗示。

例如：
一条地面线，
一个小桌面，
一块墙体颜色，
一条山的轮廓，
一个门洞。

如果背景不能帮助理解主体，
完全删除。

不要绘制完整：
房间，
天空，
街道，
山水，
室内陈设，
复杂建筑群。

【人物】
如果主体是人物：

保留：
主要身体姿态，
头部方向，
发型轮廓，
服装整体形状，
动作，
必要配饰。

脸部可以极度简化。

不要绘制写实：
皮肤，
眼睛高光，
鼻孔，
嘴唇纹理，
面部阴影。

人物应更接近：
简单编辑插画，
儿童绘本中经过设计的成年人物，
小幅手绘人物速写。

但不要过度卡通化。

【宠物】
如果主体是宠物：

保留：
体型，
头部轮廓，
耳朵，
毛色大块关系，
姿势，
尾巴。

毛发不要逐根绘制。

使用少量线条和大片色块建立毛色。

宠物仍需具有原主体的辨识特征，
但整体保持高度概括。

【建筑】
如果主体是建筑：

保留：
外轮廓，
屋顶，
塔楼，
主立面，
最重要的门窗，
标志性结构。

建筑色块要明显。

不要描绘全部砖块、装饰、窗框。

让建筑像被几笔重新提炼出来的“建筑记忆”。

【文字】
如果 {{名称或文字}} 为空：
默认不加入任何文字。

头像用途尤其默认无文字。

如果用户提供文字：
只显示用户提供的准确内容。

文字保持：
小，
少，
克制，
清楚。

可以放在：
主体下方，
右下角，
大片留白区域。

字体使用简单现代字体或轻微手写编辑字体，
不要抢主体。

不要自动加入：
英文，
日期，
说明，
Logo，
水印，
签名，
编号。

【用途适配】
如果 {{用途}} 为头像：

保持主体轮廓清楚，
构图更加集中，
减少背景暗示，
不添加文字，
缩略图状态下仍能识别。

如果为头像衍生图：

允许稍微增加一两个与主体有关的小型结构，
但继续保持大留白。

如果为纸感插画：

可增加少量纸张和手工色块细节。

如果为主题卡片：

可以在大片留白中加入用户明确提供的文字，
但仍以小主体为核心。

【必须保留】
如果用户填写 {{需要保留的特征}}：

优先保留这些特征。

这些特征应被提炼，
但不能删除或替换成其他内容。

它们可以通过：
轮廓，
动作，
色块，
少量线条
表现。

不要为了极简化而丢掉真正决定身份的关键特征。

【必须避免】
严格排除：
{{不想出现的元素}}

同时不要出现：

彩铅质感；
蜡笔质感；
水彩晕染；
纯线稿；
只有轮廓没有明显色块；
颜色过轻、过虚；

复杂写实细节；
摄影质感；
高精度人物建模；
厚重油画；
商业卡通；
3D 渲染；
光滑数字插画；

复杂背景；
满版色块；
过强空间透视；
多个视觉中心；
无关人物；
无关道具；
装饰性图案；

超过 4 种主要颜色；
复杂渐变；
发光效果；
霓虹；
重阴影；

AI 式精致堆砌；
模板化构图；
每张图都使用同一种主体位置；
相框；
卡片边框；
Logo；
水印；
大量文字。

【生成前检查】
生成前内部检查：

最值得保留的主体是什么？

主体最关键的 3–5 个识别特征是什么？

是否可以再删除一些细节？

主体是否控制在约 10%–20% 的画面面积？

是否保留了约 70%–90% 的白纸留白？

视觉是否仍然只有一个中心？

线条是否足够少？

丙烯色块是否足够明显？

是否错误地变成水彩、彩铅或蜡笔？

是否使用超过 4 种主要颜色？

背景是否真的有必要？

如果去掉背景仍然能理解主体，
去掉背景。

是否存在无意义装饰？

如果一个元素不能增加：
识别度，
主题表达，
构图，
情绪，

删除它。

【最终标准】
最终只生成一张独立完整插画。

不要输出：
多个方案，
拼图，
网格，
联系表，
样机，
设计过程，
前后对比。

最终成图必须同时满足：

真实粗糙白纸背景；
一个小而清楚的主体；
主体约占画面 10%–20%；
大面积自然留白；
主体经过高度视觉提炼；
只有少量手绘线条；
使用明显、完整的丙烯平涂色块；
最多 4 种主要颜色；
纸张纹理和手工边缘清楚可感知；
没有复杂背景；
没有多余装饰；
缩略图仍能辨认主体；
整体安静、轻巧、克制、有设计感。

最终效果应像一位擅长视觉提炼的插画师，
面对真实照片或一个复杂主题，
只留下最值得记住的一瞬间，

然后在一张略粗糙的白纸上，
用几根轻巧的线，
和几块鲜明的丙烯颜色，
把它重新画了出来。

不是“照片的简化版”，
而是“从照片或主题里提炼出来的一段视觉记忆”。
```
